# 史记·卷13　史记卷十三

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中华本页 0487a</sub>　三代世表第一索隐应劭云：“表者，录其事而见之。”案：礼有表记，而郑玄云“表，明也”。谓事微而不著，须表明也，故言表也。正义言代者，以五帝久古，传记少见，夏殷以来，乃有尚书略有年月，比于五帝事迹易明，故举三代为首表。表者，明也。明言事仪。

<a id="p2"></a>**〔2〕**　<sub>中华本页 0487a</sub>　太史公曰：五帝、三代之记，尚矣。自殷以前诸侯不可得而谱，周以来乃颇可著。孔子因史文次春秋，纪元年，正时日月，盖其详哉。至于序尚书则略，无年月；或颇有，然多阙，不可录。故疑则传疑，盖其慎也。

<a id="p3"></a>**〔3〕**　<sub>中华本页 0487a</sub>　余读谍记，黄帝以来皆有年数。稽其历谱谍终始五德之传，古文咸不同，乖异。夫子之弗论次其年月，岂虚哉！于是以五帝系谍、尚书集世纪黄帝以来讫共和为世表。

<a id="p4"></a>**〔4〕**　<sub>中华本页 0487a</sub>　皆黄帝子也，得无与诗谬秋？”

<a id="p5"></a>**〔5〕**　<sub>中华本页 0487a</sub>　神不能自成，须人而生，柰何无父而生乎！一言有父，一言无父，信以传信，疑以传

<a id="p6"></a>**〔6〕**　<sub>中华本页 0487a</sub>　疑，故两言之。尧知契、稷皆贤人，天之所生，故封之契七十里，后十余世至汤，王天

<a id="p7"></a>**〔7〕**　<sub>中华本页 0487a</sub>　下。尧知后稷子孙之后王也，故益封之百里，其后世且千岁，至文王而有天下。诗

<a id="p8"></a>**〔8〕**　<sub>中华本页 0487a</sub>　传曰：‘汤之先为契，无父而生。契母与姊妹浴于玄丘水，有燕衔卵堕之，契母得，故

<a id="p9"></a>**〔9〕**　<sub>中华本页 0487a</sub>　含之，误吞之，即生契。契生而贤，尧立为司徒，姓之曰子氏。子者兹；兹，益大

<a id="p10"></a>**〔10〕**　<sub>中华本页 0487a</sub>　也。诗人美而颂之曰“殷社芒芒，天命玄鸟，降而生商”。商者质，殷号也。文王

<a id="p11"></a>**〔11〕**　<sub>中华本页 0487a</sub>　之先为后稷，后稷亦无父而生。后稷母为姜嫄，出见大人迹而履践之，知于身，

<a id="p12"></a>**〔12〕**　<sub>中华本页 0487a</sub>　则生后稷。姜嫄以为无父，贱而[⿱𠫓廾]之道中，牛羊避不践也。抱之山中，山者养

<a id="p13"></a>**〔13〕**　<sub>中华本页 0487a</sub>　之。又捐之大泽，鸟覆席食之。姜嫄怪之，于是知其天子，乃取长之。尧知其贤才，

<a id="p14"></a>**〔14〕**　<sub>中华本页 0487a</sub>　立以为大农，姓之曰姬氏。姬者，本也。诗人美而颂之曰“厥初生民”，深修益成，而

<a id="p15"></a>**〔15〕**　<sub>中华本页 0487a</sub>　道后稷之始也。’孔子曰：‘昔者尧命契为子氏，为有汤也。命后稷为姬氏，为有文王

<a id="p16"></a>**〔16〕**　<sub>中华本页 0487a</sub>　也。大王命季历，明天瑞也。太伯之吴，遂生源也。’天命难言，非圣人莫能见。

<a id="p17"></a>**〔17〕**　<sub>中华本页 0487a</sub>　舜、禹、契、后稷皆黄帝子孙也。黄帝策天命而治天下，德泽深后世，故其子孙皆复

<a id="p18"></a>**〔18〕**　<sub>中华本页 0487a</sub>　立为天子，是天之报有德也。人不知，以为泛从布衣匹夫起耳。夫布衣匹夫安能无

<a id="p19"></a>**〔19〕**　<sub>中华本页 0506a</sub>　故而起王天下乎？其有天命然。”

<a id="p20"></a>**〔20〕**　<sub>中华本页 0506a</sub>　政明则修礼义，因天时举兵征伐而利者王，有福千世。蜀王，黄帝后世也，至今

<a id="p21"></a>**〔21〕**　<sub>中华本页 0506a</sub>　在汉西南五千里，常来朝降，输献于汉，非以其先之有德，泽流后世邪？行道德岂可

<a id="p22"></a>**〔22〕**　<sub>中华本页 0506a</sub>　以忽秋哉！人君王者举而观之。汉大将军霍子孟名光者，亦黄帝后世也。此可为

<a id="p23"></a>**〔23〕**　<sub>中华本页 0506a</sub>　博闻远见者言，固难为浅闻者说也。何以言之？古诸侯以国为姓。霍者，国名也。

<a id="p24"></a>**〔24〕**　<sub>中华本页 0506a</sub>　武王封弟叔处于霍，后世晋献公灭霍公，后世为庶民，往来居平阳。平阳在河东，河

<a id="p25"></a>**〔25〕**　<sub>中华本页 0506a</sub>　东晋地，分为衞国。以诗言之，亦可为周世。周起后稷，后稷无父而生。以三代世

<a id="p26"></a>**〔26〕**　<sub>中华本页 0506a</sub>　传言之，后稷有父名高辛；高辛，黄帝曾孙。黄帝终始传曰：‘汉兴百有余年，有

<a id="p27"></a>**〔27〕**　<sub>中华本页 0507a</sub>　人不短不长，出白燕之乡，持天下之政，时有婴儿主，欲行车。’霍

<a id="p28"></a>**〔28〕**　<sub>中华本页 0507a</sub>　将军者，本居平阳白燕。臣为郎时，与方士考功会旗亭下，为臣言。岂

<a id="p29"></a>**〔29〕**　<sub>中华本页 0507a</sub>　不伟哉！”
