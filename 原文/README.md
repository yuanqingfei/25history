# 原文

这里是本项目所用底本的可浏览版本，由 `scripts/build_yuanwen.py` 从 `sources/` 自动生成，**不要手工修改**。

- 每段前的 **〔N〕** 就是定位符里的“段”；锚点为 `#pN`，传记中的定位符链接直接跳到这里。
- 每段后的“引用此段”列出引用了这一段的人物传，可以反向跳转。
- 段首的“中華本頁”是该段起始处在中华书局点校本中的页码。
