# 漢書·卷100上　傳第七十上

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 4197a</sub>　傳第七十上

<a id="p2"></a>**〔2〕**　<sub>中華本頁 4197a</sub>　師古曰：「自漢書以後分為下卷。」

<a id="p3"></a>**〔3〕**　<sub>中華本頁 4197a</sub>　班氏之先，與楚同姓，令尹子文之後也。子文初生，棄於瞢中，而虎乳之。楚人謂乳「穀」，謂虎「於檡」，故名穀於檡，字子文。楚人謂虎「班」，其子以為號。秦之滅楚，遷晉、代之間，因氏焉。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 4197a</sub>　始皇之末，班壹避墬於樓煩，致馬牛羊數千羣。值漢初定，與民無禁，當孝惠、高后時，以財雄邊，出入弋獵，旌旗鼓吹，年百餘歲，以壽終，故北方多以「壹」為字者。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 4198a</sub>　壹生孺。孺為任俠，州郡歌之。孺生長，官至上谷守。長生回，以茂材為長子令。回生況，舉孝廉為郎，積功勞，至上河農都尉，大司農奏課連最，入為左曹越騎校尉。成帝之初，女為{GJ-FB87}伃，致仕就第，貲累千金，徙昌陵。昌陵後罷，大臣名家皆占數于長安。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 4198a</sub>　況生三子：伯、斿、穉。伯少受詩於師丹。大將軍王鳳薦伯宜勸學，召見宴昵殿，容貌甚麗，誦說有法，拜為中常侍。時上方鄉學，鄭寬中、張禹朝夕入說尚書、論語於金華殿中，詔伯受焉。既通大義，又講異同於許商，遷奉車都尉。數年，金華之業絕，出與王、許子弟為羣，在於綺襦紈絝之間，非其好也。

<a id="p7"></a>**〔7〕**　<sub>中華本頁 4198a</sub>　家本北邊，志節忼慨，數求使匈奴。河平中，單于來朝，上使伯持節迎於塞下。會定襄大姓石、李羣輩報怨，殺追捕吏，伯上狀，因自請願試守期月。上遣侍中中郎將王舜馳傳代伯護單于，并奉璽書印綬，即拜伯為定襄太守。定襄聞伯素貴，年少，自請治劇，畏其下車作威，吏民竦息。伯至，請問耆老父祖故人有舊恩者，迎延滿堂，日為供具，執子孫禮。郡中益弛。諸所賓禮皆名豪，懷恩醉酒，共諫伯宜頗攝錄盜賊，具言本謀亡匿處。伯曰：「是所望於父師矣。」乃召屬縣長吏，選精進掾史，分部收捕，及它隱伏，旬日盡得。郡中震[⿰石凾]，咸稱神明。歲餘，上徵伯。伯上書願過故郡上父祖冢。有詔，太守都尉以下會。因召宗族，各以親疎加恩施，散數百金。北州以為榮，長老紀焉。道病中風，既至，以侍中光祿大夫養病，賞賜甚厚，數年未能起。

<a id="p8"></a>**〔8〕**　<sub>中華本頁 4198a</sub>　會許皇后廢，班{GJ-FB87}伃供養東宮，進侍者李平為{GJ-FB87}伃，而趙飛燕為皇后，伯遂稱篤。久之，上出過臨候伯，伯惶恐，起{GJ-C8F4}事。

<a id="p9"></a>**〔9〕**　<sub>中華本頁 4198a</sub>　自大將軍薨後，富平、定陵侯張放、淳于長等始愛幸，出為微行，行則同輿執轡；入侍禁中，設宴飲之會，及趙、李諸侍中皆引滿舉白，談{GJ-F9DE}大噱。時乘輿幄坐張畫屏風，畫紂醉踞妲己作長夜之樂。上以伯新起，數目禮之，因顧指畫而問伯：「紂為無道，至於是虖？」伯對曰：「書云『乃用婦人之言』，何有踞肆於朝？所謂衆惡歸之，不如是之甚者也。」上曰：「苟不若此，此圖何戒？」伯曰：「『沈湎于酒』，微子所以告去也；『式號式謼』，大雅所以流連也。詩書淫亂之戒，其原皆在於酒。」上乃謂然歎曰：「吾久不見班生，今日復聞讜言！」放等不懌，稍自引起更衣，因罷出。時長信庭林表適使來，聞見之。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 4201a</sub>　後上朝東宮，太后泣曰：「帝間顏色瘦黑，班侍中本大將軍所舉，宜寵異之，益求其比，以輔聖德。宜遣富平侯且就國。」上曰：「諾。」車騎將軍王音聞之，以風丞相御史奏富平侯罪過，上乃出放為邊都尉。後復徵入，太后與上書曰：「前所道尚未效，富平侯反復來，其能默虖？」上謝曰：「請今奉詔。」是時許商為少府，師丹為光祿勳，上於是引商、丹入為光祿大夫，伯遷水衡都尉，與兩師並侍中，皆秩中二千石。每朝東宮，常從；及有大政，俱使諭指於公卿。上亦稍厭游宴，復修經書之業，太后甚悅。丞相方進復奏，富平侯竟就國。會伯病卒，年三十八，朝廷愍惜焉。

<a id="p11"></a>**〔11〕**　<sub>中華本頁 4201a</sub>　斿博學有俊材，左將軍（(師)）【史】丹舉賢良方正，以對策為議郎，遷諫大夫、右曹中郎將，與劉向校祕書。每奏事，斿以選受詔進讀羣書。上器其能，賜以祕書之副。時書不布，自東平思王以叔父求太史公、諸子書，大將軍白不許。語在東平王傳。斿亦早卒，有子曰嗣，顯名當世。

<a id="p12"></a>**〔12〕**　<sub>中華本頁 4201a</sub>　穉少為黃門郎中常侍，方直自守。成帝季年，立定陶王為太子，數遣中盾請問近臣，穉獨不敢答。哀帝即位，出穉為西河屬國都尉，遷廣平相。

<a id="p13"></a>**〔13〕**　<sub>中華本頁 4201a</sub>　王莽少與穉兄弟同列友善，兄事斿而弟畜穉。斿之卒也，修緦麻，賻賵甚厚。平帝即位，太后臨朝，莽秉政，方欲文致太平，使使者分行風俗，采頌聲，而穉無所上。琅邪太守公孫閎言災害於公府，大司空甄豐遣屬馳至兩郡諷吏民，而劾閎空造不祥，穉絕嘉應，嫉害聖政，皆不道。太后曰：「不宣德美，宜與言災害者異罰。且後宮賢家，我所哀也。」閎獨下獄誅。穉懼，上書陳恩謝罪，願歸相印，入補延陵園郎，太后許焉。食故祿終身。由是班氏不顯莽朝，亦不罹咎。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 4201a</sub>　初，成帝性寬，進入直言，是以王音、翟方進等繩法舉過，而劉向、杜鄴、王章、朱雲之徒肆意犯上，故自帝師安昌侯，諸舅大將軍兄弟及公卿大夫、後宮外屬史許之家有貴寵者，莫不被文傷詆。唯谷永嘗言「建始、河平之際，許、班之貴，傾動前朝，熏灼四方，賞賜無量，空虛內臧，女寵至極，不可尚矣；今之後起，天所不饗，什倍於前。」永指以駮譏趙、李，亦無間云。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 4205a</sub>　穉生彪。彪字叔皮，幼與從兄嗣共遊學，家有賜書，內足於財，好古之士自遠方至，父黨揚子雲以下莫不造門。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 4205a</sub>　嗣雖修儒學，然貴老嚴之術。桓生欲借其書，嗣報曰：「若夫嚴子者，絕聖棄智，修生保真，清虛澹泊，歸之自然，獨師友造化，而不為世俗所役者也。漁釣於一壑，則萬物不奸其志；栖遲於一丘，則天下不易其樂。不絓聖人之罔，不齅驕君之餌，蕩然肆志，談者不得而名焉，故可貴也。今吾子已貫仁誼之羈絆，繫名聲之韁鎖，伏周、孔之軌躅，馳顏、閔之極摯，既繫攣於世教矣，何用大道為自眩曜？昔有學步於邯鄲者。曾未得其髣髴，又復失其故步，遂匍匐而歸耳！恐似此類，故不進。」嗣之行己持論如此。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 4206a</sub>　叔皮唯聖人之道然後盡心焉。年二十，遭王莽敗，世祖即位於冀州。時隗囂據壟擁衆，招輯英俊，而公孫述稱帝於蜀漢，天下雲擾，大者連州郡，小者據縣邑。囂問彪曰：「往者周亡，戰國並爭，天下分裂，數世然後乃定，其抑者從橫之事復起於今乎？將承運迭興在於一人也？願先生論之。」對曰：「周之廢興與漢異。昔周立爵五等，諸侯從政，本根既微，枝葉強大，故其末流有從橫之事，其勢然也。漢家承秦之制，並立郡縣，主有專己之威，臣無百年之柄，至於成帝，假借外家，哀、平短祚，國嗣三絕，危自上起，傷不及下。故王氏之貴，傾擅朝廷，能竊號位，而不根於民。是以即真之後，天下莫不引領而歎，十餘年間，外內騷擾，遠近俱發，假號雲合，咸稱劉氏，不謀而同辭。方今雄桀帶州城者，皆無七國世業之資。詩云：『皇矣上帝，臨下有赫，鑒觀四方，求民之莫。』今民皆謳吟思漢，鄉仰劉氏，已可知矣。」囂曰：「先生言周、漢之勢，可也，至於但見愚民習識劉氏姓號之故，而謂漢家復興，疏矣！昔秦失其鹿，劉季逐而掎之，時民復知漢虖！」既感囂言，又愍狂狡之不息，乃著王命論以救時難。其辭曰：

<a id="p18"></a>**〔18〕**　<sub>中華本頁 4206a</sub>　虞，光濟四海，奕世載德，至于湯武，而有天下。雖其遭遇異時，禪代不同，至于

<a id="p19"></a>**〔19〕**　<sub>中華本頁 4206a</sub>　應天順民，其揆一也。是故劉氏承堯之祚，氏族之世，著乎春秋。唐據火德，而漢

<a id="p20"></a>**〔20〕**　<sub>中華本頁 4206a</sub>　紹之，始起沛澤，則神母夜號，以章赤帝之符。由是言之，帝王之祚，必有明聖顯懿之

<a id="p21"></a>**〔21〕**　<sub>中華本頁 4206a</sub>　德，豐功厚利積絫之業，然後精誠通於神明，流澤加於生民，故能為鬼神所福饗，天

<a id="p22"></a>**〔22〕**　<sub>中華本頁 4206a</sub>　下所歸往，未見運世無本，功德不紀，而得屈起在此位者也。世俗見高祖興於布

<a id="p23"></a>**〔23〕**　<sub>中華本頁 4209a</sub>　衣，不達其故，以為適遭暴亂，得奮其劍，游說之士至比天下於逐鹿，幸捷而得之，不知

<a id="p24"></a>**〔24〕**　<sub>中華本頁 4209a</sub>　神器有命，不可以智力求也。悲夫！此世所以多亂臣賊子者也。若然者，豈徒闇於

<a id="p25"></a>**〔25〕**　<sub>中華本頁 4209a</sub>　天道哉？又不覩之於人事矣！

<a id="p26"></a>**〔26〕**　<sub>中華本頁 4209a</sub>　轉死溝壑。何則？貧窮亦有命也。況虖天子之貴，四海之富，神明之祚，可得而妄處

<a id="p27"></a>**〔27〕**　<sub>中華本頁 4209a</sub>　哉？故雖遭罹會，竊其權柄，勇如信、布，彊如梁、籍，成如王莽，然卒潤鑊伏質，

<a id="p28"></a>**〔28〕**　<sub>中華本頁 4209a</sub>　亨醢分裂，又況𡺣{GJ-C8E6}，尚不及數子，而欲闇奸天位者虖！是故駑蹇之乘不騁

<a id="p29"></a>**〔29〕**　<sub>中華本頁 4210a</sub>　千里之塗，燕雀之疇不奮六翮之用，楶梲之材不荷棟梁之任，斗筲之子不秉帝王之

<a id="p30"></a>**〔30〕**　<sub>中華本頁 4210a</sub>　重。易曰「鼎折足，覆公餗」，不勝其任也。

<a id="p33"></a>**〔33〕**　<sub>中華本頁 4210a</sub>　使來，陵母見之，謂曰：「願告吾子，漢王長者，必得天下，子謹事之，無有二心。」遂對

<a id="p34"></a>**〔34〕**　<sub>中華本頁 4211a</sub>　漢使伏劍而死，以固勉陵。其後果定於漢，陵為宰相封侯。夫以匹婦之明，猶能推

<a id="p35"></a>**〔35〕**　<sub>中華本頁 4211a</sub>　事理之致，探禍福之機，而全宗祀於無窮，垂策書於春秋，而況大丈夫之事虖！是

<a id="p36"></a>**〔36〕**　<sub>中華本頁 4211a</sub>　故窮達有命，吉凶由人，嬰母知廢，陵母知興，審此四者，帝王之分決矣。

<a id="p37"></a>**〔37〕**　<sub>中華本頁 4211a</sub>　四曰寬明而仁恕，五曰知人善任使。加之以信誠好謀，達於聽受，見善如不及，用人如

<a id="p38"></a>**〔38〕**　<sub>中華本頁 4211a</sub>　由己，從諫如順流，趣時如嚮赴；當食吐哺，納子房之策；拔足揮洗，揖酈生之

<a id="p39"></a>**〔39〕**　<sub>中華本頁 4211a</sub>　說；寤戍卒之言，斷懷土之情；高四皓之名，割肌膚之愛；舉韓信於行陳，收

<a id="p40"></a>**〔40〕**　<sub>中華本頁 4211a</sub>　陳平於亡命，英雄陳力，羣策畢舉：此高祖之大略，所以成帝業也。若乃靈瑞符應，又

<a id="p41"></a>**〔41〕**　<sub>中華本頁 4211a</sub>　可略聞矣。初劉媼任高祖而夢與神遇，震電晦冥，有龍蛇之怪。及其長而多靈，有

<a id="p42"></a>**〔42〕**　<sub>中華本頁 4211a</sub>　異於衆，是以王、武感物而折券，呂公覩形而進女；秦皇東游以厭其氣，呂后望雲而知

<a id="p43"></a>**〔43〕**　<sub>中華本頁 4212a</sub>　所處；始受命則白蛇分，西入關則五星聚。故淮陰、留侯謂之天授，非人力也。

<a id="p44"></a>**〔44〕**　<sub>中華本頁 4212a</sub>　瑞不同斯度，而苟昧於權利，越次妄據，外不量力，內不知命，則必喪保家之主，

<a id="p45"></a>**〔45〕**　<sub>中華本頁 4212a</sub>　失天年之壽，遇折足之凶，伏鈇鉞之誅。英雄誠知覺寤，畏若禍戒，超然遠覽，淵

<a id="p46"></a>**〔46〕**　<sub>中華本頁 4212a</sub>　然深識，收陵、嬰之明分，絕信、布之覬覦，距逐鹿之瞽說，審神器之有授，毋貪不

<a id="p47"></a>**〔47〕**　<sub>中華本頁 4212a</sub>　可幾，為二母之所咲，則福祚流于子孫，天祿其永終矣。

<a id="p48"></a>**〔48〕**　<sub>中華本頁 4212a</sub>　知隗囂終不寤，乃避墬於河西。河西大將軍竇融嘉其美德，訪問焉。舉茂材，為徐令，以病去官。後數應三公之召。仕不為祿，所如不合；學不為人，博而不俗；言不為華，述而不作。

<a id="p49"></a>**〔49〕**　<sub>中華本頁 4212a</sub>　有子曰固，弱冠而孤，作幽通之賦，以致命遂志。其辭曰：
