# 漢書·卷2　惠帝紀第二

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 0085a</sub>　惠帝紀第二

<a id="p2"></a>**〔2〕**　<sub>中華本頁 0085a</sub>　孝惠皇帝，高祖太子也，母曰呂皇后。帝年五歲，高祖初為漢王。二年，立為太子。十二年四月，高祖崩。五月丙寅，太子即皇帝位，尊皇后曰皇太后。賜民爵一級。中郎、郎中滿六歲爵三級，四歲二級。外郎滿六歲二級。中郎不滿一歲一級。外郎不滿二歲賜錢萬。宦官尚食比郎中。謁者、執楯、執戟、武士、騶比外郎。太子御驂乘賜爵五大夫，舍人滿五歲二級。賜給喪事者，二千石錢二萬，六百石以上萬，五百石、二百石以下至佐史五千。視作斥上者，將軍四十金，二千石二十金，六百石以上六金，五百石以下至佐史二金。減田租，復十五稅一。爵五大夫、吏六百石以上及宦皇帝而知名者有罪當盜械者，皆頌繫。上造以上及內外公孫耳孫有罪當刑及當為城旦舂者，皆耐為鬼薪白粲。民年七十以上若不滿十歲有罪當刑者，皆完之。又曰：「吏所以治民也，能盡其治則民賴之，故重其祿，所以為民也。今吏六百石以上父母妻子與同居，及故吏嘗佩將軍都尉印將兵及佩二千石官印者，家唯給軍賦，他無有所與。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 0086a</sub>　令郡諸侯王立高廟。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 0086a</sub>　元年冬十二月，趙隱王如意薨。民有罪，得買爵三十級以免死罪。賜民爵，戶一級。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 0086a</sub>　春正月，城長安。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 0086a</sub>　二年冬十月，齊悼恵王來朝，獻城陽郡以益魯元公主邑，尊公主為太后。

<a id="p7"></a>**〔7〕**　<sub>中華本頁 0086a</sub>　春正月癸酉，有兩龍見蘭陵家人井中，乙亥夕而不見。隴西地震。

<a id="p8"></a>**〔8〕**　<sub>中華本頁 0086a</sub>　夏旱。郃陽侯仲薨。秋七月辛未，相國何薨。

<a id="p9"></a>**〔9〕**　<sub>中華本頁 0086a</sub>　三年春，發長安六百里內男女十四萬六千人城長安，三十日罷。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 0086a</sub>　以宗室女為公主，嫁匈奴單于。

<a id="p11"></a>**〔11〕**　<sub>中華本頁 0086a</sub>　夏五月，立閩越君搖為東海王。

<a id="p12"></a>**〔12〕**　<sub>中華本頁 0086a</sub>　六月，發諸侯王、列侯徒隸二萬人城長安。

<a id="p13"></a>**〔13〕**　<sub>中華本頁 0086a</sub>　秋七月，都災。南越王趙佗稱臣奉貢。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 0086a</sub>　四年冬十月壬寅，立皇后張氏。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 0086a</sub>　春正月，舉民孝弟力田者復其身。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 0086a</sub>　三月甲子，皇帝冠，赦天下。省法令妨吏民者；除挾書律。長樂宮鴻臺災。宜陽雨血。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 0086a</sub>　秋七月乙亥，未央宮凌室災；丙子，織室災。

<a id="p18"></a>**〔18〕**　<sub>中華本頁 0086a</sub>　五年冬十月，靁；桃李華，棗實。

<a id="p19"></a>**〔19〕**　<sub>中華本頁 0086a</sub>　春正月，復發長安六百里內男女十四萬五千人城長安，三十日罷。

<a id="p20"></a>**〔20〕**　<sub>中華本頁 0086a</sub>　夏，大旱。

<a id="p21"></a>**〔21〕**　<sub>中華本頁 0091a</sub>　秋八月己丑，相國參薨。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 0091a</sub>　九月，長安城成。賜民爵，戶一級。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 0091a</sub>　六年冬十月辛丑，齊王肥薨。

<a id="p24"></a>**〔24〕**　<sub>中華本頁 0091a</sub>　令民得賣爵。女子年十五以上至三十不嫁，五算。

<a id="p25"></a>**〔25〕**　<sub>中華本頁 0091a</sub>　夏六月，舞陽侯噲薨。

<a id="p26"></a>**〔26〕**　<sub>中華本頁 0091a</sub>　起長安西巿，修敖倉。

<a id="p27"></a>**〔27〕**　<sub>中華本頁 0091a</sub>　七年冬十月，發車騎、材官詣滎陽，太尉灌嬰將。

<a id="p28"></a>**〔28〕**　<sub>中華本頁 0091a</sub>　春正月辛丑朔，日有蝕之。夏五月丁卯，日有蝕之，既。

<a id="p29"></a>**〔29〕**　<sub>中華本頁 0091a</sub>　秋八月戊寅，帝崩于未央宮。九月辛丑，葬安陵。

<a id="p30"></a>**〔30〕**　<sub>中華本頁 0091a</sub>　贊曰：孝惠內修親親，外禮宰相，優寵齊悼、趙隱，恩敬篤矣。聞叔孫通之諫則懼然，納曹相國之對而心說，可謂寬仁之主。遭呂太后虧損至德，悲夫！
