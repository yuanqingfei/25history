# 漢書·卷7　昭帝紀第七

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 0217a</sub>　昭帝紀第七

<a id="p2"></a>**〔2〕**　<sub>中華本頁 0217a</sub>　孝昭皇帝，武帝少子也。母曰趙{GJ-FB87}伃，本以有奇異得幸，及生帝，亦奇異。語在外戚傳。武帝末，戾太子敗，燕王旦、廣陵王胥行驕嫚，後元二年二月上疾病，遂立昭帝為太子，年八歲。以侍中奉車都尉霍光為大司馬大將軍，受遺詔輔少主。明日，武帝崩。戊辰，太子即皇帝位，謁高廟。帝姊鄂邑公主益湯沐邑，為長公主，共養省中。大將軍光秉政，領尚書事，車騎將軍金日磾、左將軍上官桀副焉。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 0217a</sub>　夏六月，赦天下。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 0217a</sub>　秋七月，有星孛于東方。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 0217a</sub>　濟北王寬有罪，自殺。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 0217a</sub>　賜長公主及宗室昆弟各有差。追尊趙{GJ-FB87}伃為皇太后，起雲陵。

<a id="p7"></a>**〔7〕**　<sub>中華本頁 0217a</sub>　冬，匈奴入朔方，殺略吏民。發軍屯西河，左將軍桀行北邊。

<a id="p8"></a>**〔8〕**　<sub>中華本頁 0217a</sub>　始元元年春二月，黃鵠下建章宮太液池中。公卿上壽。賜諸侯王、列侯、宗室金錢各有差。

<a id="p9"></a>**〔9〕**　<sub>中華本頁 0217a</sub>　己亥，上耕于鉤盾弄田。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 0217a</sub>　益封燕王、廣陵王及鄂邑長公主各萬三千戶。

<a id="p11"></a>**〔11〕**　<sub>中華本頁 0217a</sub>　夏，為太后起園廟雲陵。

<a id="p12"></a>**〔12〕**　<sub>中華本頁 0217a</sub>　益州廉頭、姑繒、牂柯談指、同並二十四邑皆反。遣水衡都尉呂破胡募吏民及發犍為、蜀郡犇命擊益州，大破之。

<a id="p13"></a>**〔13〕**　<sub>中華本頁 0217a</sub>　有司請河內屬冀州，河東屬并州。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 0217a</sub>　秋七月，赦天下，賜民百戶牛酒。大雨，渭橋絕。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 0217a</sub>　八月，齊孝王孫劉澤謀反，欲殺青州刺史雋不疑，發覺，皆伏誅。遷不疑為京兆尹，賜錢百萬。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 0220a</sub>　九月丙子，車騎將軍日磾薨。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 0220a</sub>　閏月，遣故廷尉王平等五人持節行郡國，舉賢良，問民所疾苦、冤、失職者。

<a id="p18"></a>**〔18〕**　<sub>中華本頁 0220a</sub>　冬，無冰。

<a id="p19"></a>**〔19〕**　<sub>中華本頁 0220a</sub>　二年春正月，大將軍光、左將軍桀皆以前捕斬反虜重合侯馬通功封，光為博陸侯，桀為安陽侯。

<a id="p20"></a>**〔20〕**　<sub>中華本頁 0220a</sub>　以宗室毋在位者，舉茂才劉辟彊、劉長樂皆為光祿大夫，辟彊守長樂衞尉。

<a id="p21"></a>**〔21〕**　<sub>中華本頁 0220a</sub>　三月，遣使者振貸貧民毋種、食者。秋八月，詔曰：「往年災害多，今年蠶麥傷，所振貸種、食勿收責，毋令民出今年田租。」

<a id="p22"></a>**〔22〕**　<sub>中華本頁 0220a</sub>　冬，發習戰射士詣朔方，調故吏將屯田張掖郡。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 0220a</sub>　三年春二月，有星孛于西北。

<a id="p24"></a>**〔24〕**　<sub>中華本頁 0220a</sub>　秋，募民徙雲陵，賜錢田宅。

<a id="p25"></a>**〔25〕**　<sub>中華本頁 0220a</sub>　冬十月，鳳皇集東海，遣使者祠其處。

<a id="p26"></a>**〔26〕**　<sub>中華本頁 0220a</sub>　十一月壬辰朔，日有蝕之。

<a id="p27"></a>**〔27〕**　<sub>中華本頁 0220a</sub>　四年春三月甲寅，立皇后上官氏。赦天下。辭訟在後二年前，皆勿聽治。夏六月，皇后見高廟。賜長公主、丞相、將軍、列侯、中二千石以下及郎吏宗室錢帛各有差。

<a id="p28"></a>**〔28〕**　<sub>中華本頁 0220a</sub>　徙三輔富人雲陵，賜錢，戶十萬。

<a id="p29"></a>**〔29〕**　<sub>中華本頁 0220a</sub>　秋七月，詔曰：「比歲不登，民匱於食，流庸未盡還，往時令民共出馬，其止勿出。諸給中都官者，且減之。」

<a id="p30"></a>**〔30〕**　<sub>中華本頁 0222a</sub>　冬，遣大鴻臚田廣明擊益州。

<a id="p31"></a>**〔31〕**　<sub>中華本頁 0222a</sub>　廷尉李种坐故縱死罪棄市。

<a id="p32"></a>**〔32〕**　<sub>中華本頁 0222a</sub>　五年春正月，追尊皇太后父為順成侯。

<a id="p33"></a>**〔33〕**　<sub>中華本頁 0222a</sub>　夏陽男子張延年詣北闕，自稱衞太子，誣罔，要斬。

<a id="p34"></a>**〔34〕**　<sub>中華本頁 0222a</sub>　夏，罷天下亭母馬及馬弩關。

<a id="p35"></a>**〔35〕**　<sub>中華本頁 0222a</sub>　六月，封皇后父驃騎將軍上官安為桑樂侯。

<a id="p36"></a>**〔36〕**　<sub>中華本頁 0222a</sub>　詔曰：「朕以眇身獲保宗廟，戰戰栗栗，夙興夜寐，修古帝王之事，通保傅，傳孝經、論語、尚書，未云有明。其令三輔、太常舉賢良各二人，郡國文學高第各一人。賜中二千石以下至吏民爵各有差。」

<a id="p37"></a>**〔37〕**　<sub>中華本頁 0222a</sub>　罷儋耳、真番郡。

<a id="p38"></a>**〔38〕**　<sub>中華本頁 0222a</sub>　秋，大鴻臚廣明、軍正王平擊益州，斬首捕虜三萬餘人，獲畜產五萬餘頭。

<a id="p39"></a>**〔39〕**　<sub>中華本頁 0222a</sub>　六月春正月，上耕于上林。

<a id="p40"></a>**〔40〕**　<sub>中華本頁 0222a</sub>　二月，詔有司問郡國所舉賢良文學民所疾苦。議罷鹽鐵榷酤。

<a id="p41"></a>**〔41〕**　<sub>中華本頁 0222a</sub>　栘中監蘇武前使匈奴，留單于庭十九歲乃還，奉使全節，以武為典屬國，賜錢百萬。

<a id="p42"></a>**〔42〕**　<sub>中華本頁 0224a</sub>　夏，旱，大雩，大得舉火。

<a id="p43"></a>**〔43〕**　<sub>中華本頁 0224a</sub>　秋七月，罷榷酤官，令民得以律占租，賣酒升四錢。以邊塞闊遠，取天水、隴西、張掖郡各二縣置金城郡。

<a id="p44"></a>**〔44〕**　<sub>中華本頁 0224a</sub>　詔曰：「鉤町侯毋波率其君長人民擊反者，斬首捕虜有功。其立毋波為鉤町王。大鴻臚廣明將率有功，賜爵關內侯，食邑。」

<a id="p45"></a>**〔45〕**　<sub>中華本頁 0224a</sub>　元鳳元年春，長公主共養勞苦，復以藍田益長公主湯沐邑。

<a id="p46"></a>**〔46〕**　<sub>中華本頁 0224a</sub>　泗水戴王前薨，以毋嗣，國除。後宮有遺腹子煖，相、內史不奏言，上聞而憐之，立煖為泗水王。相、內史皆下獄。

<a id="p47"></a>**〔47〕**　<sub>中華本頁 0224a</sub>　三月，賜郡國所選有行義者涿郡韓福等五人帛，人五十匹，遣歸。詔曰：「朕閔勞以官職之事，其務修孝弟以教鄉里。令郡縣常以正月賜羊酒。有不幸者賜衣被一襲，祠以中牢。」

<a id="p48"></a>**〔48〕**　<sub>中華本頁 0224a</sub>　武都氐人反，遣執金吾馬適建、龍侯韓增、大鴻臚廣明將三輔、太常徒，皆免刑擊之。

<a id="p49"></a>**〔49〕**　<sub>中華本頁 0224a</sub>　夏六月，赦天下。

<a id="p50"></a>**〔50〕**　<sub>中華本頁 0224a</sub>　秋七月乙亥晦，日有蝕之，既。

<a id="p51"></a>**〔51〕**　<sub>中華本頁 0224a</sub>　八月，改始元為元鳳。

<a id="p52"></a>**〔52〕**　<sub>中華本頁 0224a</sub>　九月，鄂邑長公主、燕王旦與左將軍上官桀、桀子票騎將軍安、御史大夫桑弘羊皆謀反，伏誅。初，桀、安父子與大將軍光爭權，欲害之，詐使人為燕王旦上書言光罪。時上年十四，覺其詐。後有譖光者，上輒怒曰：「大將軍國家忠臣，先帝所屬，敢有譖毀者，坐之。」光由是得盡忠。語在燕王、霍光傳。

<a id="p53"></a>**〔53〕**　<sub>中華本頁 0224a</sub>　冬十月，詔曰：「左將軍安陽侯桀、票騎將軍桑樂侯安、御史大夫弘羊皆數以邪枉干輔政，大將軍不聽，而懷怨望，與燕王通謀，置驛往來相約結。燕王遣壽西長、孫縱之等賂遺長公主、丁外人、謁者杜延年、大將軍長史公孫遺等，交通私書，共謀令長公主置酒，伏兵殺大將軍光，徵立燕王為天子，大逆毋道。故稻田使者燕倉先發覺，以告大司農敞，敞告諫大夫延年，延年以聞。丞相徵事任宮手捕斬桀，丞相少史王壽誘將安入府門，皆已伏誅，吏民得以安。封延年、倉、宮、壽皆為列侯。」又曰：「燕王迷惑失道，前與齊王子劉澤等為逆，抑而不揚，望王反道自新，今乃與長公主及左將軍桀等謀危宗廟。王及公主皆自伏辜。其赦王太子建、公主子文信及宗室子與燕王、上官桀等謀反父母同產當坐者，皆免為庶人。其吏為桀等所詿誤，未發覺在吏者，除其罪。」

<a id="p54"></a>**〔54〕**　<sub>中華本頁 0227a</sub>　二年夏四月，上自建章宮徙未央宮，大置酒。賜郎從官帛，及宗室子錢，人二十萬。吏民獻牛酒者賜帛，人一匹。

<a id="p55"></a>**〔55〕**　<sub>中華本頁 0227a</sub>　六月，赦天下。詔曰：「朕閔百姓未贍，前年減漕三百萬石。頗省乘輿馬及（(菀)）【苑】馬，以補邊郡三輔傳馬。其令郡國毋斂今年馬口錢，三輔、太常郡得以叔粟當賦。」

<a id="p56"></a>**〔56〕**　<sub>中華本頁 0227a</sub>　三年春正月，泰山有大石自起立，上林有柳樹枯僵自起生。

<a id="p57"></a>**〔57〕**　<sub>中華本頁 0229a</sub>　罷中牟苑賦貧民。詔曰：「乃者民被水災，頗匱於食，朕虛倉廩，使使者振困乏。其止四年毋漕。三年以前所振貸，非丞相御史所請，邊郡受牛者勿收責。」

<a id="p58"></a>**〔58〕**　<sub>中華本頁 0229a</sub>　夏四月，少府徐仁、廷尉王平、左馮翊賈勝胡皆坐縱反者，仁自殺，平、勝胡皆要斬。

<a id="p59"></a>**〔59〕**　<sub>中華本頁 0229a</sub>　冬，遼東烏桓反，以中郎將范明友為度遼將軍，將北邊七郡郡二千騎擊之。

<a id="p60"></a>**〔60〕**　<sub>中華本頁 0229a</sub>　四年春正月丁亥，帝加元服，見于高廟。賜諸侯王、丞相、大將軍、列侯、宗室下至吏民金帛牛酒各有差。賜中二千石以下及天下民爵。毋收四年、五年口賦。三年以前逋更賦未入者，皆勿收。令天下酺五日。

<a id="p61"></a>**〔61〕**　<sub>中華本頁 0229a</sub>　甲戌，丞相千秋薨。

<a id="p62"></a>**〔62〕**　<sub>中華本頁 0229a</sub>　夏四月，詔曰：「度遼將軍明友前以羌騎校尉將羌王侯君長以下擊益州反虜，後復率擊武都反氐，今破烏桓，斬虜獲生，有功。其封明友為平陵侯。平樂監傅介子持節使，誅斬樓蘭王安，歸首縣北闕，封義陽侯。」

<a id="p63"></a>**〔63〕**　<sub>中華本頁 0229a</sub>　五月丁丑，孝文廟正殿火，上及羣臣皆素服。發中二千石將五校作治，六日成。太常及廟令丞郎吏皆劾大不敬，會赦，太常轑陽侯德免為庶人。

<a id="p64"></a>**〔64〕**　<sub>中華本頁 0231a</sub>　六月，赦天下。

<a id="p65"></a>**〔65〕**　<sub>中華本頁 0231a</sub>　五年春正月，廣陵王來朝，益國萬一千戶，賜錢二千萬，黃金二百斤，劍二，安車一，乘馬二駟。

<a id="p66"></a>**〔66〕**　<sub>中華本頁 0231a</sub>　夏，大旱。

<a id="p67"></a>**〔67〕**　<sub>中華本頁 0231a</sub>　六月，發三輔及郡國惡少年吏有告劾亡者，屯遼東。

<a id="p68"></a>**〔68〕**　<sub>中華本頁 0231a</sub>　秋，罷象郡，分屬鬱林、牂柯。

<a id="p69"></a>**〔69〕**　<sub>中華本頁 0231a</sub>　冬十一月，大雷。

<a id="p70"></a>**〔70〕**　<sub>中華本頁 0231a</sub>　十二月庚戌，丞相訢薨。

<a id="p71"></a>**〔71〕**　<sub>中華本頁 0231a</sub>　六年春正月，募郡國徒築遼東玄菟城。夏，赦天下。詔曰：「夫穀賤傷農，今三輔、太常穀減賤，其令以叔粟當今年賦。」

<a id="p72"></a>**〔72〕**　<sub>中華本頁 0231a</sub>　右將軍張安世宿衞忠謹，封富平侯。

<a id="p73"></a>**〔73〕**　<sub>中華本頁 0231a</sub>　烏桓復犯塞，遣度遼將軍范明友擊之。

<a id="p74"></a>**〔74〕**　<sub>中華本頁 0231a</sub>　元平元年春二月，詔曰：「天下以農桑為本。日者省用，罷不急官，減外繇，耕桑者益衆，而百姓未能家給，朕甚愍焉。其減口賦錢。」有司奏請減什三，上許之。

<a id="p75"></a>**〔75〕**　<sub>中華本頁 0231a</sub>　甲申，晨有流星，大如月，衆星皆隨西行。

<a id="p76"></a>**〔76〕**　<sub>中華本頁 0231a</sub>　夏四月癸未，帝崩于未央宮。六月壬申，葬平陵。

<a id="p77"></a>**〔77〕**　<sub>中華本頁 0233a</sub>　贊曰：昔周成以孺子繼統，而有管、蔡四國流言之變。孝昭幼年即位，亦有燕、盍、上官逆亂之謀。成王不疑周公，孝昭委任霍光，各因其時以成名，大矣哉！承孝武奢侈餘敝師旅之後，海內虛耗，戶口減半，光知時務之要，輕繇薄賦，與民休息。至始元、元鳳之間，匈奴和親，百姓充實。舉賢良文學，問民所疾苦，議鹽鐵而罷榷酤，尊號曰「昭」，不亦宜乎！
