# 漢書·卷10　成帝紀第十

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 0301a</sub>　成帝紀第十

<a id="p2"></a>**〔2〕**　<sub>中華本頁 0301a</sub>　孝成皇帝，元帝太子也。母曰王皇后，元帝在太子宮生甲觀畫堂，為世嫡皇孫。宣帝愛之，字曰太孫，常置左右。年三歲而宣帝崩，元帝即位，帝為太子。壯好經書，寬博謹慎。初居桂宮，上嘗急召，太子出龍樓門，不敢絕馳道，西至直城門，得絕乃度，還入作室門。上遲之，問其故，以狀對。上大說，乃著令，令太子得絕馳道云。其後幸酒，樂燕樂，上不以為能。而定陶恭王有材藝，母傅昭儀又愛幸，上以故常有意欲以恭王為嗣。賴侍中史丹護太子家，輔助有力，上亦以先帝尤愛太子，故得無廢。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 0301a</sub>　竟寧元年五月，元帝崩。六月己未，太子即皇帝位，謁高廟。尊皇太后曰太皇太后，皇后曰皇太后。以元舅侍中衞尉陽平侯王鳳為大司馬大將軍，領尚書事。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 0301a</sub>　乙未，有司言：「乘輿車、牛馬、禽獸皆非禮，不宜以葬。」奏可。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 0301a</sub>　七月，大赦天下。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 0301a</sub>　建始元年春正月乙丑，皇曾祖悼考廟災。

<a id="p7"></a>**〔7〕**　<sub>中華本頁 0301a</sub>　立故河間王弟上郡庫令良為王。

<a id="p8"></a>**〔8〕**　<sub>中華本頁 0301a</sub>　有星孛于營室。

<a id="p9"></a>**〔9〕**　<sub>中華本頁 0301a</sub>　罷上林詔獄。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 0301a</sub>　二月，右將軍長史姚尹等使匈奴還，去塞百餘里，暴風火發，燒殺尹等七人。

<a id="p11"></a>**〔11〕**　<sub>中華本頁 0301a</sub>　賜諸侯王、丞相、將軍、列侯、王太后、公主、王主、吏二千石黃金，宗室諸官吏千石以下至二百石及宗室子有屬籍者、三老、孝弟力田、[⿰魚眾]寡孤獨錢帛，各有差，吏民五十戶牛酒。

<a id="p12"></a>**〔12〕**　<sub>中華本頁 0301a</sub>　詔曰：「乃者火災降於祖廟，有星孛于東方，始正而虧，咎孰大焉！書云：『惟先假王正厥事。』羣公孜孜，帥先百寮，輔朕不逮。崇寬大，長和睦，凡事恕己，毋行苛刻。其大赦天下，使得自新。」

<a id="p13"></a>**〔13〕**　<sub>中華本頁 0301a</sub>　封舅諸吏光祿大夫關內侯王崇為安成侯。賜舅王譚、商、立、根、逢時爵關內侯。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 0301a</sub>　夏四月，黃霧四塞，博問公卿大夫，無有所諱。六月，有青蠅無萬數集未央宮殿中朝者坐。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 0301a</sub>　秋，罷上林宮館希御幸者二十五所。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 0301a</sub>　八月，有兩月相承，晨見東方。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 0301a</sub>　九月戊子，流星光燭地，長四五丈，委曲蛇形，貫紫宮。

<a id="p18"></a>**〔18〕**　<sub>中華本頁 0301a</sub>　十二月，作長安南北郊，罷甘泉、汾陰祠。是日大風，拔甘泉畤中大木十韋以上。郡國被災什四以上，毋收田租。

<a id="p19"></a>**〔19〕**　<sub>中華本頁 0305a</sub>　二年春正月，罷雍五畤。辛巳，上始郊祀長安南郊。詔曰：「乃者徙泰畤、后土于南郊、北郊，朕親飭躬，郊祀上帝。皇天報應，神光並見。三輔長無共張繇役之勞，赦奉郊縣長安、長陵及中都官耐罪徒。減天下賦錢，算四十。」

<a id="p20"></a>**〔20〕**　<sub>中華本頁 0305a</sub>　閏月，以渭城延陵亭部為初陵。

<a id="p21"></a>**〔21〕**　<sub>中華本頁 0305a</sub>　二月，詔三輔內郡舉賢良方正各一人。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 0305a</sub>　三月，北宮井水溢出。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 0306a</sub>　辛丑，上始祠后土于北郊。

<a id="p24"></a>**〔24〕**　<sub>中華本頁 0306a</sub>　丙午，立皇后許氏。

<a id="p25"></a>**〔25〕**　<sub>中華本頁 0306a</sub>　罷六、技巧官。

<a id="p26"></a>**〔26〕**　<sub>中華本頁 0306a</sub>　夏，大旱。

<a id="p27"></a>**〔27〕**　<sub>中華本頁 0306a</sub>　東平王宇有罪，削樊、亢父縣。

<a id="p28"></a>**〔28〕**　<sub>中華本頁 0306a</sub>　秋，罷太子博望苑，以賜宗室朝請者。減乘輿馬。

<a id="p29"></a>**〔29〕**　<sub>中華本頁 0306a</sub>　三年春三月，赦天下徒。賜孝弟力田爵二級。諸逋租賦所振貸勿收。

<a id="p30"></a>**〔30〕**　<sub>中華本頁 0306a</sub>　秋，關內大水。七月，虒上小女陳持弓聞大水至，走入橫城門，闌入尚方掖門，至未央宮鉤盾中。吏民驚上城。九月，詔曰：「乃者郡國被水災，流殺人民，多至千數。京師無故訛言大水至，吏民驚恐，奔走乘城。殆苛暴深刻之吏未息，元元冤失職者衆。遣諫大夫林等循行天下。」

<a id="p31"></a>**〔31〕**　<sub>中華本頁 0307a</sub>　冬十二月戊申朔，日有蝕之。夜，地震未央宮殿中。詔曰：「蓋聞天生衆民，不能相治，為之立君以統理之。君道得，則草木昆蟲咸得其所；人君不德，謫見天地，災異婁發，以告不治。朕涉道日寡，舉錯不中，乃戊申日蝕地震，朕甚懼焉。公卿其各思朕過失，明白陳之。『女無面從，退有後言。』丞相、御史與將軍、列侯、中二千石及內郡國舉賢良方正能直言極諫之士，詣公車，朕將覽焉。」

<a id="p32"></a>**〔32〕**　<sub>中華本頁 0307a</sub>　越嶲山崩。

<a id="p33"></a>**〔33〕**　<sub>中華本頁 0307a</sub>　四年春，罷中書宦官，初置尚書員五人。

<a id="p34"></a>**〔34〕**　<sub>中華本頁 0307a</sub>　夏四月，雨雪。

<a id="p35"></a>**〔35〕**　<sub>中華本頁 0307a</sub>　五月，中謁者丞陳臨殺司隸校尉轅豐於殿中。

<a id="p36"></a>**〔36〕**　<sub>中華本頁 0307a</sub>　秋，桃李實。大水，河決東郡金隄。冬十月，御史大夫尹忠以河決不憂職，自殺。

<a id="p37"></a>**〔37〕**　<sub>中華本頁 0309a</sub>　河平元年春三月，詔曰：「河決東郡，流漂二州，校尉王延世隄塞輒平，其改元為河平。賜天下吏民爵，各有差。」

<a id="p38"></a>**〔38〕**　<sub>中華本頁 0309a</sub>　夏四月己亥晦，日有蝕之，既。詔曰：「朕獲保宗廟，戰戰栗栗，未能奉稱。傳曰：『男教不修，陽事不得，則日為之蝕。』天著厥異，辜在朕躬。公卿大夫其勉悉心，以輔不逮。百寮各修其職，惇任仁人，退遠殘賊。陳朕過失，無有所諱。」大赦天下。

<a id="p39"></a>**〔39〕**　<sub>中華本頁 0309a</sub>　六月，罷典屬國并大鴻臚。

<a id="p40"></a>**〔40〕**　<sub>中華本頁 0309a</sub>　秋九月，復太上皇寢廟園。

<a id="p41"></a>**〔41〕**　<sub>中華本頁 0309a</sub>　二年春正月，沛郡鐵官冶鐵飛。語在五行志。

<a id="p42"></a>**〔42〕**　<sub>中華本頁 0310a</sub>　夏六月，封舅譚、商、立、根、逢時皆為列侯。

<a id="p43"></a>**〔43〕**　<sub>中華本頁 0310a</sub>　三年春二月丙戌，犍為地震山崩，雍江水，水逆流。

<a id="p44"></a>**〔44〕**　<sub>中華本頁 0310a</sub>　秋八月乙卯晦，日有蝕之。

<a id="p45"></a>**〔45〕**　<sub>中華本頁 0310a</sub>　光祿大夫劉向校中祕書。謁者陳農使，使求遺書於天下。

<a id="p46"></a>**〔46〕**　<sub>中華本頁 0310a</sub>　四年春正月，匈奴單于來朝。

<a id="p47"></a>**〔47〕**　<sub>中華本頁 0310a</sub>　赦天下徒，賜孝弟力田爵二級，諸逋租賦所振貸勿收。

<a id="p48"></a>**〔48〕**　<sub>中華本頁 0310a</sub>　二月，單于罷歸國。

<a id="p49"></a>**〔49〕**　<sub>中華本頁 0310a</sub>　三月癸丑朔，日有蝕之。

<a id="p50"></a>**〔50〕**　<sub>中華本頁 0310a</sub>　遣光祿大夫博士嘉等十一人行舉瀕河之郡水所毀傷困乏不能自存者，財振貸。其為水所流壓死，不能自葬，令郡國給槥櫝葬埋。已葬者與錢，人二千。避水它郡國，在所冗食之，謹遇以文理，無令失職。舉惇厚有行能直言之士。

<a id="p51"></a>**〔51〕**　<sub>中華本頁 0311a</sub>　壬申，長陵臨涇岸崩，雍涇水。

<a id="p52"></a>**〔52〕**　<sub>中華本頁 0311a</sub>　夏六月庚戌，楚王囂薨。

<a id="p53"></a>**〔53〕**　<sub>中華本頁 0311a</sub>　山陽火生石中，改元為陽朔。

<a id="p54"></a>**〔54〕**　<sub>中華本頁 0311a</sub>　陽朔元年。

<a id="p55"></a>**〔55〕**　<sub>中華本頁 0311a</sub>　春二月丁未晦，日有蝕之。

<a id="p56"></a>**〔56〕**　<sub>中華本頁 0312a</sub>　三月，赦天下徒。

<a id="p57"></a>**〔57〕**　<sub>中華本頁 0312a</sub>　冬，京兆尹王章有罪，下獄死。

<a id="p58"></a>**〔58〕**　<sub>中華本頁 0312a</sub>　二年春，寒。詔曰：「昔在帝堯立羲、和之官，命以四時之事，令不失其序。故書云『黎民於蕃時雍』，明以陰陽為本也。今公卿大夫或不信陰陽，薄而小之，所奏請多違時政。傳以不知，周行天下，而欲望陰陽和調，豈不謬哉！其務順四時月令。」

<a id="p59"></a>**〔59〕**　<sub>中華本頁 0312a</sub>　三月，大赦天下。

<a id="p60"></a>**〔60〕**　<sub>中華本頁 0312a</sub>　夏五月，除吏八百石、五百石秩。

<a id="p61"></a>**〔61〕**　<sub>中華本頁 0312a</sub>　秋，關東大水，流民欲入函谷、天井、壺口、五阮關者，勿苛留。遣諫大夫博士分行視。

<a id="p62"></a>**〔62〕**　<sub>中華本頁 0312a</sub>　八月甲申，定陶王康薨。

<a id="p63"></a>**〔63〕**　<sub>中華本頁 0312a</sub>　九月，奉使者不稱。詔曰：「古之立太學，將以傳先王之業，流化於天下也。儒林之官，四海淵原，宜皆明於古今，溫故知新，通達國體，故謂之博士。否則學者無述焉，為下所輕，非所以尊道德也。『工欲善其事，必先利其器。』丞相、御史其與中二千石、二千石雜舉可充博士位者，使卓然可觀。」

<a id="p64"></a>**〔64〕**　<sub>中華本頁 0312a</sub>　是歲，御史大夫張忠卒。

<a id="p65"></a>**〔65〕**　<sub>中華本頁 0312a</sub>　三年春三月壬戌，隕石東郡，八。

<a id="p66"></a>**〔66〕**　<sub>中華本頁 0312a</sub>　夏六月，潁川鐵官徒申屠聖等百八十人殺長吏，盜庫兵，自稱將軍，經歷九郡。遣丞相長史、御史中丞逐捕，以軍興從事，皆伏辜。

<a id="p67"></a>**〔67〕**　<sub>中華本頁 0312a</sub>　秋八月丁巳，大司馬大將軍王鳳薨。

<a id="p68"></a>**〔68〕**　<sub>中華本頁 0312a</sub>　四年春正月，詔曰：「夫洪範八政，以食為首，斯誠家給刑錯之本也。先帝劭農，薄其租稅，寵其彊力，令與孝弟同科。間者，民彌惰怠，鄉本者少，趨末者衆，將何以矯之？方東作時，其令二千石勉勸農桑，出入阡陌，致勞來之。書不云乎？『服田力嗇，乃亦有秋。』其勗之哉！」

<a id="p69"></a>**〔69〕**　<sub>中華本頁 0312a</sub>　二月，赦天下。

<a id="p70"></a>**〔70〕**　<sub>中華本頁 0312a</sub>　秋九月壬申，東平王宇薨。

<a id="p71"></a>**〔71〕**　<sub>中華本頁 0312a</sub>　閏月壬戌，御史大夫于永卒。

<a id="p72"></a>**〔72〕**　<sub>中華本頁 0312a</sub>　鴻嘉元年春二月，詔曰：「朕承天地，獲保宗廟，明有所蔽，德不能綏，刑罰不中，衆冤失職，趨闕告訴者不絕。是以陰陽錯謬，寒暑失序，日月不光，百姓蒙辜，朕甚閔焉。書不云乎？『即我御事，罔克耆壽，咎在厥躬。』方春生長時，臨遣諫大夫理等舉三輔、三河、弘農冤獄。公卿大夫、部刺史明申敕守相，稱朕意焉。其賜天下民爵一級，女子百戶牛酒，加賜[⿰魚眾]寡孤獨高年帛。逋貸未入者勿收。」

<a id="p73"></a>**〔73〕**　<sub>中華本頁 0316a</sub>　壬午，行幸初陵，赦作徒。以新豐戲鄉為昌陵縣，奉初陵，賜百戶牛酒。

<a id="p74"></a>**〔74〕**　<sub>中華本頁 0316a</sub>　上始為微行出。

<a id="p75"></a>**〔75〕**　<sub>中華本頁 0316a</sub>　冬，黃龍見真定。

<a id="p76"></a>**〔76〕**　<sub>中華本頁 0316a</sub>　二年春，行幸雲陽。

<a id="p77"></a>**〔77〕**　<sub>中華本頁 0316a</sub>　三月，博士行飲酒禮，有雉蜚集于庭，歷階升堂而雊，後集諸府，又集承明殿。

<a id="p78"></a>**〔78〕**　<sub>中華本頁 0317a</sub>　詔曰：「古之選賢，傅納以言，明試以功，故官無廢事，下無逸民，教化流行，風雨和時，百穀用成，衆庶樂業，咸以康寧。朕承鴻業十有餘年，數遭水旱疾疫之災，黎民婁困於飢寒，而望禮義之興，豈不難哉！朕既無以率道，帝王之道日以陵夷，意乃招賢選士之路鬱滯而不通與，將舉者未得其人也？其舉敦厚有行義能直言者，冀聞切言嘉謀，匡朕之不逮。」

<a id="p79"></a>**〔79〕**　<sub>中華本頁 0317a</sub>　夏，徙郡國豪傑貲五百萬以上五千戶于昌陵。賜丞相、御史、將軍、列侯、公主、中二千石冢地、第宅。

<a id="p80"></a>**〔80〕**　<sub>中華本頁 0318a</sub>　六月，立中山憲王孫雲客為廣德王。

<a id="p81"></a>**〔81〕**　<sub>中華本頁 0318a</sub>　三年夏四月，赦天下。令吏民得買爵，賈級千錢。

<a id="p82"></a>**〔82〕**　<sub>中華本頁 0318a</sub>　大旱。

<a id="p83"></a>**〔83〕**　<sub>中華本頁 0318a</sub>　秋八月乙卯，孝景廟闕災。

<a id="p84"></a>**〔84〕**　<sub>中華本頁 0318a</sub>　冬十一月甲寅，皇后許氏廢。

<a id="p85"></a>**〔85〕**　<sub>中華本頁 0318a</sub>　廣漢男子鄭躬等六十餘人攻官寺，篡囚徒，盜庫兵，自稱山君。

<a id="p86"></a>**〔86〕**　<sub>中華本頁 0318a</sub>　四年春正月，詔曰：「數敕有司，務行寬大，而禁苛暴，訖今不改。一人有辜，舉宗拘繫，農民失業，怨恨者衆，傷害和氣，水旱為災，關東流冗者衆，青、幽、冀部尤劇，朕甚痛焉。未聞在位有惻然者，孰當助朕憂之！已遣使者循行郡國。被災害什四以上，民貲不滿三萬，勿出租賦。逋貸未入，皆勿收。流民欲入關，輒籍內。所之郡國，謹遇以理，務有以全活之，思稱朕意。」

<a id="p87"></a>**〔87〕**　<sub>中華本頁 0319a</sub>　秋，勃海、清河河溢，被災者振貸之。

<a id="p88"></a>**〔88〕**　<sub>中華本頁 0319a</sub>　冬，廣漢鄭躬等黨與廣，犯歷四縣，衆且萬人。拜河東都尉趙護為廣漢太守，發郡中及蜀郡合三萬人擊之。或相捕斬，除罪。旬月平，遷護為執金吾，賜黃金百斤。

<a id="p89"></a>**〔89〕**　<sub>中華本頁 0319a</sub>　永始元年春正月癸丑，太官凌室火。戊午，戾后園闕火。

<a id="p90"></a>**〔90〕**　<sub>中華本頁 0319a</sub>　夏四月，封婕妤趙氏父臨為成陽侯。五月，封舅曼子侍中騎都尉光祿大夫王莽為新都侯。六月丙寅，立皇后趙氏。大赦天下。

<a id="p91"></a>**〔91〕**　<sub>中華本頁 0320a</sub>　秋七月，詔曰：「朕執德不固，謀不盡下，過聽將作大匠萬年言昌陵三年可成。作治五年，中陵、司馬殿門內尚未加功。天下虛耗，百姓罷勞，客土疏惡，終不可成。朕惟其難，怛然傷心。夫『過而不改，是謂過矣。』其罷昌陵，及故陵勿徙吏民，令天下毋有動搖之心。」立城陽孝王子俚為王。

<a id="p92"></a>**〔92〕**　<sub>中華本頁 0320a</sub>　八月丁丑，太皇太后王氏崩。

<a id="p93"></a>**〔93〕**　<sub>中華本頁 0321a</sub>　二年春正月己丑，大司馬車騎將軍王音薨。

<a id="p94"></a>**〔94〕**　<sub>中華本頁 0321a</sub>　二月癸未夜，星隕如雨。乙酉晦，日有蝕之。詔曰：「乃者，龍見于東萊，日有蝕之。天著變異，以顯朕郵，朕甚懼焉。公卿申敕百寮，深思天誡，有可省減便安百姓者，條奏。所振貸貧民，勿收。」又曰：「關東比歲不登，吏民以義收食貧民、入穀物助縣官振贍者，已賜直，其百萬以上，加賜爵右更，欲為吏補三百石，其吏也遷二等。三十萬以上，賜爵五大夫，吏亦遷二等，民補郎。十萬以上，家無出租賦三歲。萬錢以上，一年。」

<a id="p95"></a>**〔95〕**　<sub>中華本頁 0321a</sub>　冬十一月，行幸雍，祠五畤。

<a id="p96"></a>**〔96〕**　<sub>中華本頁 0321a</sub>　十二月，詔曰：「前將作大匠萬年知昌陵卑下，不可為萬歲居，奏請營作，建置郭邑，妄為巧詐，積土增高，多賦斂繇役，興卒暴之作。卒徒蒙辜，死者連屬，百姓罷極，天下匱竭。常侍閎前為大司農中丞，數奏昌陵不可成。侍中衞尉長數白宜早止，徙家反故處。朕以長言下閎章，公卿議者皆合長計。【長】首建至策，閎典主省大費，民以康寧。閎前賜爵關內侯，黃金百斤。其賜長爵關內侯，食邑千戶，閎五百戶。萬年佞邪不忠，毒流衆庶，海內怨望，至今不息，雖蒙赦令，不宜居京師。其徙萬年敦煌郡。」

<a id="p97"></a>**〔97〕**　<sub>中華本頁 0321a</sub>　是歲，御史大夫王駿卒。

<a id="p98"></a>**〔98〕**　<sub>中華本頁 0321a</sub>　三年春正月己卯晦，日有蝕之。詔曰：「天災仍重，朕甚懼焉。惟民之失職，臨遣大中大夫嘉等循行天下，存問耆老，民所疾苦。其與部刺史舉惇樸遜讓有行義者各一人。」

<a id="p99"></a>**〔99〕**　<sub>中華本頁 0321a</sub>　冬十月庚辰，皇太后詔有司復甘泉泰畤、汾陰后土、雍五畤、陳倉陳寶祠。語在郊祀志。

<a id="p100"></a>**〔100〕**　<sub>中華本頁 0321a</sub>　十一月，尉氏男子樊並等十三人謀反，殺陳留太守，劫略吏民，自稱將軍。徒李譚等五人共格殺並等，皆封為列侯。

<a id="p101"></a>**〔101〕**　<sub>中華本頁 0321a</sub>　十二月，山陽鐵官徒蘇令等二百二十八人攻殺長吏，盜庫兵，自稱將軍，經歷郡國十九，殺東郡太守、汝南都尉。遣丞相長史、御史中丞持節督趣逐捕。汝南太守嚴訢捕斬令等。遷訢為大司農，賜黃金百斤。

<a id="p102"></a>**〔102〕**　<sub>中華本頁 0324a</sub>　四年春正月，行幸甘泉，郊泰畤，神光降集紫殿。大赦天下。賜雲陽吏民爵，女子百戶牛酒，[⿰魚眾]寡孤獨高年帛。三月，行幸河東，祠后土，賜吏民如雲陽，行所過無出田租。

<a id="p103"></a>**〔103〕**　<sub>中華本頁 0324a</sub>　夏四月癸未，長樂臨華殿、未央宮東司馬門皆災。

<a id="p104"></a>**〔104〕**　<sub>中華本頁 0324a</sub>　六月甲午，霸陵園門闕災。出杜陵諸未嘗御者歸家。詔曰：「乃者，地震京師，火災婁降，朕甚懼之。有司其悉心明對厥咎，朕將親覽焉。」

<a id="p105"></a>**〔105〕**　<sub>中華本頁 0324a</sub>　又曰：「聖王明禮制以序尊卑，異車服以章有德，雖有其財，而無其尊，不得踰制，故民興行，上義而下利。方今世俗奢僭罔極，靡有厭足。公卿列侯親屬近臣，四方所則，未聞修身遵禮，同心憂國者也。或乃奢侈逸豫，務廣第宅，治園池，多畜奴婢，被服綺穀，設鐘鼓，備女樂，車服嫁娶葬埋過制。吏民慕效，以成俗，而欲望百姓儉節，家給人足，豈不難哉！詩不云乎？『赫赫師尹，民具爾瞻。』其申敕有司，以漸禁之。青綠民所常服，且勿止。列侯近臣，各自省改。司隸校尉察不變者。」

<a id="p106"></a>**〔106〕**　<sub>中華本頁 0325a</sub>　秋七月辛未晦，日有蝕之。

<a id="p107"></a>**〔107〕**　<sub>中華本頁 0325a</sub>　元延元年春正月己亥朔，日有蝕之。

<a id="p108"></a>**〔108〕**　<sub>中華本頁 0326a</sub>　三月，行幸雍，祠五畤。

<a id="p109"></a>**〔109〕**　<sub>中華本頁 0326a</sub>　夏四月丁酉，無雲有雷，聲光耀耀，四面下至地，昏止。赦天下。

<a id="p110"></a>**〔110〕**　<sub>中華本頁 0326a</sub>　秋七月，有星孛于東井。詔曰：「乃者，日蝕星隕，謫見于天，大異重仍。在位默然，罕有忠言。今孛星見于東井，朕甚懼焉。公卿大夫、博士、議郎其各悉心，惟思變意，明以經對，無有所諱；與內郡國舉方正能直言極諫者各一人，北邊二十二郡舉勇猛知兵法者各一人。」

<a id="p111"></a>**〔111〕**　<sub>中華本頁 0326a</sub>　封蕭相國後喜為酇侯。

<a id="p112"></a>**〔112〕**　<sub>中華本頁 0326a</sub>　冬十二月辛亥，大司馬大將軍王商薨。

<a id="p113"></a>**〔113〕**　<sub>中華本頁 0326a</sub>　是歲，昭儀趙氏害後宮皇子。

<a id="p114"></a>**〔114〕**　<sub>中華本頁 0326a</sub>　二年春正月，行幸甘泉，郊泰畤。

<a id="p115"></a>**〔115〕**　<sub>中華本頁 0326a</sub>　三月，行幸河東，祠后土。

<a id="p116"></a>**〔116〕**　<sub>中華本頁 0327a</sub>　夏四月，立廣陵孝王子守為王。

<a id="p117"></a>**〔117〕**　<sub>中華本頁 0327a</sub>　冬，行幸長楊宮，從胡客大校獵。宿萯陽宮，賜從官。

<a id="p118"></a>**〔118〕**　<sub>中華本頁 0327a</sub>　三年春正月丙寅，蜀郡岷山崩，雍江三日，江水竭。

<a id="p119"></a>**〔119〕**　<sub>中華本頁 0327a</sub>　二月，封侍中衞尉淳于長為定陵侯。

<a id="p120"></a>**〔120〕**　<sub>中華本頁 0327a</sub>　三月，行幸雍，祠五畤。

<a id="p121"></a>**〔121〕**　<sub>中華本頁 0327a</sub>　四年春正月，行幸甘泉，郊泰畤。

<a id="p122"></a>**〔122〕**　<sub>中華本頁 0327a</sub>　二月，罷司隸校尉官。

<a id="p123"></a>**〔123〕**　<sub>中華本頁 0327a</sub>　三月，行幸河東，祠后土。

<a id="p124"></a>**〔124〕**　<sub>中華本頁 0328a</sub>　甘露降京師，賜長安民牛酒。

<a id="p125"></a>**〔125〕**　<sub>中華本頁 0328a</sub>　綏和元年春正月，大赦天下。

<a id="p126"></a>**〔126〕**　<sub>中華本頁 0328a</sub>　二月癸丑，詔曰：「朕承太祖鴻業，奉宗廟二十五年，德不能綏理宇內，百姓怨望者衆。不蒙天祐，至今未有繼嗣，天下無所係心。觀于往古近事之戒，禍亂之萌，皆由斯焉。定陶王欣於朕為子，慈仁孝順，可以承天序，繼祭祀。其立欣為皇太子。封中山王舅諫大夫馮參為宜鄉侯，益中山國三萬戶，以慰其意。賜諸侯王、列侯金，天下當為父後者爵，三老、孝弟力田帛，各有差。」

<a id="p127"></a>**〔127〕**　<sub>中華本頁 0328a</sub>　又曰：「蓋聞王者必存二王之後，所以通三統也。昔成湯受命，列為三代，而祭祀廢絕。考求其後，莫正孔吉。其封吉為殷紹嘉侯。」三月，進爵為公，及周承休侯皆為公，地各百里。

<a id="p128"></a>**〔128〕**　<sub>中華本頁 0328a</sub>　行幸雍，祠五畤。

<a id="p129"></a>**〔129〕**　<sub>中華本頁 0328a</sub>　夏四月，以大司馬票騎（(大)）將軍（(根)）為大司馬，罷將軍官。御史大夫為大司空，封為列侯。益大司馬、大司空奉如丞相。

<a id="p130"></a>**〔130〕**　<sub>中華本頁 0328a</sub>　秋八月庚戌，中山王興薨。

<a id="p131"></a>**〔131〕**　<sub>中華本頁 0328a</sub>　冬十一月，立楚孝王孫景為定陶王。

<a id="p132"></a>**〔132〕**　<sub>中華本頁 0328a</sub>　定陵侯淳于長大逆不道，下獄死。廷尉孔光使持節賜貴人許氏藥，飲藥死。

<a id="p133"></a>**〔133〕**　<sub>中華本頁 0328a</sub>　十二月，罷部刺史，更置州牧，秩二千石。

<a id="p134"></a>**〔134〕**　<sub>中華本頁 0328a</sub>　二年春正月，行幸甘泉，郊泰畤。

<a id="p135"></a>**〔135〕**　<sub>中華本頁 0328a</sub>　二月壬子，丞相翟方進薨。

<a id="p136"></a>**〔136〕**　<sub>中華本頁 0328a</sub>　三月，行幸河東，祠后土。

<a id="p137"></a>**〔137〕**　<sub>中華本頁 0330a</sub>　丙戌，帝崩于未央宮。皇太后詔有司復長安南北郊。四月己卯，葬延陵。

<a id="p138"></a>**〔138〕**　<sub>中華本頁 0330a</sub>　贊曰：臣之姑充後宮為婕妤，父子昆弟侍帷幄，數為臣言成帝善修容儀，升車正立，不內顧，不疾言，不親指，臨朝淵嘿，尊嚴若神，可謂穆穆天子之容者矣！博覽古今，容受直辭。公卿稱職，奏議可述。遭世承平，上下和睦。然湛于酒色，趙氏亂內，外家擅朝，言之可為於邑。建始以來，王氏始執國命，哀、平短祚，莽遂篡位，蓋其威福所由來者漸矣！
