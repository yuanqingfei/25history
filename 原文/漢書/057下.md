# 漢書·卷57下　司馬相如傳第二十七下

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 2577a</sub>　司馬相如傳第二十七下

<a id="p2"></a>**〔2〕**　<sub>中華本頁 2577a</sub>　相如為郎數歲，會唐蒙使略通夜郎、僰中，發巴蜀吏卒千人，郡又多為發轉漕萬餘人，用軍興法誅其渠率。巴蜀民大驚恐。上聞之，乃遣相如責唐蒙等，因諭告巴蜀民以非上意。檄曰：

<a id="p3"></a>**〔3〕**　<sub>中華本頁 2577a</sub>　下，集安中國，然後興師出兵，北征匈奴，單于怖駭，交臂受事，屈膝請和。康居西

<a id="p4"></a>**〔4〕**　<sub>中華本頁 2577a</sub>　域，重譯納貢，稽首來享。移師東指，閩越相誅；右弔番禺，太子入朝。南夷之

<a id="p5"></a>**〔5〕**　<sub>中華本頁 2577a</sub>　君，西僰之長，常效貢職，不敢惰怠，延頸舉踵，喁喁然，皆鄉風慕義，欲為臣妾，

<a id="p6"></a>**〔6〕**　<sub>中華本頁 2577a</sub>　道里遼遠，山川阻深，不能自致。夫不順者已誅，而為善者未賞，故遣中郎將往賓

<a id="p7"></a>**〔7〕**　<sub>中華本頁 2578a</sub>　之，發巴蜀之士各五百人以奉幣，衞使者不然，靡有兵革之事，戰鬬之患。今聞其

<a id="p8"></a>**〔8〕**　<sub>中華本頁 2578a</sub>　乃發軍興制，驚懼子弟，憂患長老，郡又擅為轉粟運輸，皆非陛下之意也。當行者

<a id="p9"></a>**〔9〕**　<sub>中華本頁 2578a</sub>　或亡逃自賊殺，亦非人臣之節也。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 2578a</sub>　後，觸白刃，冒流矢，議不反顧，計不旋踵，人懷怒心，如報私讐。彼豈樂死惡

<a id="p11"></a>**〔11〕**　<sub>中華本頁 2578a</sub>　生，非編列之民，而與巴蜀異主哉？計深慮遠，急國家之難，而樂盡人臣之道也。故

<a id="p12"></a>**〔12〕**　<sub>中華本頁 2578a</sub>　有剖符之封，析圭而爵，位為通侯，居列東第。終則遺顯號於後世，傳土地於子

<a id="p13"></a>**〔13〕**　<sub>中華本頁 2579a</sub>　孫，事行甚忠敬，居位甚安佚，名聲施於無窮，功（(業)）【烈】著而不滅。是以賢人君子。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 2579a</sub>　肝腦塗中原，膏液潤埜屮而不辭也。今奉幣使至南夷，即自賊殺，或亡逃抵誅，

<a id="p15"></a>**〔15〕**　<sub>中華本頁 2579a</sub>　身死無名，諡為至愚，恥及父母，為天下笑。人之度量相越，豈不遠哉！然此非

<a id="p16"></a>**〔16〕**　<sub>中華本頁 2579a</sub>　獨行者之罪也，父兄之教不先，子弟之率不謹，寡廉鮮恥，而俗不長厚也。其被

<a id="p17"></a>**〔17〕**　<sub>中華本頁 2579a</sub>　刑戮，不亦宜乎！

<a id="p18"></a>**〔18〕**　<sub>中華本頁 2579a</sub>　事，因數之以不忠死亡之罪，讓三老孝弟以不教誨之過。方今田時，重煩百

<a id="p19"></a>**〔19〕**　<sub>中華本頁 2579a</sub>　姓，已親見近縣，恐遠所谿谷山澤之民不徧聞，檄到，亟下縣道，咸喻陛下

<a id="p20"></a>**〔20〕**　<sub>中華本頁 2579a</sub>　意，毋忽！

<a id="p21"></a>**〔21〕**　<sub>中華本頁 2579a</sub>　相如還報。唐蒙已略通夜郎，因通西南夷道，發巴蜀廣漢卒，作者數萬人。治道二歲，道不成，士卒多物故，費以億萬計。蜀民及漢用事者多言其不便。是時卭、莋之君長聞南夷與漢通，得賞賜多，多欲願為內臣妾，請吏，比南夷。上問相如，相如曰：「卭、莋、冉、駹者近蜀，道易通，異時嘗通為郡縣矣，至漢興而罷。今誠復通，為置縣，愈於南夷。」上以為然，乃拜相如為中郎將，建節往使。副使者王然于、壺充國、呂越人，馳四乘之傳，因巴蜀吏幣物以賂西南夷。至蜀，太守以下郊迎，縣令負弩矢先驅，蜀人以為寵。於是卓王孫、臨卭諸公皆因門下獻牛酒以交驩。卓王孫喟然而歎，自以得使女尚司馬長卿晚，乃厚分與其女財，與男等。相如使略定西南夷，卭、莋、冉、駹、斯榆之君皆請為臣妾，除邊關，【邊關】益斥，西至沬、若水，南至牂牁為徼，通靈山道，橋孫水，以通卭、莋。還報，天子大說。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 2581a</sub>　相如使時，蜀長老多言通西南夷之不為用，大臣亦以為然。相如欲諫，業已建之，不敢，乃著書，藉蜀父老為辭，而己詰難之，以風天子，且因宣其使（(詣)）【指】，令百姓皆知天子意。其辭曰：

<a id="p23"></a>**〔23〕**　<sub>中華本頁 2581a</sub>　外。於是乃命使西征，隨流而攘，風之所被，罔不披靡。因朝冉從駹，定莋存

<a id="p24"></a>**〔24〕**　<sub>中華本頁 2581a</sub>　卭，略斯榆，舉苞蒲，結軌還轅，東鄉將報，至于蜀都。

<a id="p25"></a>**〔25〕**　<sub>中華本頁 2581a</sub>　於夷狄也，其義羈縻勿絕而已。今罷三郡之士，通夜郎之塗，三年於茲，而功不

<a id="p26"></a>**〔26〕**　<sub>中華本頁 2581a</sub>　竟，士卒勞倦，萬民不贍；今又接之以西夷，百姓力屈，恐不能卒業，此亦使者之累

<a id="p27"></a>**〔27〕**　<sub>中華本頁 2581a</sub>　也，竊為左右患之。且夫卭、莋、西僰之與中國並也，歷年茲多，不可記已。仁者

<a id="p28"></a>**〔28〕**　<sub>中華本頁 2581a</sub>　不以德來，強者不以力并，意者殆不可乎！今割齊民以附夷狄，弊所恃以事無

<a id="p29"></a>**〔29〕**　<sub>中華本頁 2581a</sub>　用，鄙人固陋，不識所謂。」

<a id="p30"></a>**〔30〕**　<sub>中華本頁 2581a</sub>　說。然斯事體大，固非觀者之所覯也。余之行急，其詳不可得聞已。請為大夫

<a id="p31"></a>**〔31〕**　<sub>中華本頁 2581a</sub>　粗陳其略：

<a id="p32"></a>**〔32〕**　<sub>中華本頁 2581a</sub>　固常人之所異也。故曰非常之元，黎民懼焉；及臻厥成，天下晏如也。

<a id="p33"></a>**〔33〕**　<sub>中華本頁 2585a</sub>　原，決江疏河，灑沈澹災，東歸之於海，而天下永寧。當斯之勤，豈惟民哉？心

<a id="p34"></a>**〔34〕**　<sub>中華本頁 2585a</sub>　煩於慮，而身親其勞，躬傶骿胝無胈，膚不生毛，故休烈顯乎無窮，聲稱浹乎于

<a id="p35"></a>**〔35〕**　<sub>中華本頁 2585a</sub>　茲。

<a id="p36"></a>**〔36〕**　<sub>中華本頁 2585a</sub>　哉！必將崇論谹議，創業垂統，為萬世規。故馳騖乎兼容并包，而勤思乎參天貳

<a id="p37"></a>**〔37〕**　<sub>中華本頁 2585a</sub>　地。且詩不云乎？『普天之下，莫非王土；率土之濱，莫非王臣。』是以六合之

<a id="p38"></a>**〔38〕**　<sub>中華本頁 2585a</sub>　內，八方之外，浸淫衍溢，懷生之物有不浸潤於澤者，賢君恥之。今封疆之內，

<a id="p39"></a>**〔39〕**　<sub>中華本頁 2586a</sub>　冠帶之倫，咸獲嘉祉，靡有闕遺矣。而夷狄殊俗之國，遼絕異黨之域，舟車不通，

<a id="p40"></a>**〔40〕**　<sub>中華本頁 2586a</sub>　人迹至，政教未加，流風猶微，內之則犯義侵禮於邊境，外之則邪行橫作，放殺其

<a id="p41"></a>**〔41〕**　<sub>中華本頁 2586a</sub>　上，君臣易位，尊卑失序，父兄不辜，幼孤為奴虜，係絫號泣。內鄉而怨，曰：

<a id="p42"></a>**〔42〕**　<sub>中華本頁 2586a</sub>　『蓋聞中國有至仁焉，德洋恩普，物靡不得其所，今獨曷為遺己！』舉踵思慕，若

<a id="p43"></a>**〔43〕**　<sub>中華本頁 2586a</sub>　枯旱之望雨，盭夫為之垂涕，況乎上聖，又烏能已？故北出師以討強胡，南馳使

<a id="p44"></a>**〔44〕**　<sub>中華本頁 2586a</sub>　以誚勁越。四面風德，二方之君鱗集仰流，願得受號者以億計。故乃關

<a id="p45"></a>**〔45〕**　<sub>中華本頁 2586a</sub>　沬、若，徼牂牁，鏤靈山，梁孫原，創道德之塗，垂仁義之統，將博恩廣施，遠撫長

<a id="p46"></a>**〔46〕**　<sub>中華本頁 2586a</sub>　駕，使疏逖不閉，曶爽闇昧得燿乎光明，以偃甲兵於此，而息討伐於彼。遐

<a id="p47"></a>**〔47〕**　<sub>中華本頁 2586a</sub>　邇一體，中外禔福，不亦康乎？夫拯民於沈溺，奉至尊之休德，反衰世之陵

<a id="p48"></a>**〔48〕**　<sub>中華本頁 2586a</sub>　夷，繼周氏之絕業，天子之急務也。百姓雖勞，又惡可以已哉？

<a id="p49"></a>**〔49〕**　<sub>中華本頁 2586a</sub>　方將增太山之封，加梁父之事，鳴和鸞，揚樂頌，上咸五，下登三。觀者未覩指，聽者

<a id="p50"></a>**〔50〕**　<sub>中華本頁 2586a</sub>　未聞音，猶焦朋已翔乎寥廓，而羅者猶視乎藪澤，悲夫！」

<a id="p51"></a>**〔51〕**　<sub>中華本頁 2586a</sub>　鄙人之所願聞也。百姓雖勞，請以身先之。」敞罔靡徙，遷延而辭避。

<a id="p52"></a>**〔52〕**　<sub>中華本頁 2586a</sub>　其後人有上書言相如使時受金，失官。居歲餘，復召為郎。

<a id="p53"></a>**〔53〕**　<sub>中華本頁 2586a</sub>　相如口吃而善著書。常有消渴病。與卓氏婚，饒於財。故其仕宦，未嘗肯與公卿國家之事，常稱疾閒居，不慕官爵。嘗從上至長楊獵。是時天子方好自擊熊豕，馳逐壄獸，相如因上疏諫。其辭曰：

<a id="p54"></a>**〔54〕**　<sub>中華本頁 2586a</sub>　為人誠有之，獸亦宜然。今陛下好陵阻險，射猛獸，卒然遇逸材之獸，駭不存之地，

<a id="p55"></a>**〔55〕**　<sub>中華本頁 2586a</sub>　犯屬車之清塵，輿不及還轅，人不暇施巧，雖有烏獲、逢蒙之技不能用，枯木朽

<a id="p56"></a>**〔56〕**　<sub>中華本頁 2590a</sub>　株盡為難矣。是胡越起於轂下，而羌夷接軫也，豈不殆哉！雖萬全而無患，然本非

<a id="p57"></a>**〔57〕**　<sub>中華本頁 2590a</sub>　天子之所宜近也。

<a id="p58"></a>**〔58〕**　<sub>中華本頁 2590a</sub>　利獸之樂，而內無存變之意，其為害也不【亦】難矣！夫輕萬乘之重不以為安，樂出萬

<a id="p59"></a>**〔59〕**　<sub>中華本頁 2590a</sub>　有一危之塗以為娛，臣竊為陛下不取。

<a id="p60"></a>**〔60〕**　<sub>中華本頁 2590a</sub>　也。故鄙諺曰：「家絫千金，坐不垂堂。」此言雖小，可以諭大。臣願陛下留意幸察。

<a id="p61"></a>**〔61〕**　<sub>中華本頁 2590a</sub>　深山之谾谾兮，通谷乎{GJ-F9E8}。汨淢靸以永逝兮，注平皋之廣衍。觀衆樹之蓊薆

<a id="p62"></a>**〔62〕**　<sub>中華本頁 2590a</sub>　兮，覽竹林之榛榛。東馳土山兮，北揭石瀨。弭節容與兮，歷弔二世。持身不謹

<a id="p63"></a>**〔63〕**　<sub>中華本頁 2590a</sub>　兮，亡國失勢；信讒不寤兮，宗廟滅絕。烏乎！操行之不得，墓蕪穢而不修兮，

<a id="p64"></a>**〔64〕**　<sub>中華本頁 2590a</sub>　魂亡歸而不食。

<a id="p65"></a>**〔65〕**　<sub>中華本頁 2590a</sub>　相如拜為孝文園令。上既美子虛之事，相如見上好僊，因曰：「上林之事未足美也，尚有靡者。臣嘗為大人賦，未就，請具而奏之。」相如以為列僊之儒居山澤間，形容甚臞，此非帝王之僊意也，乃遂奏大人賦。其辭曰：

<a id="p66"></a>**〔66〕**　<sub>中華本頁 2590a</sub>　輕舉而遠游。乘絳幡之素蜺兮，載雲氣而上浮。建格澤之修竿兮，總光燿之

<a id="p67"></a>**〔67〕**　<sub>中華本頁 2590a</sub>　采旄。垂旬始以為幓兮，曳彗星而為髾。掉指橋以偃寋兮，又猗抳以招

<a id="p68"></a>**〔68〕**　<sub>中華本頁 2590a</sub>　搖。㖿攙搶以為旌兮，靡屈虹而為綢。紅杳眇以玄湣兮，猋風涌而雲浮。駕應

<a id="p69"></a>**〔69〕**　<sub>中華本頁 2593a</sub>　龍象輿之蠖略委麗兮，驂赤螭青虬之蚴蟉宛蜒。低卬夭蟜裾以驕驁兮，詘折隆窮

<a id="p70"></a>**〔70〕**　<sub>中華本頁 2593a</sub>　躩以連卷。沛艾赳螑仡以佁儗兮，放散畔岸驤以孱顏。跮踱輵螛容以骫麗

<a id="p71"></a>**〔71〕**　<sub>中華本頁 2593a</sub>　兮，蜩蟉偃寋怵[⿻奐比]以梁倚。糾蓼叫奡踏以{GJ-F9E6}路兮，薎蒙踊躍騰而狂趭。莅

<a id="p72"></a>**〔72〕**　<sub>中華本頁 2593a</sub>　颯芔歙焱至電過兮，煥然霧除，霍然雲消。

<a id="p73"></a>**〔73〕**　<sub>中華本頁 2593a</sub>　東。悉徵靈圉而選之兮，部署衆神於搖光。使五帝先導兮，反大壹而從陵陽。

<a id="p74"></a>**〔74〕**　<sub>中華本頁 2593a</sub>　左玄冥而右黔雷兮，前長離而後矞皇。廝征伯僑而役羨門兮，詔岐伯使尚

<a id="p75"></a>**〔75〕**　<sub>中華本頁 2593a</sub>　方。祝融警而蹕御兮，清氣氛而后行。屯余車而萬乘兮，綷雲蓋而樹華旗。使

<a id="p76"></a>**〔76〕**　<sub>中華本頁 2593a</sub>　句芒其將行兮，吾欲往乎南娭。

<a id="p77"></a>**〔77〕**　<sub>中華本頁 2593a</sub>　衝蓯其（(相)）紛挐兮，滂濞泱軋麗以林離。攢羅列聚叢以蘢茸兮，衍曼流爛痑以陸

<a id="p78"></a>**〔78〕**　<sub>中華本頁 2593a</sub>　離。徑入雷室之砰磷鬱律兮，洞出鬼谷之堀礨崴魁。徧覽八紘而觀四海兮，朅度

<a id="p79"></a>**〔79〕**　<sub>中華本頁 2593a</sub>　九江越五河。經營炎火而浮弱水兮，杭絕浮渚涉流沙。奄息葱極氾濫水娭兮，

<a id="p80"></a>**〔80〕**　<sub>中華本頁 2593a</sub>　使靈媧鼓琴而舞馮夷。時若曖曖將混濁兮，召屏翳誅風伯，刑雨師。西望崑崙之

<a id="p81"></a>**〔81〕**　<sub>中華本頁 2593a</sub>　軋沕荒忽兮，直徑馳乎三危。排閶闔而入帝宮兮，載玉女而與之歸。登閬風

<a id="p82"></a>**〔82〕**　<sub>中華本頁 2593a</sub>　而遙集兮，亢鳥騰而壹止。低徊陰山翔以紆曲兮，吾乃今日覩西王母。暠然白首戴

<a id="p83"></a>**〔83〕**　<sub>中華本頁 2593a</sub>　勝而穴處兮，亦幸有三足烏為之使。必長生若此而不死兮，雖濟萬世不足以喜。

<a id="p84"></a>**〔84〕**　<sub>中華本頁 2593a</sub>　華。僸祲尋而高縱兮，紛鴻溶而上厲。貫列缺之倒景兮，涉豐隆之滂濞。

<a id="p85"></a>**〔85〕**　<sub>中華本頁 2593a</sub>　騁游道而脩降兮，騖遺霧而遠逝。迫區中之隘陝兮，舒節出乎北垠。遺屯騎於玄

<a id="p86"></a>**〔86〕**　<sub>中華本頁 2593a</sub>　闕兮，軼先驅於寒門。下崢嶸而無地兮，上嵺廓而無天。視眩泯而亡見

<a id="p87"></a>**〔87〕**　<sub>中華本頁 2593a</sub>　兮，聽敞怳而亡聞。乘虛亡而上遐兮，超無友而獨存。

<a id="p88"></a>**〔88〕**　<sub>中華本頁 2593a</sub>　相如既奏大人賦，天子大說，飄飄有陵雲氣游天地之閒意。

<a id="p89"></a>**〔89〕**　<sub>中華本頁 2593a</sub>　相如既病免，家居茂陵。天子曰：「司馬相如病甚，可往從悉取其書，若後之矣。」使所忠往，而相如已死，家無遺書。問其妻，對曰：「長卿未嘗有書也。時時著書，人又取去。長卿未死時，為一卷書，曰有使來求書，奏之。」其遺札書言封禪事，所忠奏焉，天子異之。其辭曰：

<a id="p90"></a>**〔90〕**　<sub>中華本頁 2593a</sub>　聲。紛輪威蕤，堙滅而不稱者，不可勝數也。繼昭夏，崇號諡，略可道者七十有二

<a id="p91"></a>**〔91〕**　<sub>中華本頁 2593a</sub>　君。罔若淑而不昌，疇逆失而能存？

<a id="p92"></a>**〔92〕**　<sub>中華本頁 2593a</sub>　書曰：「元首明哉！股肱良哉！」因斯以談，君莫盛於堯，臣莫賢於后稷。后稷創業

<a id="p93"></a>**〔93〕**　<sub>中華本頁 2593a</sub>　於唐，公劉發迹於西戎，文王改制，爰周郅隆，大行越成，而后陵夷衰微，千載亡聲，

<a id="p94"></a>**〔94〕**　<sub>中華本頁 2593a</sub>　豈不善始善終哉！然無異端，慎所由於前，謹遺教於後耳。故軌迹夷易，易遵

<a id="p95"></a>**〔95〕**　<sub>中華本頁 2593a</sub>　也；湛恩厖洪，易豐也；憲度著明，易則也；垂統理順，易繼也。是以業隆

<a id="p96"></a>**〔96〕**　<sub>中華本頁 2593a</sub>　於繈保而崇冠乎二后。揆厥所元，終都攸卒，未有殊尤絕迹可考於今者也。

<a id="p97"></a>**〔97〕**　<sub>中華本頁 2593a</sub>　然猶躡梁甫，登大山，建顯號，施尊名。大漢之德，逢涌原泉，沕潏曼羨，旁魄四塞，

<a id="p98"></a>**〔98〕**　<sub>中華本頁 2593a</sub>　雲布霧散，上暢九垓，下泝八埏。懷生之類，沾濡浸潤，協氣橫流，武節焱逝，

<a id="p99"></a>**〔99〕**　<sub>中華本頁 2593a</sub>　爾游原，䄄闊泳末，首惡鬱沒，闇昧昭晰，昆蟲闓懌，回首面內。然后囿騶

<a id="p100"></a>**〔100〕**　<sub>中華本頁 2602a</sub>　虞之珍羣，徼麋鹿之怪獸，導一莖六穗於庖，犧雙觡共抵之獸，獲周餘放龜

<a id="p101"></a>**〔101〕**　<sub>中華本頁 2602a</sub>　于岐，招翠黃乘龍於沼。鬼神接靈圉，賓於閒館。奇物譎詭，俶儻窮變。欽

<a id="p102"></a>**〔102〕**　<sub>中華本頁 2602a</sub>　哉，符瑞臻茲，猶以為薄，不敢道封禪。蓋周躍魚隕杭，休之以燎。微夫斯之為符

<a id="p103"></a>**〔103〕**　<sub>中華本頁 2602a</sub>　也，以登介丘，不亦恧乎！進攘之道，何其爽與？

<a id="p104"></a>**〔104〕**　<sub>中華本頁 2602a</sub>　牟往初，功無與二，休烈液洽，符瑞衆變，期應紹至，不特創見。意者太山、梁父

<a id="p105"></a>**〔105〕**　<sub>中華本頁 2602a</sub>　設壇場望幸，蓋號以況榮，上帝垂恩儲祉，將以慶成，陛下嗛讓而弗發也。挈

<a id="p106"></a>**〔106〕**　<sub>中華本頁 2602a</sub>　三神之歡，缺王道之儀，羣臣恧焉。或謂且天為質闇，示珍符固不可辭；若

<a id="p107"></a>**〔107〕**　<sub>中華本頁 2602a</sub>　然辭之，是泰山靡記而梁父罔幾也。亦各並時而榮，咸濟厥世而屈，說者尚何稱於

<a id="p108"></a>**〔108〕**　<sub>中華本頁 2602a</sub>　後，而云七十二君哉？夫修德以錫符，奉符以行事，不為進越也。故聖王弗替，

<a id="p109"></a>**〔109〕**　<sub>中華本頁 2602a</sub>　而修禮地祇，謁款天神，勒功中岳，以章至尊，舒盛德，發號榮，受厚福，以

<a id="p110"></a>**〔110〕**　<sub>中華本頁 2605a</sub>　浸黎民。皇皇哉斯事，天下之壯觀，王者之卒業，不可貶也。願陛下全之。而后

<a id="p111"></a>**〔111〕**　<sub>中華本頁 2605a</sub>　因雜縉紳先生之略術，使獲曜日月之末光絕炎，以展采錯事。猶兼正列其義，祓飾

<a id="p112"></a>**〔112〕**　<sub>中華本頁 2605a</sub>　厥文，作春秋一藝。將襲舊六為七，攄之無窮，俾萬世得激清流，揚微波，蜚英

<a id="p113"></a>**〔113〕**　<sub>中華本頁 2605a</sub>　聲，騰茂實。前聖之所以永保鴻名而常為稱首者用此。宜命掌故悉奏其儀而覽

<a id="p114"></a>**〔114〕**　<sub>中華本頁 2605a</sub>　焉。」

<a id="p115"></a>**〔115〕**　<sub>中華本頁 2605a</sub>　之事，詩大澤之博，廣符瑞之富。遂作頌曰：

<a id="p117"></a>**〔117〕**　<sub>中華本頁 2607a</sub>　也。

<a id="p118"></a>**〔118〕**　<sub>中華本頁 2607a</sub>　相如既卒五歲，上始祭后土。八年而遂禮中岳，封于太山，至梁甫，禪肅然。

<a id="p119"></a>**〔119〕**　<sub>中華本頁 2607a</sub>　相如它所著，苦遺平陵侯書、與五公子相難、屮木書篇，不采，采其尤著公卿者云。

<a id="p120"></a>**〔120〕**　<sub>中華本頁 2607a</sub>　贊曰：司馬遷稱「春秋推見至隱，易本隱以之顯，大雅言王公大人，而德逮黎庶，小雅譏小己之得失，其流及上。所言雖殊，其合德一也。相如雖多虛辭濫說，然要其歸引之於節儉，此亦詩之風諫何異？」揚雄以為靡麗之賦，勸百而風一，猶騁鄭衞之聲，曲終而奏雅，不已戲乎！
