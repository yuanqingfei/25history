# 漢書·卷64下　漢書卷六十四下

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 2809a</sub>　嚴朱吾丘主父徐嚴終王賈傳第三十四下師古曰：「此卷首尚載嚴、朱、吾丘、主父、徐者，存其本書題目，以示不變易也。」

<a id="p2"></a>**〔2〕**　<sub>中華本頁 2809a</sub>　嚴安者，臨菑人也。以故丞相史上書，曰：臣聞鄒（(衍)）【子】曰：「政教文質者，所以云救也，當時則用，過則舍之，有

<a id="p3"></a>**〔3〕**　<sub>中華本頁 2809a</sub>　易則易（(也)）【之】，故守一而不變者，未睹治之至也。」今天下人民用財侈靡，車馬衣

<a id="p4"></a>**〔4〕**　<sub>中華本頁 2809a</sub>　裘宮室皆競修飾，調五聲使有節族，雜五色使有文章，重五味方丈於前，以觀欲天

<a id="p5"></a>**〔5〕**　<sub>中華本頁 2809a</sub>　下。彼民之情，見美則願之，是教民以侈也。侈而無節，則不可贍，民離本而徼

<a id="p6"></a>**〔6〕**　<sub>中華本頁 2809a</sub>　末矣。末不可徒得，故搢紳者不憚為詐，帶劍者夸殺人以矯奪，而世不知媿，

<a id="p7"></a>**〔7〕**　<sub>中華本頁 2809a</sub>　故姦軌浸長。夫佳麗珍怪固順於耳目，故養失而泰，樂失而淫，禮失而采，教失

<a id="p8"></a>**〔8〕**　<sub>中華本頁 2809a</sub>　而偽。偽、采、淫、泰，非所以範民之道也。是以天下人民逐利無已，犯法者衆。臣

<a id="p9"></a>**〔9〕**　<sub>中華本頁 2809a</sub>　願為民制度以防其淫，使貧富不相燿以和其心。心既和平，其性恬安。恬安不營，則

<a id="p10"></a>**〔10〕**　<sub>中華本頁 2810a</sub>　盜賊銷；盜賊銷，則刑罰少；刑罰少，則陰陽和，四時正，風雨時，草木暢茂，五穀蕃

<a id="p11"></a>**〔11〕**　<sub>中華本頁 2810a</sub>　孰，六畜遂字，民不夭厲，和之至也。

<a id="p12"></a>**〔12〕**　<sub>中華本頁 2810a</sub>　百餘年，故五伯更起。伯者，常佐天子興利除害，誅暴禁邪，匡正海內，以尊天子。

<a id="p13"></a>**〔13〕**　<sub>中華本頁 2810a</sub>　五伯既沒，賢聖莫續，天子孤弱，號令不行。諸侯恣行，彊陵弱，衆暴寡。田常篡齊，六

<a id="p14"></a>**〔14〕**　<sub>中華本頁 2810a</sub>　卿分晉，並為戰國，此民之始苦也。於是彊國務攻，弱國修守，合從連衡，馳車轂擊，

<a id="p15"></a>**〔15〕**　<sub>中華本頁 2810a</sub>　介冑生蟣蝨，民無所告愬。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 2810a</sub>　以為鍾虡，示不復用。元元黎民得免於戰國，逢明天子，人人自以為更生。鄉使

<a id="p17"></a>**〔17〕**　<sub>中華本頁 2810a</sub>　秦緩刑罰，薄賦斂，省繇役，貴仁義，賤權利，上篤厚，下佞巧，變風易俗，化於海內，

<a id="p18"></a>**〔18〕**　<sub>中華本頁 2810a</sub>　則世世必安矣。秦不行是風，循其故俗，為知巧權利者進，篤厚忠正者退，法嚴令苛，

<a id="p19"></a>**〔19〕**　<sub>中華本頁 2810a</sub>　讇諛者衆，（(曰)）【日】聞其美，（(章)）【意】廣心逸。欲威海外，使蒙恬將兵以北攻彊胡，

<a id="p20"></a>**〔20〕**　<sub>中華本頁 2810a</sub>　辟地進境，戍於北河，飛芻輓粟以隨其後。又使尉屠睢將樓船之士攻越，使監祿鑿

<a id="p21"></a>**〔21〕**　<sub>中華本頁 2810a</sub>　渠運糧，深入越地，越人遁逃。曠日持久，糧食乏絕，越人擊之，秦兵大敗。秦乃使尉佗

<a id="p22"></a>**〔22〕**　<sub>中華本頁 2810a</sub>　將卒以戍越。當是時，秦禍北構於胡，南挂於越，宿兵於無用之地，進而不得

<a id="p23"></a>**〔23〕**　<sub>中華本頁 2812a</sub>　退。行十餘年，丁男被甲，丁女轉輸，苦不聊生，自經於道樹，死者相望。及秦皇帝崩，

<a id="p24"></a>**〔24〕**　<sub>中華本頁 2812a</sub>　天下大畔。陳勝、吳廣舉陳，武臣、張耳舉趙，項梁舉吳，田儋舉齊，景駒舉郢，周市

<a id="p25"></a>**〔25〕**　<sub>中華本頁 2812a</sub>　舉魏，韓廣舉燕，窮山通谷，豪士並起，不可勝載也。然本皆非公侯之後，非長官之

<a id="p26"></a>**〔26〕**　<sub>中華本頁 2812a</sub>　吏，無尺寸之勢，起閭巷，杖棘矜，應時而動，不謀而俱起，不約而同會，壤長地進，

<a id="p27"></a>**〔27〕**　<sub>中華本頁 2812a</sub>　至乎伯王，時教使然也。秦貴為天子，富有天下，滅世絕祀，窮兵之禍也。故周失

<a id="p28"></a>**〔28〕**　<sub>中華本頁 2812a</sub>　之弱，秦失之彊，不變之患也。

<a id="p29"></a>**〔29〕**　<sub>中華本頁 2812a</sub>　之。此人臣之利，非天下之長策也。今中國無狗吠之警，而外累於遠方之備，靡敝國

<a id="p30"></a>**〔30〕**　<sub>中華本頁 2812a</sub>　家，非所以子民也。行無窮之欲，甘心快意，結怨於匈奴，非所以安邊也。禍

<a id="p31"></a>**〔31〕**　<sub>中華本頁 2812a</sub>　挐而不解，兵休而復起，近者愁苦，遠者驚駭，非所以持久也。今天下鍛甲摩劍，矯

<a id="p32"></a>**〔32〕**　<sub>中華本頁 2812a</sub>　箭控弦，轉輸軍糧，未見休時，此天下所共憂也。夫兵久而變起，事煩而慮生。今

<a id="p33"></a>**〔33〕**　<sub>中華本頁 2812a</sub>　外郡之地或幾千里，列城數十，形束壤制，帶脅諸侯，非宗室之利也。上觀

<a id="p34"></a>**〔34〕**　<sub>中華本頁 2812a</sub>　齊晉所以亡，公室卑削，六卿大盛也；下覽秦之所以滅，刑嚴文刻，欲大無窮也。今郡

<a id="p35"></a>**〔35〕**　<sub>中華本頁 2812a</sub>　守之權非特六卿之重也，地幾千里非特閭巷之資也，甲兵器械非特棘矜之用也，以逢

<a id="p36"></a>**〔36〕**　<sub>中華本頁 2812a</sub>　萬世之變，則不可勝諱也。

<a id="p37"></a>**〔37〕**　<sub>中華本頁 2812a</sub>　後以安為騎馬令。

<a id="p38"></a>**〔38〕**　<sub>中華本頁 2812a</sub>　終軍字子雲，濟南人也。少好學，以辯博能屬文聞於郡中。年十八，選為博士弟子。至府受遣，太守聞其有異材，召見軍，甚奇之，與交結。軍揖太守而去，至長安上書言事。武帝異其文，拜軍為謁者給事中。

<a id="p39"></a>**〔39〕**　<sub>中華本頁 2812a</sub>　從上幸雍祠五畤，獲白麟，一角而五蹄。時又得奇木，其枝旁出，輒復合於木上。上異此二物，博謀羣臣。軍上對曰：

<a id="p40"></a>**〔40〕**　<sub>中華本頁 2812a</sub>　羣，正朔不及其俗。有司臨境，而東甌內附，閩王伏辜，南越賴救。北胡隨畜薦

<a id="p41"></a>**〔41〕**　<sub>中華本頁 2812a</sub>　居，禽獸行，虎狼心，上古未能攝。大將軍秉鉞，單于犇幕；票騎抗旌，昆邪右

<a id="p42"></a>**〔42〕**　<sub>中華本頁 2812a</sub>　衽。是澤南洽而威北暢也。若罰不阿近，舉不遺遠，設官竢賢，縣賞待功，能

<a id="p43"></a>**〔43〕**　<sub>中華本頁 2812a</sub>　者進以保祿，罷者退而勞力，刑於宇內矣。履衆美而不足，懷聖明而不專，建

<a id="p44"></a>**〔44〕**　<sub>中華本頁 2812a</sub>　三宮之文質，章厥職之所宜，封禪之君無聞焉。

<a id="p45"></a>**〔45〕**　<sub>中華本頁 2812a</sub>　傳於無窮。故周至成王，然後制定，而休徵之應見。陛下盛日月之光，垂聖思於

<a id="p46"></a>**〔46〕**　<sub>中華本頁 2812a</sub>　勒成，專神明之敬，奉燔瘞於郊宮，獻享之精交神，積和之氣塞明，而異獸來獲，

<a id="p47"></a>**〔47〕**　<sub>中華本頁 2812a</sub>　宜矣。昔武王中流未濟，白魚入於王舟，俯取以燎，羣公咸曰「休哉！」今郊祀未見

<a id="p48"></a>**〔48〕**　<sub>中華本頁 2812a</sub>　於神祇，而獲獸以饋，此天之所以示饗，而上通之符合也。宜因昭時令日，改定告

<a id="p49"></a>**〔49〕**　<sub>中華本頁 2812a</sub>　元，苴（(以)）白茅於江淮，發嘉號于營丘，以應緝熙，使著事者有紀焉。

<a id="p50"></a>**〔50〕**　<sub>中華本頁 2812a</sub>　各以類推。今野獸并角，明同本也；衆支內附，示無外也。若此之應，殆將有解編

<a id="p51"></a>**〔51〕**　<sub>中華本頁 2812a</sub>　髮，削左衽，襲冠帶，要衣裳，而蒙化者焉。斯拱而竢之耳！

<a id="p52"></a>**〔52〕**　<sub>中華本頁 2812a</sub>　對奏，上甚異之，由是改元為元狩。後數月，越地及匈奴名王有率衆來降者，時皆以軍言為中。

<a id="p53"></a>**〔53〕**　<sub>中華本頁 2812a</sub>　元鼎中，博士徐偃使行風俗。偃矯制，使膠東、魯國鼓鑄鹽鐵。還，奏事，徙為太常丞。御史大夫張湯劾偃矯制大害，法至死。偃以為春秋之義，大夫出疆，有可以安社稷，存萬民，顓之可也。湯以致其法，不能詘其義。有詔下軍問狀，軍詰偃曰：「古者諸侯國異俗分，百里不通，時有聘會之事，安危之勢，呼吸成變，故有不受辭造命顓己之宜；今天下為一，萬里同風，故春秋『王者無外』。偃巡封域之中，稱以出疆何也？且鹽鐵，郡有餘臧，正二國廢，國家不足以為利害，而以安社稷存萬民為辭，何也？」又詰偃：「膠東南近琅邪，北接北海，魯國西枕泰山，東有東海，受其鹽鐵。偃度四郡口數田地，率其用器食鹽，不足以并給二郡邪？將勢宜有餘，而吏不能也？何以言之？偃矯制而鼓鑄者，欲及春耕種贍民器也。今魯國之鼓，當先具其備，至秋乃能舉火。此言與實反者非？偃已前三奏，無詔，不惟所為不許，而直矯作威福，以從民望，干名采譽，此明聖所必加誅也。『枉尺直尋』，孟子稱其不可；今所犯罪重，所就者小，偃自予必死而為之邪？將幸誅不加，欲以采名也？」偃窮詘，服罪當死。軍奏「偃矯制顓行，非奉使體，請下御史徵偃即罪。」奏可。上善其詰，有詔示御史大夫。

<a id="p54"></a>**〔54〕**　<sub>中華本頁 2818a</sub>　初，軍從濟南當詣博士，步入關，關吏予軍繻。軍問：「以此何為？」吏曰；「為復傳，還當以合符。」軍曰：「大丈夫西游，終不復傳還。」棄繻而去。軍為謁者，使行郡國，建節東出關，關吏識之，曰：「此使者乃前棄繻生也。」軍行郡國，所見便宜以聞。還奏事，上甚說。

<a id="p55"></a>**〔55〕**　<sub>中華本頁 2820a</sub>　當發使（(使)）匈奴，軍自請曰：「軍無橫草之功，得列宿衞，食祿五年。邊境時有風塵之警，臣宜被堅執銳，當矢石，啟前行。駑下不習金革之事，今聞將遣匈奴使者，臣願盡精厲氣，奉佐明使，畫吉凶於單于之前。臣年少材下，孤於外官，不足以亢一方之任，竊不勝憤懣。」詔問畫吉凶之狀，上奇軍對，擢為諫大夫。

<a id="p56"></a>**〔56〕**　<sub>中華本頁 2820a</sub>　南越與漢和親，乃遣軍使南越，說其王，欲令入朝，比內諸侯。軍自請：「願受長纓，必羈南越王而致之闕下。」軍遂往說越王，越王聽許，請舉國內屬。天子大說，賜南越大臣印綬，壹用漢法，以新改其俗，令使者留填撫之。越相呂嘉不欲內屬，發兵攻殺其王，及漢使者皆死。語在南越傳。軍死時年二十餘，故世謂之「終童」。

<a id="p57"></a>**〔57〕**　<sub>中華本頁 2820a</sub>　王襃字子淵，蜀人也。宣帝時修武帝故事，講論六藝羣書，博盡奇異之好，徵能為楚辭九江被公，召見誦讀，益召高材劉向、張子僑、華龍、柳襃等待詔金馬門。神爵、五鳳之間，天下殷（(當)）【富】，數有嘉應。上頗作歌詩，欲興協律之事，丞相魏相奏言知音善鼓雅琴者渤海趙定、梁國龔德，皆召見待詔。於是益州刺史王襄欲宣風化於衆庶，聞王襃有俊材，請與相見，使襃作中和、樂職、宣布詩，選好事者令依鹿鳴之聲習而歌之。時氾鄉侯何武為僮子，選在歌中。久之，武等學長安，歌太學下，轉而上聞。宣帝召見武等觀之，皆賜帛，謂曰：「此盛德之事，吾何足以當之！」

<a id="p58"></a>**〔58〕**　<sub>中華本頁 2822a</sub>　襃既為刺史作頌，又作其傳，益州刺史因奏襃有軼材。上乃徵襃。既至，詔褎為聖主得賢臣頌其意。襃對曰：

<a id="p59"></a>**〔59〕**　<sub>中華本頁 2822a</sub>　味。今臣辟在西蜀，生於窮巷之中，長於蓬茨之下，無有游觀廣覽之知，顧有

<a id="p60"></a>**〔60〕**　<sub>中華本頁 2822a</sub>　至愚極陋之累，不足以塞厚望，應明指。雖然，敢不略陳愚而抒情素！

<a id="p61"></a>**〔61〕**　<sub>中華本頁 2822a</sub>　任賢，則趨舍省而功施普；器用利，則用力少而就效衆。故工人之用鈍器也，勞筋

<a id="p62"></a>**〔62〕**　<sub>中華本頁 2822a</sub>　苦骨，終日矻矻。及至巧冶鑄干將之樸，清水焠其鋒，越砥斂其咢，水斷蛟

<a id="p63"></a>**〔63〕**　<sub>中華本頁 2822a</sub>　龍，陸剸犀革，忽若彗氾畫塗。如此，則使離婁督繩，公輸削墨，雖崇臺五增，

<a id="p64"></a>**〔64〕**　<sub>中華本頁 2822a</sub>　延袤百丈，而不溷者，工用相得也。庸人之御駑馬，亦傷吻敝策而不進於行，匈

<a id="p65"></a>**〔65〕**　<sub>中華本頁 2822a</sub>　喘膚汗，人極馬倦。及至駕齧{GJ-C8D9}，驂乘旦，王良執靶，韓哀附輿，縱馳騁騖，

<a id="p66"></a>**〔66〕**　<sub>中華本頁 2822a</sub>　忽如景靡，過都越國，蹶如歷塊；追奔電，逐遺風，周流八極，萬里壹息。何

<a id="p67"></a>**〔67〕**　<sub>中華本頁 2822a</sub>　其遼哉？人馬相得也。故服絺綌之涼者，不苦盛暑之鬱燠；襲貂狐之{GJ-C8E2}者，不

<a id="p68"></a>**〔68〕**　<sub>中華本頁 2822a</sub>　憂至寒之悽愴。何則？有其具者易其備。賢人君子，亦聖（(主)）【王】之所以易海內

<a id="p69"></a>**〔69〕**　<sub>中華本頁 2822a</sub>　也。是以嘔喻受之，開寬裕之路，以延天下英俊也。夫竭知附賢者，必建仁策；

<a id="p70"></a>**〔70〕**　<sub>中華本頁 2822a</sub>　索人求士者，必樹伯迹。昔周公躬吐捉之勞，故有圉空之隆；齊桓設庭燎之禮，

<a id="p71"></a>**〔71〕**　<sub>中華本頁 2824a</sub>　故有匡合之功。由此觀之，君人者勤於求賢而逸於得人。

<a id="p72"></a>**〔72〕**　<sub>中華本頁 2824a</sub>　信，進仕不得施效，斥逐又非其愆。是故伊尹勤於鼎俎，太公困於鼓刀，百里自

<a id="p73"></a>**〔73〕**　<sub>中華本頁 2824a</sub>　鬻，甯子飯牛，離此患也。及其遇明君遭聖主也，運籌合上意，諫諍即見聽，進退

<a id="p75"></a>**〔75〕**　<sub>中華本頁 2824a</sub>　壤而光祖考，傳之子孫，以資說士。故世必有聖知之君，而後有賢明之臣。故虎嘯

<a id="p76"></a>**〔76〕**　<sub>中華本頁 2824a</sub>　而（(冽風)）【風冽】，龍興而致雲，蟋蟀俟秋唫，蜉蝤出以陰。易曰：「飛龍在天，利見

<a id="p77"></a>**〔77〕**　<sub>中華本頁 2824a</sub>　大人。」詩曰：「思皇多士，生此王國。」故世平主聖，俊艾將自至，若堯、舜、

<a id="p78"></a>**〔78〕**　<sub>中華本頁 2824a</sub>　禹、湯、文、武之君，獲稷、契、皋陶、伊尹、呂望，明明在朝，穆穆列布，聚精會神，

<a id="p79"></a>**〔79〕**　<sub>中華本頁 2824a</sub>　相得益章。雖伯牙操遞鍾，逢門子彎烏號，猶未足以喻其意也。

<a id="p80"></a>**〔80〕**　<sub>中華本頁 2824a</sub>　合，論說無疑，翼乎如鴻毛過順風，沛乎如巨魚縱大壑。其得意若此，則胡禁不止，

<a id="p81"></a>**〔81〕**　<sub>中華本頁 2828a</sub>　曷令不行？化溢四表，橫被無窮，遐夷貢獻，萬祥畢溱。是以聖王不徧窺望而視

<a id="p82"></a>**〔82〕**　<sub>中華本頁 2828a</sub>　已明，不單頃耳而聽已聰；恩從祥風翺，德與和氣游，太平之責塞，優游之望

<a id="p83"></a>**〔83〕**　<sub>中華本頁 2828a</sub>　得；遵遊自然之勢，恬淡無為之場，休徵自至，壽考無疆，雍容垂拱，永永萬年，何

<a id="p84"></a>**〔84〕**　<sub>中華本頁 2828a</sub>　必偃卬詘信若彭祖，呴噓呼吸如僑、松，眇然絕俗離世哉！詩云「濟濟多士，文

<a id="p85"></a>**〔85〕**　<sub>中華本頁 2828a</sub>　王以寧」，蓋信乎其以寧也！

<a id="p86"></a>**〔86〕**　<sub>中華本頁 2828a</sub>　上令襃與張子僑等並待詔，數從襃等放獵，所幸宮館，輒為歌頌，第其高下，以差賜帛。議者多以為淫靡不急，上曰：「『不有博弈者乎，為之猶賢乎已！』辭賦大者與古詩同義，小者辯麗可喜。辟如女工有綺縠，音樂有鄭衞，今世俗猶皆以此虞說耳目，辭賦比之，尚有仁義風諭，鳥獸草木多聞之觀，賢於倡優博弈遠矣。」頃之，擢襃為諫大夫。

<a id="p87"></a>**〔87〕**　<sub>中華本頁 2828a</sub>　其後太子體不安，苦忽忽善忘，不樂。詔使襃等皆之太子宮虞侍太子，朝夕誦讀奇文及所自造作。疾平復，乃歸。太子喜襃所為甘泉及洞簫頌，令後宮貴人左右皆誦讀之。

<a id="p88"></a>**〔88〕**　<sub>中華本頁 2828a</sub>　後方士言益州有金馬碧雞之寶，可祭祀致也，宣帝使襃往祀焉。襃於道病死，上閔惜之。

<a id="p89"></a>**〔89〕**　<sub>中華本頁 2828a</sub>　賈捐之字君房，賈誼之曾孫也。元帝初即位，上疏言得失，召待詔金馬門。

<a id="p90"></a>**〔90〕**　<sub>中華本頁 2828a</sub>　初，武帝征南越，元封元年立儋耳、珠厓郡，皆在南方海中洲居，廣袤可千里，合十六縣，戶二萬三千餘。其民暴惡，自以阻絕，數犯吏禁，吏亦酷之，率數年壹反，殺吏，漢輒發兵擊定之。自初為郡至昭帝始元元年，二十餘年間，凡六反叛。至其五年，罷儋耳郡并屬珠厓。至宣帝神爵三年，珠厓三縣復反。反後七年，甘露元年，九縣反，輒發兵擊定之。元帝初元元年，珠厓又反，發兵擊之。諸縣更叛，連年不定。上與有司議大發軍，捐之建議，以為不當擊。上使侍中駙馬都尉樂昌侯王商詰問捐之曰：「珠厓內屬為郡久矣，今背畔逆節，而云不當擊，長蠻夷之亂，虧先帝功德，經義何以處之？」捐之對曰：

<a id="p91"></a>**〔91〕**　<sub>中華本頁 2828a</sub>　曰「無間」。以三聖之德，地方不過數千里，【西】被流沙，東漸于海，朔南暨聲教，迄

<a id="p92"></a>**〔92〕**　<sub>中華本頁 2828a</sub>　于四海，欲與聲教則治之，不欲與者不彊治也。故君臣歌德，含氣之物各（(德)）

<a id="p93"></a>**〔93〕**　<sub>中華本頁 2828a</sub>　【得】其宜。武丁、成王，殷、周之大仁也，然地東不過江、黃，西不過氐、羌，南不過

<a id="p94"></a>**〔94〕**　<sub>中華本頁 2828a</sub>　蠻荊，北不過朔方。是以頌聲並作，視聽之類咸樂其生，越裳氏重九譯而獻，此非兵

<a id="p95"></a>**〔95〕**　<sub>中華本頁 2828a</sub>　革之所能致。及其衰也，南征不還，齊桓捄其難，孔子定其文。以至乎秦，興

<a id="p96"></a>**〔96〕**　<sub>中華本頁 2828a</sub>　兵遠攻，貪外虛內，務欲廣地，不慮其害。然地南不過閩越，北不過太原，而天下潰畔，

<a id="p97"></a>**〔97〕**　<sub>中華本頁 2828a</sub>　禍卒在於二世之末，長城之歌至今未絕。

<a id="p98"></a>**〔98〕**　<sub>中華本頁 2828a</sub>　獄數百，民賦四十，丁男三年而一事。時有獻千里馬者，詔曰：「鸞旗在前，屬車在

<a id="p99"></a>**〔99〕**　<sub>中華本頁 2828a</sub>　後，吉行日五十里，師行（(二)）【三】十里，朕乘千里之馬，獨先安之？」於是還馬，與

<a id="p100"></a>**〔100〕**　<sub>中華本頁 2828a</sub>　道里費，而下詔曰：「朕不受獻也，其令四方毋求來獻。」當此之時，逸游之樂絕，奇麗之賂

<a id="p101"></a>**〔101〕**　<sub>中華本頁 2828a</sub>　塞，鄭衞之倡微矣。夫後（(官)）【宮】盛色則賢者隱處，佞人用事則諍臣杜口，而文帝不行，

<a id="p102"></a>**〔102〕**　<sub>中華本頁 2828a</sub>　故諡為孝文，廟稱太宗。至孝武皇帝元狩六年，太倉之粟紅腐而不可食，都內之錢貫

<a id="p103"></a>**〔103〕**　<sub>中華本頁 2828a</sub>　朽而不可（(挍)）【校】。乃探平城之事，錄冒頓以來數為邊害，籍兵厲馬，因富民以攘

<a id="p104"></a>**〔104〕**　<sub>中華本頁 2828a</sub>　服之。西連諸國至于安息，東過碣石以玄菟、樂浪為郡，（(比)）【北】卻匈奴萬里，

<a id="p105"></a>**〔105〕**　<sub>中華本頁 2828a</sub>　更起營塞，制南海以為八郡，則天下斷獄萬數，民賦數百，造鹽鐵酒榷之利以佐用度，

<a id="p106"></a>**〔106〕**　<sub>中華本頁 2833a</sub>　猶不能足。當此之時，寇賊並起，軍旅數發，父戰死於前，子鬬傷於後，女子乘亭鄣，孤

<a id="p107"></a>**〔107〕**　<sub>中華本頁 2833a</sub>　兒號於道，老母寡婦飲泣巷哭，遙設虛祭，想魂乎萬里之外。淮南王盜寫虎符，陰

<a id="p108"></a>**〔108〕**　<sub>中華本頁 2833a</sub>　聘名士，關東公孫勇等詐為使者，是皆廓地泰大，征伐不休之故也。

<a id="p109"></a>**〔109〕**　<sub>中華本頁 2833a</sub>　道路。人情莫親父母，莫樂夫婦，至嫁妻賣子，法不能禁，義不能止，此社稷之憂

<a id="p110"></a>**〔110〕**　<sub>中華本頁 2833a</sub>　也。今陛下不忍悁悁之忿，欲驅士衆擠之大海之中，快心幽冥之地，非所以救助飢

<a id="p111"></a>**〔111〕**　<sub>中華本頁 2834a</sub>　饉，保全元元也。詩云「蠢爾蠻荊，大邦為讎」，言聖人起則後服，中國衰則先畔，動

<a id="p112"></a>**〔112〕**　<sub>中華本頁 2834a</sub>　為國家難，自古而患之久矣，何況乃復其南方萬里之蠻乎！駱越之人父子同川而浴，

<a id="p113"></a>**〔113〕**　<sub>中華本頁 2834a</sub>　相習以鼻飲，與禽獸無異，本不足郡縣置也。顓顓獨居一海之中，霧露氣溼，多毒

<a id="p114"></a>**〔114〕**　<sub>中華本頁 2834a</sub>　草蟲蛇水土之害，人未見虜，戰士自死。又非獨珠厓有珠犀{M-49301}瑁也，棄之不足惜，

<a id="p115"></a>**〔115〕**　<sub>中華本頁 2834a</sub>　不擊不損威。其民譬猶魚鼈，何足貪也！

<a id="p116"></a>**〔116〕**　<sub>中華本頁 2834a</sub>　盡，乃以少府禁錢續之。夫一隅為不善，費尚如此，況於勞師遠攻，亡士毋功乎！求

<a id="p117"></a>**〔117〕**　<sub>中華本頁 2834a</sub>　之往古則不合，施之當今又不便。臣愚以為非冠帶之國，禹貢所及，春秋所治，皆可且

<a id="p118"></a>**〔118〕**　<sub>中華本頁 2834a</sub>　無以為。願遂棄珠厓，專用恤關東為憂。

<a id="p119"></a>**〔119〕**　<sub>中華本頁 2834a</sub>　對奏，上以問丞相御史。御史大夫陳萬年以為當擊；丞相于定國以為「前日興兵擊之連年，護軍都尉、校尉及丞凡十一人，還者二人，卒士及轉輸死者萬人以上，費用三萬萬餘，尚未能盡降。今關東困乏，民難搖動，捐之議是。」上乃從之。遂下詔曰：「珠厓虜殺吏民，背畔為逆，今廷議者或言可擊，或言可守，或欲棄之，其指各殊。朕日夜惟思議者之言，羞威不行，則欲誅之；狐疑辟難，則守屯田；通于時變，則憂萬民。夫萬民之饑餓，與遠蠻之不討，危孰大焉？且宗廟之祭，凶年不備，況乎辟不嫌之辱哉！今關東大困，倉庫空虛，無以相贍，又以動兵，非特勞民，凶年隨之。其罷珠厓郡。民有慕義欲內屬，便處之；不欲，勿彊。」珠厓由是罷。

<a id="p120"></a>**〔120〕**　<sub>中華本頁 2834a</sub>　捐之數召見，言多納用。時中書令石顯用事，捐之數短顯，以故不得官，後稀復見。而長安令楊興新以材能得幸，與捐之相善。捐之欲得召見，謂興曰：「京兆尹缺，使我得見，言君蘭，京兆尹可立得。」興曰：「縣官嘗言興瘉薛大夫，我易助也。君房下筆，言語妙天下，使君房為尚書令，勝五鹿充宗遠甚。」捐之曰：「令我得代充宗，君蘭為京兆，京兆郡國首，尚書百官本，天下真大治，士則不隔矣。捐之前言平恩侯可為將軍，期思侯並可為諸曹，皆如言；又薦謁者滿宣，立為冀州刺史；言中謁者不宜受事，宦者不宜入宗廟，立止。相薦之信，不當如是乎！」興曰：「我復見，言君房也。」捐之復短石顯。興曰：「顯鼎貴，上信用之。今欲進，弟從我計，且與合意，即得入矣。」

<a id="p121"></a>**〔121〕**　<sub>中華本頁 2836a</sub>　捐之即與興共為薦顯奏，曰：「竊見石顯本山東名族，有禮義之家也。持正六年，未嘗有過，明習於事，敏而疾見，出公門，入私門。宜賜爵關內侯，引其兄弟以為諸曹。」又共為薦興奏，曰：「竊見長安令興，幸得以知名數召見。興事父母有曾氏之孝，事師有顏閔之材，榮名聞於四方。明詔舉茂材，列侯以為首。為長安令，吏民敬鄉，道路皆稱能。觀其下筆屬文，則董仲舒；進談動辭，則東方生；置之爭臣，則汲直；用之介冑，則冠軍侯；施之治民，則趙廣漢；抱公絕私，則尹翁歸。興兼此六人而有之，守道堅固，執義不回，臨大節而不可奪，國之良臣也，可試守京兆尹。」

<a id="p122"></a>**〔122〕**　<sub>中華本頁 2837a</sub>　石顯聞知，白之上。乃下興、捐之獄，令皇后父陽平侯禁與顯共雜治，奏「興、捐之懷詐偽，以上語相風，更相薦譽，欲得大位，漏泄省中語，（(岡)）【罔】上不道。書曰：『讒說殄行，震驚朕師。』王制：『順非而澤，不聽而誅。』請論如法。」

<a id="p123"></a>**〔123〕**　<sub>中華本頁 2837a</sub>　贊曰：詩稱「戎狄是膺，荊舒是懲」，久矣其為諸夏患也。漢興，征伐胡越，於是為盛。究觀淮南、捐之、主父、嚴安之義，深切著明，故備論其語。世稱公孫弘排主父，張湯陷嚴助，石顯譖捐之，察其行迹，主父求欲鼎亨而得族，嚴、賈出入禁門招權利，死皆其所也，亦何排陷之恨哉！
