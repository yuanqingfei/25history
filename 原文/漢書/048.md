# 漢書·卷48　賈誼傳第十八

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 2221a</sub>　賈誼傳第十八

<a id="p2"></a>**〔2〕**　<sub>中華本頁 2221a</sub>　賈誼，雒陽人也，年十八，以能誦詩書屬文稱於郡中。河南守吳公聞其秀材，召置門下，甚幸愛。文帝初立，聞河南守吳公治平為天下第一，故與李斯同邑，而嘗學事焉，徵以為廷尉。廷尉乃言誼年少，頗通諸家之書。文帝召以為博士。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 2221a</sub>　是諸，誼年二十餘，最為少。每詔令議下，諸老先生未能言，誼盡為之對，人人各如其意所出。諸生於是以為能。文帝說之，超遷，歲中至太中大夫。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 2221a</sub>　誼以為漢興二十餘年，天下和洽，宜當改正朔，易服色制度，定官名，興禮樂。乃草具其儀法，色上黃，數用五，為官名悉更，奏之。文帝謙讓未皇也。然諸法令所更定，及列侯就國，其說皆誼發之。於是天子議以誼任公卿之位。絳、灌、東陽侯、馮敬之屬盡害之，乃毀誼曰：「雒陽之人年少初學，專欲擅權，紛亂諸事。」於是天子後亦疏之，不用其議，以誼為長沙王太傅。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 2221a</sub>　誼既以適去，意不自得，及度湘水，為賦以弔屈原。屈原，楚賢臣也，被讒放逐，作離騷賦，其終篇曰：「已矣！國亡人，莫我知也。」遂自投江而死。誼追傷之，因以自諭。其辭曰：

<a id="p6"></a>**〔6〕**　<sub>中華本頁 2221a</sub>　生。遭世罔極兮，迺隕厥身。烏虖哀哉兮，逢時不祥！鸞鳳伏竄兮，鴟鴞翺

<a id="p7"></a>**〔7〕**　<sub>中華本頁 2221a</sub>　翔。闒茸尊顯兮，讒諛得志；賢聖逆曳兮，方正倒植。謂隨、夷溷兮，謂

<a id="p8"></a>**〔8〕**　<sub>中華本頁 2221a</sub>　跖、蹻廉；莫邪為鈍兮，鈆刀為銛。于嗟默默，生之亡故兮！斡棄周

<a id="p9"></a>**〔9〕**　<sub>中華本頁 2221a</sub>　鼎，寶康瓠兮。騰駕罷牛，驂蹇驢兮；驥垂兩耳，服鹽車兮。章父薦屨，

<a id="p10"></a>**〔10〕**　<sub>中華本頁 2221a</sub>　漸不可久兮；嗟（(若)）【苦】先生，獨離此咎兮！

<a id="p11"></a>**〔11〕**　<sub>中華本頁 2221a</sub>　自引而遠去。襲九淵之神龍兮，沕淵潛以自珍；偭蟂獺以隱處兮，夫豈

<a id="p12"></a>**〔12〕**　<sub>中華本頁 2221a</sub>　從蝦與蛭螾？所貴聖之神德兮，遠濁世而自臧。使麒麟可係而羈兮，豈云異夫

<a id="p13"></a>**〔13〕**　<sub>中華本頁 2221a</sub>　犬羊？般紛紛其離此郵兮，亦夫子之故也！歷九州而相其君兮，何必懷此都

<a id="p14"></a>**〔14〕**　<sub>中華本頁 2221a</sub>　也？鳳皇翔于千仞兮，覽德煇而下之；見細德之險（(微)）【徵】兮，遙增擊而去

<a id="p15"></a>**〔15〕**　<sub>中華本頁 2225a</sub>　之。彼尋常之汙瀆兮，豈容吞舟之魚！橫江湖之鱣鯨兮，固將制於螻螘。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 2225a</sub>　誼為長沙傅三年，有服飛入誼舍，止於坐隅。服似鴞，不祥鳥也。誼既以適居長沙，長沙卑濕，誼自傷悼，以為壽不得長，乃為賦以自廣。其辭曰：

<a id="p17"></a>**〔17〕**　<sub>中華本頁 2225a</sub>　來{GJ-C863}，私怪其故，發書占之，讖言其度。曰「野鳥入室，主人將去。」問于子服：

<a id="p18"></a>**〔18〕**　<sub>中華本頁 2225a</sub>　「余去何之？吉虖告我，凶言其災。淹速之度，語余其期。」

<a id="p19"></a>**〔19〕**　<sub>中華本頁 2225a</sub>　或推而還。形氣轉續，變化而嬗。沕穆亡間，胡可勝言！禍兮福所倚，福兮禍

<a id="p20"></a>**〔20〕**　<sub>中華本頁 2225a</sub>　所伏；憂喜聚門，吉凶同域。彼吳彊大，夫差以敗；粵棲會稽，句踐伯世。斯

<a id="p21"></a>**〔21〕**　<sub>中華本頁 2225a</sub>　遊遂成，卒被五刑；傅說胥靡，乃相武丁。夫禍之與福，何異糾纆！命不可

<a id="p22"></a>**〔22〕**　<sub>中華本頁 2225a</sub>　說，孰知其極？水激則旱，矢激則遠。萬物回薄，震蕩相轉。雲烝雨降，糾錯相

<a id="p23"></a>**〔23〕**　<sub>中華本頁 2225a</sub>　紛。大鈞播物，坱圠無垠。天不可與慮，道不可與謀。遲速有命，烏識其時？

<a id="p24"></a>**〔24〕**　<sub>中華本頁 2225a</sub>　萬化，未始有極。忽然為人，何足控揣；化為異物，又何足患！小智自私，賤

<a id="p25"></a>**〔25〕**　<sub>中華本頁 2225a</sub>　彼貴我；達人大觀，物亡不可。貪夫徇財，列士徇名；夸者死權，品庶每生。怵

<a id="p26"></a>**〔26〕**　<sub>中華本頁 2225a</sub>　迫之徒，或趨西東；大人不曲，意變齊同。愚士繫俗，{GJ-C847}若囚拘；至人遺物，獨

<a id="p27"></a>**〔27〕**　<sub>中華本頁 2225a</sub>　與道俱。衆人惑惑，好惡積意；真人恬漠，獨與道息。釋智遺形，超然自喪；

<a id="p28"></a>**〔28〕**　<sub>中華本頁 2225a</sub>　寥廓忽荒，與道翺翔。乘流則逝，得坎則止；縱軀委命，不私與己。其生兮若浮，

<a id="p29"></a>**〔29〕**　<sub>中華本頁 2225a</sub>　其死兮若休。澹虖若深淵之靚，氾虖若不繫之舟。不以生故自保，養空而浮。

<a id="p30"></a>**〔30〕**　<sub>中華本頁 2225a</sub>　德人無累，知命不憂。細故蔕芥，何足以疑！

<a id="p31"></a>**〔31〕**　<sub>中華本頁 2225a</sub>　後歲餘，文帝思誼，徵之。至，入見，上方受釐，坐宣室。上因感鬼神事，而問鬼神之本。誼具道所以然之故。至夜半，文帝前席。既罷，曰：「吾久不見賈生，自以為過之，今不及也。」乃拜誼為梁懷王太傅。懷王，上少子，愛，而好書，故令誼傅之，數問以得失。

<a id="p32"></a>**〔32〕**　<sub>中華本頁 2225a</sub>　是時，匈奴彊，侵邊。天下初定，制度疏闊。諸侯王僭儗，地過古制，淮南、濟北王皆為逆誅。誼數上疏陳政事，多所欲匡建，其大略曰：

<a id="p33"></a>**〔33〕**　<sub>中華本頁 2225a</sub>　道者，難徧以疏舉。進言者皆曰天下已安已治矣，臣獨以為未也。曰安且治

<a id="p34"></a>**〔34〕**　<sub>中華本頁 2225a</sub>　者，非愚則諛，皆非事實知治亂之體者也。夫抱火厝之積薪之下而寢其上，火

<a id="p35"></a>**〔35〕**　<sub>中華本頁 2225a</sub>　未及燃，因謂之安，方今之勢，何以異此！本末舛逆，首尾衡決，國制搶攘，非甚有

<a id="p36"></a>**〔36〕**　<sub>中華本頁 2225a</sub>　紀，胡可謂治！陛下何不壹令臣得孰數之於前，因陳治安之策，試詳擇焉！

<a id="p37"></a>**〔37〕**　<sub>中華本頁 2231a</sub>　可也。樂與今同，而加之諸侯軌道，兵革不動，民保首領，匈奴賓服，四荒鄉風，

<a id="p38"></a>**〔38〕**　<sub>中華本頁 2231a</sub>　百姓素朴，獄訟衰息，大數既得，則天下順治，海內之氣清和咸理，生為明帝，沒為明

<a id="p39"></a>**〔39〕**　<sub>中華本頁 2231a</sub>　神，名譽之美，垂於無窮。禮祖有功而宗有德，使顧成之廟稱為太宗，上配太祖，與漢

<a id="p40"></a>**〔40〕**　<sub>中華本頁 2231a</sub>　亡極。建久安之勢，成長治之業，以承祖廟，以奉六親，至孝也；以幸天下，以育羣

<a id="p41"></a>**〔41〕**　<sub>中華本頁 2231a</sub>　生，至仁也；立經陳紀，輕重同得，後可以為萬世法程，雖有愚幼不肖之嗣，猶得蒙

<a id="p42"></a>**〔42〕**　<sub>中華本頁 2231a</sub>　業而安，至明也。以陛下之明達，因使少知治體者得佐下風，致此非難也。其具可素

<a id="p43"></a>**〔43〕**　<sub>中華本頁 2231a</sub>　陳於前，願幸無忽。臣謹稽之天地，驗之往古，按之當今之務，日夜念此至孰

<a id="p44"></a>**〔44〕**　<sub>中華本頁 2231a</sub>　也，雖使禹舜復生，為陛下計，亡以易此。

<a id="p45"></a>**〔45〕**　<sub>中華本頁 2232a</sub>　今或親弟謀為東帝，親兄之子西鄉而擊，今吳又見告矣。天子春秋鼎盛，

<a id="p46"></a>**〔46〕**　<sub>中華本頁 2232a</sub>　行義未過，德澤有加焉，猶尚如是，況莫大諸侯，權力且十此者虖！

<a id="p47"></a>**〔47〕**　<sub>中華本頁 2232a</sub>　諸侯之王大抵皆冠，血氣方剛，漢之傅相稱病而賜罷，彼自丞尉以上偏置私人，如

<a id="p48"></a>**〔48〕**　<sub>中華本頁 2232a</sub>　此，有異淮南、濟北之為邪！此時而欲為治安，雖堯舜不治。

<a id="p49"></a>**〔49〕**　<sub>中華本頁 2232a</sub>　骨肉之屬而抗剄之，豈有異秦之季世虖！夫以天子之位，乘今之時，因天之助，尚

<a id="p50"></a>**〔50〕**　<sub>中華本頁 2232a</sub>　憚以危為安，以亂為治，假設陛下居齊桓之處，將不合諸侯而匡天下乎？臣又以知陛

<a id="p51"></a>**〔51〕**　<sub>中華本頁 2232a</sub>　下有所必不能矣。假設天下如曩時，淮陰侯尚王楚，黥布王淮南，彭越王梁，韓信王

<a id="p52"></a>**〔52〕**　<sub>中華本頁 2232a</sub>　韓，張敖王趙，貫高為相，盧綰王燕，陳豨在代，令此六七公者皆亡恙，當是時而陛

<a id="p53"></a>**〔53〕**　<sub>中華本頁 2232a</sub>　下即天子位，能自安乎？臣有以知陛下之不能也。天下殽亂，高皇帝與諸公併起，

<a id="p54"></a>**〔54〕**　<sub>中華本頁 2234a</sub>　非有仄室之勢以豫席之也。諸公幸者，乃為中涓，其次廑得舍人，材之不逮至

<a id="p55"></a>**〔55〕**　<sub>中華本頁 2234a</sub>　遠也。高皇帝以明聖威武即天子位，割膏腴之地以王諸公，多者百餘城，少者乃三四

<a id="p56"></a>**〔56〕**　<sub>中華本頁 2234a</sub>　十縣，惪至渥也，然其後十年之間，反者九起。陛下之與諸公，非親角材而臣之

<a id="p57"></a>**〔57〕**　<sub>中華本頁 2234a</sub>　也，又非身封王之也，自高皇帝不能以是一歲為安，故臣知陛下之不能也。然尚

<a id="p58"></a>**〔58〕**　<sub>中華本頁 2234a</sub>　有可諉者，曰疏，臣請試言其親者。假令悼惠王王齊，元王王楚，中子王趙，幽王王

<a id="p59"></a>**〔59〕**　<sub>中華本頁 2234a</sub>　淮陽，共王王梁，靈王王燕，厲王王淮南，六七貴人皆亡恙，當是時陛下即位，能為

<a id="p60"></a>**〔60〕**　<sub>中華本頁 2234a</sub>　治虖？臣又知陛下之不能也。若此諸王，雖名為臣，實皆有布衣昆弟之心，慮亡

<a id="p61"></a>**〔61〕**　<sub>中華本頁 2234a</sub>　不帝制而天子自為者。擅爵人，赦死罪，甚者或戴黃屋，漢法令非行也。雖

<a id="p62"></a>**〔62〕**　<sub>中華本頁 2234a</sub>　行不軌如厲王者，令之不肯聽，召之安可致乎！幸而來至，法安可得加！動一親

<a id="p63"></a>**〔63〕**　<sub>中華本頁 2234a</sub>　戚，天下圜視而起，陛下之臣雖有悍如馮敬者，適啟其口，匕首已陷其匈矣。

<a id="p64"></a>**〔64〕**　<sub>中華本頁 2234a</sub>　陛下雖賢，誰與領此？故疏者必危，親者必亂，已然之效也。其異姓負彊而動者，

<a id="p65"></a>**〔65〕**　<sub>中華本頁 2234a</sub>　漢已幸勝之矣，又不易其所以然。同姓襲是跡而動，既有徵矣，其勢盡又復然。

<a id="p66"></a>**〔66〕**　<sub>中華本頁 2234a</sub>　殃之變，未知所移，明帝處之尚不能以安，後世將如之何！

<a id="p67"></a>**〔67〕**　<sub>中華本頁 2234a</sub>　髖髀之所，非斤則斧。夫仁義恩厚，人主之芒刃也；權勢法制，人主之斤斧也。今

<a id="p68"></a>**〔68〕**　<sub>中華本頁 2234a</sub>　諸侯王皆衆髖髀也，釋斤斧之用，而欲嬰以芒刃，臣以為不缺則折。胡不用之淮南、

<a id="p69"></a>**〔69〕**　<sub>中華本頁 2234a</sub>　濟北？勢不可也。

<a id="p70"></a>**〔70〕**　<sub>中華本頁 2234a</sub>　貫高因趙資，則又反；陳豨兵精，則又反；彭越用梁，則又反；黥布用淮南，則又

<a id="p71"></a>**〔71〕**　<sub>中華本頁 2234a</sub>　反；盧綰最弱，最後反。長沙乃在二萬五千戶耳，功少而最完，勢疏而最忠，非獨性異

<a id="p72"></a>**〔72〕**　<sub>中華本頁 2234a</sub>　人也，亦形勢然也。曩令樊、酈、絳、灌據數十城而王，今雖以殘亡可也；令信、越

<a id="p73"></a>**〔73〕**　<sub>中華本頁 2234a</sub>　之倫列為徹侯而居，雖至今存可也。然則天下之大計可知已。欲諸王之皆忠附，

<a id="p74"></a>**〔74〕**　<sub>中華本頁 2234a</sub>　則莫若令如長沙王；欲臣子之勿菹醢，則莫若令如樊、酈等；欲天下之治安，莫若衆

<a id="p75"></a>**〔75〕**　<sub>中華本頁 2234a</sub>　建諸侯而少其力。力少則易使以義，國小則亡邪心。令海內之勢如身之使臂，臂之

<a id="p76"></a>**〔76〕**　<sub>中華本頁 2234a</sub>　使指，莫不制從，諸侯之君不敢有異心，輻湊並進而歸命天子，雖在細民，且知其安，故

<a id="p77"></a>**〔77〕**　<sub>中華本頁 2234a</sub>　天下咸知陛下之明。割地定制，令齊、趙、楚各為若干國，使悼惠王、幽王、元王之子

<a id="p78"></a>**〔78〕**　<sub>中華本頁 2234a</sub>　孫畢以次各受祖之分地，地盡而止，及燕、梁它國皆然。其分地衆而子孫少者，建

<a id="p79"></a>**〔79〕**　<sub>中華本頁 2234a</sub>　以為國，空而置之，須其子孫生者，舉使君之。諸侯之地其削頗入漢者，為徙其侯國

<a id="p80"></a>**〔80〕**　<sub>中華本頁 2234a</sub>　及封其子孫也，所以數償之：一寸之地，一人之衆，天子亡所利焉，誠以定治而

<a id="p81"></a>**〔81〕**　<sub>中華本頁 2234a</sub>　已，故天下咸知陛下之廉。地制壹定，宗室子孫莫慮不王，下無倍畔之心，上無誅

<a id="p82"></a>**〔82〕**　<sub>中華本頁 2234a</sub>　伐之志，故天下咸知陛下之仁。法立而不犯，令行而不逆，貫高、利幾之謀不生，柴

<a id="p83"></a>**〔83〕**　<sub>中華本頁 2238a</sub>　奇、開章之計不萌，細民鄉善，大臣致順，故天下咸知陛下之義。臥赤子天下

<a id="p84"></a>**〔84〕**　<sub>中華本頁 2238a</sub>　之上而安，植遺腹，朝委裘，而天下不亂，當時大治，後世誦聖。壹動而五業

<a id="p85"></a>**〔85〕**　<sub>中華本頁 2238a</sub>　附，陛下誰憚而久不為此？

<a id="p176"></a>**〔176〕**　<sub>中華本頁 2253a</sub>　引殷、周、秦事以觀之也？

<a id="p177"></a>**〔177〕**　<sub>中華本頁 2253a</sub>　級，廉近地，則堂卑。高者難攀，卑者易陵，理勢然也。故古者聖王制為等列，內有

<a id="p178"></a>**〔178〕**　<sub>中華本頁 2253a</sub>　公卿大夫士，外有公侯伯子男，然後有官師小吏，延及庶人，等級分明，而天子加

<a id="p179"></a>**〔179〕**　<sub>中華本頁 2253a</sub>　焉，故其尊不可及也。里諺曰：「欲投鼠而忌器。」此善諭也。鼠近於器，尚憚不投，恐

<a id="p180"></a>**〔180〕**　<sub>中華本頁 2253a</sub>　傷其器，況於貴臣之近主乎！廉恥節禮以治君子，故有賜死而亡戮辱。是以黥劓

<a id="p181"></a>**〔181〕**　<sub>中華本頁 2253a</sub>　之辠不及大夫，以其離主上不遠也。禮不敢齒君之路馬，蹴其芻者有罰；見君之

<a id="p182"></a>**〔182〕**　<sub>中華本頁 2255a</sub>　几杖則起，遭君之乘車則下，入正門則趨；君之寵臣雖或有過，刑戮之辠不加其身者，

<a id="p183"></a>**〔183〕**　<sub>中華本頁 2255a</sub>　尊君之故也。此所以為主上豫遠不敬也，所以體貌大臣而厲其節也。今自王侯

<a id="p184"></a>**〔184〕**　<sub>中華本頁 2255a</sub>　三公之貴，皆天子之所改容而禮之也，古天子之所謂伯父、伯舅也，而令與衆庶同

<a id="p185"></a>**〔185〕**　<sub>中華本頁 2255a</sub>　黥劓髠刖笞傌棄巿之法，然則堂不亡陛虖？被戮辱者不泰迫虖？廉恥不行，

<a id="p186"></a>**〔186〕**　<sub>中華本頁 2255a</sub>　大臣無乃握重權，大官而有徒隸亡恥之心虖？夫望夷之事，二世見當以重法者，投

<a id="p187"></a>**〔187〕**　<sub>中華本頁 2255a</sub>　鼠而不忌器之習也。

<a id="p188"></a>**〔188〕**　<sub>中華本頁 2255a</sub>　體貌之矣，吏民嘗俯伏以敬畏之矣，今而有過，帝令廢之可也，退之可也，賜之死可也，

<a id="p189"></a>**〔189〕**　<sub>中華本頁 2255a</sub>　滅之可也；若夫束縛之，係緤之，輸之司寇，編之徒官，司寇小吏詈罵而榜笞

<a id="p190"></a>**〔190〕**　<sub>中華本頁 2255a</sub>　之，殆非所以令衆庶見也。夫卑賤者習知尊貴者之一旦吾亦乃可以加此也，非

<a id="p191"></a>**〔191〕**　<sub>中華本頁 2255a</sub>　所以習天下也，非尊尊貴貴之化也。夫天子之所嘗敬，衆庶之所嘗寵，死而死耳，賤人

<a id="p192"></a>**〔192〕**　<sub>中華本頁 2255a</sub>　安宜得如此而頓辱之哉！

<a id="p193"></a>**〔193〕**　<sub>中華本頁 2255a</sub>　必報襄子，五起而不中。人問豫子，豫子曰：「中行衆人畜我，我故衆人事之；智伯國

<a id="p194"></a>**〔194〕**　<sub>中華本頁 2255a</sub>　士遇我，我故國士報之。」故此一豫讓也，反君事讐，行若狗彘，已而抗節致忠，行出虖

<a id="p195"></a>**〔195〕**　<sub>中華本頁 2255a</sub>　列士，人主使然也。故主上遇其大臣如遇犬馬，彼將犬馬自為也；如遇官徒，彼將官

<a id="p196"></a>**〔196〕**　<sub>中華本頁 2257a</sub>　徒自為也。頑頓亡恥{GJ-C85F}詬亡節，廉恥不立，且不自好，苟若而可，故見利

<a id="p197"></a>**〔197〕**　<sub>中華本頁 2257a</sub>　則逝，見便則奪。主上有敗，則因而挻之矣；主上有患，則吾苟免而已，立而觀

<a id="p198"></a>**〔198〕**　<sub>中華本頁 2257a</sub>　之耳；有便吾身者，則欺賣而利之耳。人主將何便於此？羣下至衆，而主上至少也，

<a id="p199"></a>**〔199〕**　<sub>中華本頁 2257a</sub>　所託財器職業者粹於羣下也。俱亡恥，俱苟妄，則主上最病。故古者禮不及庶人，

<a id="p200"></a>**〔200〕**　<sub>中華本頁 2257a</sub>　刑不至大夫，所以厲寵臣之節也。古者大臣有坐不廉而廢者，不謂不廉，曰「簠簋不

<a id="p201"></a>**〔201〕**　<sub>中華本頁 2257a</sub>　飾」；坐汙穢淫亂男女亡別者，不曰汙穢，曰「帷薄不修」；坐罷軟不勝任者，不謂

<a id="p202"></a>**〔202〕**　<sub>中華本頁 2257a</sub>　罷軟，曰「下官不職」。故貴大臣定有其辠矣，猶未斥然正以謼之也，尚遷就而

<a id="p203"></a>**〔203〕**　<sub>中華本頁 2257a</sub>　為之諱也。故其在大譴大何之域者，聞譴何則白冠氂纓，盤水加劍，造請室而

<a id="p204"></a>**〔204〕**　<sub>中華本頁 2257a</sub>　請辠耳，上不執縛係引而行也。其有中罪者，聞命而自弛，上不使人頸盭而加

<a id="p205"></a>**〔205〕**　<sub>中華本頁 2257a</sub>　也。其有大辠者，聞命則北面再拜，跪而自裁，上不使捽抑而刑之也，曰：「子

<a id="p206"></a>**〔206〕**　<sub>中華本頁 2257a</sub>　大夫自有過耳！吾遇子有禮矣。」遇之有禮，故羣臣自憙；嬰以廉恥，故人矜節

<a id="p207"></a>**〔207〕**　<sub>中華本頁 2257a</sub>　行。上設廉恥禮義以遇其臣，而臣不以節行報其上者，則非人類也。故化成俗定，

<a id="p208"></a>**〔208〕**　<sub>中華本頁 2257a</sub>　則為人臣者主耳忘身，國耳忘家，公耳忘私，利不苟就，害不苟去，唯義所在。上之

<a id="p209"></a>**〔209〕**　<sub>中華本頁 2257a</sub>　化也，故父兄之臣誠死宗廟，法度之臣誠死社稷，輔翼之臣誠死君上，守圄扞敵之臣誠

<a id="p210"></a>**〔210〕**　<sub>中華本頁 2257a</sub>　死城郭封疆。故曰聖人有金城者，比物此志也。彼且為我死，故吾得與之俱生；

<a id="p211"></a>**〔211〕**　<sub>中華本頁 2258a</sub>　彼且為我亡，故吾得與之俱存；夫將為我危，故吾得與之皆安。顧行而忘利，守節

<a id="p212"></a>**〔212〕**　<sub>中華本頁 2258a</sub>　而仗義，故可以託不御之權，可以寄六尺之孤。此厲廉恥行禮誼之所致也，主上

<a id="p213"></a>**〔213〕**　<sub>中華本頁 2258a</sub>　何喪焉！此之不為，而顧彼之久行，故曰可為長太息者此也。

<a id="p214"></a>**〔214〕**　<sub>中華本頁 2258a</sub>　是時丞相絳侯周勃免就國，人有告勃謀反，逮繫長安獄治，卒亡事，復爵邑，故賈誼以此譏上。上深納其言，養臣下有節。是後大臣有罪，皆自殺，不受刑。至武帝時，稍復入獄，自甯成始。

<a id="p215"></a>**〔215〕**　<sub>中華本頁 2258a</sub>　初，文帝以代王入即位，後分代為兩國，立皇子武為代王，參為太原王，小子勝則梁王矣。後又徙代王武為淮陽王，而太原王參為代王，盡得故地。居數年，梁王勝死，亡子。誼復上疏曰：陛下即不定制，如今之勢，不過一傳再傳，諸侯猶且人恣而不制，豪植而大

<a id="p216"></a>**〔216〕**　<sub>中華本頁 2258a</sub>　強，漢法不得行矣。陛下所以為蕃扞及皇太子之所恃者，唯淮陽、代二國耳。代

<a id="p217"></a>**〔217〕**　<sub>中華本頁 2258a</sub>　北邊匈奴，與強敵為鄰。能自完則足矣。而淮陽之比大諸侯，厪如黑子之著面，適

<a id="p218"></a>**〔218〕**　<sub>中華本頁 2258a</sub>　足以餌大國耳，不足以有所禁禦。方今制在陛下，制國而令子適足以為餌，豈可謂

<a id="p219"></a>**〔219〕**　<sub>中華本頁 2258a</sub>　工哉！人主之行異布衣。布衣者，飾小行，競小廉，以自託於鄉黨，人主唯天下安社禝

<a id="p220"></a>**〔220〕**　<sub>中華本頁 2258a</sub>　固不耳。高皇帝瓜分天下以王功臣，反者如蝟毛而起，以為不可，故蔪去不義諸侯

<a id="p221"></a>**〔221〕**　<sub>中華本頁 2258a</sub>　而虛其國。擇良日，立諸子雒陽上東門之外，畢以為王，而天下安。故大人

<a id="p222"></a>**〔222〕**　<sub>中華本頁 2261a</sub>　者，不牽小行，以成大功。

<a id="p223"></a>**〔223〕**　<sub>中華本頁 2261a</sub>　自悉而補，中道衣敝，錢用諸費稱此，其苦屬漢而欲得王至甚，逋逃而歸諸侯

<a id="p224"></a>**〔224〕**　<sub>中華本頁 2261a</sub>　者已不少矣。其勢不可久。臣之愚計，願舉淮南地以益淮陽，而為梁王立後，割淮陽北

<a id="p225"></a>**〔225〕**　<sub>中華本頁 2261a</sub>　邊二三列城與東郡以益梁；不可者，可徙代王而都睢陽。梁起於新郪以北著之

<a id="p226"></a>**〔226〕**　<sub>中華本頁 2261a</sub>　河，淮陽包陳以南揵之江，則大諸侯之有異心者，破膽而不敢謀。梁足以扞齊、

<a id="p227"></a>**〔227〕**　<sub>中華本頁 2261a</sub>　趙，淮陽足以禁吳、楚，陛下高枕，終亡山東之憂矣，此二世之利也。當今恬然，適遇

<a id="p228"></a>**〔228〕**　<sub>中華本頁 2262a</sub>　諸侯之皆少，數歲之後，陛下且見之矣。夫秦日夜苦心勞力以除六國之，今陛下

<a id="p229"></a>**〔229〕**　<sub>中華本頁 2262a</sub>　力制天下，頤指如意，高拱以成六國之，難以言智。苟身亡事，畜亂宿，孰視而

<a id="p230"></a>**〔230〕**　<sub>中華本頁 2262a</sub>　不定，萬年之後，傳之老母弱子，將使不寧，不可謂仁。臣聞聖主言問其臣而不自

<a id="p231"></a>**〔231〕**　<sub>中華本頁 2262a</sub>　造事，故使人臣得畢其愚忠。唯陛下財幸！

<a id="p232"></a>**〔232〕**　<sub>中華本頁 2262a</sub>　時又封淮南厲王四子皆為列侯。誼知上必將復王之也，上疏諫曰：「竊恐陛下接王淮南諸子，曾不與如臣者孰計之也。淮南王之悖逆亡道，天下孰不知其辠？陛下幸而赦遷之，自疾而死，天下孰以王死之不當？今奉尊罪人之子，適足以負謗於天下耳。此人少壯，豈能忘其父哉？白公勝所為父報仇者，大父與伯父、叔父也。白公為亂，非欲取國代主也，發憤快志，剡手以衝仇人之匈，固為俱靡而已。淮南雖小，黥布嘗用之矣，漢存特幸耳。夫擅仇人足以危漢之資，於策不便。雖割而為四，四子一心也。予之衆，積之財，此非有子胥、白公報於廣都之中，即疑有剸諸、荊軻起於兩柱之間，所謂假賊兵為虎翼者也。願陛下少留計！」

<a id="p233"></a>**〔233〕**　<sub>中華本頁 2262a</sub>　梁王勝墜馬死，誼自傷為傅無狀，常哭泣，後歲餘，亦死。賈生之死，年三十三矣。

<a id="p234"></a>**〔234〕**　<sub>中華本頁 2262a</sub>　後四歲，齊文王薨，亡子。文帝思賈生之言，乃分齊為六國，盡立悼惠王子六人為王；又遷淮南王喜於城陽，分淮南為三國，盡立厲王三子以王之。後十年，文帝崩，景帝立，三年而吳、楚、趙與四齊王合從舉兵，西鄉京師，梁王扞之，卒破七國。至武帝時，淮南厲王子為王者兩國亦反誅。

<a id="p235"></a>**〔235〕**　<sub>中華本頁 2262a</sub>　孝武初立，舉賈生之孫二人至郡守。賈嘉最好學，世其家。

<a id="p236"></a>**〔236〕**　<sub>中華本頁 2262a</sub>　贊曰：劉向稱「賈誼言三代與秦治亂之意，其論甚美，通達國體，雖古之伊、管未能遠過也。使時見用，功化必盛。為庸臣所害，甚可悼痛。」追觀孝文玄默躬行以移風俗，誼之所陳略施行矣。及欲改定制度，以漢為土德，色上黃，數用五，及欲試屬國，施五餌三表以係單于，其術固以疏矣。誼（(以夭)）【亦天】年早終，雖不至公卿，未為不遇也。凡所著述五十八篇，掇其切於世事者著于傳云。
