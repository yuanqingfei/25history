# 漢書·卷62　司馬遷傳第三十二

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 2707a</sub>　司馬遷傳第三十二

<a id="p2"></a>**〔2〕**　<sub>中華本頁 2707a</sub>　昔在顓頊，命南正重司天，火正黎司地。唐虞之際，紹重黎之後，使復典之，至于夏商，故重黎氏世序天地。其在周，程伯休甫其後也。當宣王時，官失其守而為司馬氏。司馬氏世典周史。惠襄之間，司馬氏適晉。晉中軍隨會犇魏，而司馬氏入少梁。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 2707a</sub>　自司馬氏去周適晉，分散，或在衞，或在趙，或在秦。其在衞者，相中山。在趙者，以傳劍論顯，蒯聵其後也。在秦者錯，與張儀爭論，於是惠王使錯將兵伐蜀，遂拔，因而守之。錯孫蘄，事武安君白起。而少梁更名夏陽。蘄與武安君阬趙長平軍，還而與之俱賜死杜郵，葬於華池。蘄孫昌，為秦王鐵官。當始皇之時，蒯聵玄孫卬為武信君將而徇朝歌。諸侯之相王，王卬於殷。漢之伐楚，卬歸漢，以其地為河內郡。昌生毋懌，毋懌為漢市長。毋懌生喜，喜為五大夫，卒，皆葬高門。喜生談，談為太史公。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 2707a</sub>　太史公學天官於唐都，受易於楊何，習道論於黃子。太史公仕於建元、元封之間，愍學者不達其意而師誖，乃論六家之要指曰：

<a id="p5"></a>**〔5〕**　<sub>中華本頁 2707a</sub>　務為治者也，直所從言之異路，有省不省耳。嘗竊觀陰陽之術，大詳而衆忌諱，使

<a id="p6"></a>**〔6〕**　<sub>中華本頁 2707a</sub>　人拘而多畏，然其序四時之大順，不可失也。儒者博而寡要，勞而少功，是以其事

<a id="p7"></a>**〔7〕**　<sub>中華本頁 2707a</sub>　難盡從，然其君臣父子之禮，列夫婦長幼之別，不可易也。墨者儉而難遵，是以

<a id="p8"></a>**〔8〕**　<sub>中華本頁 2707a</sub>　其事不可徧循，然其彊本節用，不可廢也。法家嚴而少恩，然其正君臣上下之分，

<a id="p9"></a>**〔9〕**　<sub>中華本頁 2707a</sub>　不可改也。名家使人儉而善失真，然其正名實，不可不察也。道家使人精神專一，

<a id="p10"></a>**〔10〕**　<sub>中華本頁 2707a</sub>　動合無形，澹足萬物，其為術也，因陰陽之大順，采儒墨之善，撮名法之要，與時

<a id="p11"></a>**〔11〕**　<sub>中華本頁 2707a</sub>　遷徙，應物變化，立俗施事，無所不宜，指約而易操，事少而功多。儒者則不然，以

<a id="p12"></a>**〔12〕**　<sub>中華本頁 2707a</sub>　為人主天下之儀表也，君唱臣和，主先臣隨。如此，則主勞而臣佚。至於大道之要，

<a id="p13"></a>**〔13〕**　<sub>中華本頁 2707a</sub>　去健羨，黜聰明，釋此而任術。夫神大用則竭，形大勞則敝；神形蚤衰，欲

<a id="p14"></a>**〔14〕**　<sub>中華本頁 2707a</sub>　與天地長久，非所聞也。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 2707a</sub>　未必然也，故曰「使人拘而多畏」。夫春生夏長，秋收冬臧，此天道之大經也，弗順

<a id="p16"></a>**〔16〕**　<sub>中華本頁 2707a</sub>　則無以為天下紀綱，故曰「四時之大順，不可失也」。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 2712a</sub>　禮，故曰「博而寡要，勞而少功」。若夫列君臣父子之禮，序夫婦長幼之別，雖百家

<a id="p18"></a>**〔18〕**　<sub>中華本頁 2712a</sub>　弗能易也。

<a id="p19"></a>**〔19〕**　<sub>中華本頁 2712a</sub>　土簋，歠土刑，{GJ-C8B6}粱之食，藜藿之羹；夏日葛衣，冬日鹿裘。」其送死，桐棺

<a id="p20"></a>**〔20〕**　<sub>中華本頁 2712a</sub>　三寸，舉音不盡其哀。教喪禮，必以此為萬民率。故天下共若此，則尊卑無別也。夫

<a id="p21"></a>**〔21〕**　<sub>中華本頁 2712a</sub>　世異時移，事業不必同，故曰「儉而難遵」也。要曰彊本節用，則人給家足之道也。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 2712a</sub>　此墨子之所長，雖百家不能廢也。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 2712a</sub>　不可長用也，故曰「嚴而少恩」。若尊主卑臣，明分職不得相踰越，雖百家不能改也。

<a id="p24"></a>**〔24〕**　<sub>中華本頁 2712a</sub>　失真」。若夫控名責實，參伍不失，此不可不察也。

<a id="p25"></a>**〔25〕**　<sub>中華本頁 2712a</sub>　用。無成勢，無常形，故能究萬物之情。不為物先後，故能為萬物主。有法無法，

<a id="p26"></a>**〔26〕**　<sub>中華本頁 2712a</sub>　因時為業；有度無度，因物興舍。故曰「聖人不巧，時變是守」。虛者道之常也，

<a id="p27"></a>**〔27〕**　<sub>中華本頁 2712a</sub>　因者君之綱也。羣臣並至，使各自明也。其實中其聲者謂之端，實不中其聲者謂

<a id="p28"></a>**〔28〕**　<sub>中華本頁 2712a</sub>　之款。款言不聽，姦乃不生，賢不肖自分，白黑乃形。在所欲用耳，何事不成！

<a id="p29"></a>**〔29〕**　<sub>中華本頁 2712a</sub>　乃合大道，混混冥冥。光燿天下，復反無名。凡人所生者神也，所託者形也。

<a id="p30"></a>**〔30〕**　<sub>中華本頁 2712a</sub>　神大用則竭，形大勞則敝，形神離則死。死者不可復生，離者不可復合，故聖人重之。

<a id="p31"></a>**〔31〕**　<sub>中華本頁 2714a</sub>　由此觀之，神者生之本，形者生之具。不先定其神形，而曰「我有以治天下」，何由

<a id="p32"></a>**〔32〕**　<sub>中華本頁 2714a</sub>　哉？

<a id="p33"></a>**〔33〕**　<sub>中華本頁 2714a</sub>　太史公既掌天官，不治民。有子曰遷。

<a id="p34"></a>**〔34〕**　<sub>中華本頁 2714a</sub>　遷生龍門，耕牧河山之陽。年十歲則誦古文。二十而南游江淮，上會稽，探禹穴，窺九疑，浮沅湘。{GJ-A59F}涉汶泗，講業齊魯之都，觀夫子遺風，鄉射鄒嶧；困蕃、薛、彭城，過梁楚以歸。於是遷仕為郎中，奉使西征巴蜀以南，略邛、筰、昆明，還報命。

<a id="p35"></a>**〔35〕**　<sub>中華本頁 2715a</sub>　是歲，天子始建漢家之封，而太史公留滯周南，不得與從事，發憤且卒。而子遷適反，見父於河雒之間。太史公執遷手而泣曰：「予先，周室之太史也。自上世嘗顯功名虞夏，典天官事。後世中衰，絕於予乎？汝復為太史，則續吾祖矣。今天子接千歲之統，封泰山，而予不得從行，是命也夫！命也夫！予死，爾必為太史；為太史，毋忘吾所欲論著矣。且夫孝，始於事親，中於事君，終於立身；揚名於後世，以顯父母，此孝之大也。夫天下稱周公，言其能論歌文武之德，宣周召之風，達大王王季思慮，爰及公劉，以尊后稷也。幽厲之後，王道缺，禮樂衰，孔子脩舊起廢，論詩書，作春秋，則學者至今則之。自獲麟以來四百有餘歲，而諸侯相兼，史記放絕。今漢興，海內壹統，明主賢君，忠臣義士，予為太史而不論載，廢天下之文，予甚懼焉，爾其念哉！」遷俯首流涕曰：「小子不敏，請悉論先人所次舊聞，不敢闕。」卒三歲，而遷為太史令，紬史記石室金鐀之書。五年而當太初元年，十一月甲子朔旦冬至，天曆始改，建於明堂，諸神受記。

<a id="p36"></a>**〔36〕**　<sub>中華本頁 2716a</sub>　太史公曰：「先人有言：『自周公卒五百歲而有孔子，孔子至於今五百歲，有能紹而明之，正易傳，繼春秋，本詩書禮樂之際。』意在斯乎！意在斯乎！小子何敢攘焉！」

<a id="p37"></a>**〔37〕**　<sub>中華本頁 2716a</sub>　上大夫壺遂曰：「昔孔子為何作春秋哉？」太史公曰：「余聞之董生：『周道廢，孔子為魯司寇，諸侯害之，大夫壅之。孔子知時之不用，道之不行也，是非二百四十二年之中，以為天下儀表，貶諸侯，討大夫，以達王事而已矣。』子曰：『我欲載之空言，不如見之於行事之深切著明也。』春秋上明三王之道，下辨人事之經紀，別嫌疑，明是非，定猶與，善善惡惡，賢賢賤不肖，存亡國，繼絕世，補弊起廢，王道之大者也。易著天地陰陽四時五行，故長於變；禮綱紀人倫，故長於行；書記先王之事，故長於政；詩記山川谿谷禽獸草木牝牡雌雄，故長於風；樂樂所以立，故長於和；春秋辯是非，故長於治人。是故禮以節人，樂以發和，書以道事，詩以達意，易以道化，春秋以道義。撥亂世反之正，莫近於春秋。春秋文成數萬，其指數千。萬物之散聚皆在春秋。春秋之中，弒君三十六，亡國五十二，諸侯奔走不得保社稷者不可勝數。察其所以，皆失其本已。故易曰『差以豪氂，謬以千里』。故『臣弒君，子弒父，非一朝一夕之故，其漸久矣』。有國者不可以不知春秋，前有讒而不見，後有賊而不知。為人臣者不可以不知春秋，守經事而不知其宜，遭變事而不知其權。為人君父者而不通於春秋之義者，必蒙首惡之名。為人臣子不通於春秋之義者，必陷篡弒誅死之罪。其實皆以善為之，而不知其義，被之空言不敢辭。夫不通禮義之指，至於君不君，臣不臣，父不父，子不子。夫君不君則犯，臣不臣則誅，父不父則無道，子不子則不孝。此四行者，天下之大過也。以天下大過予之，受而不敢辭。故春秋者，禮義之大宗也。夫禮禁未然之前，法施已然之後；法之所為用者易見，而禮之所為禁者難知。」

<a id="p38"></a>**〔38〕**　<sub>中華本頁 2718a</sub>　壺遂曰：「孔子之時，上無明君，下不得任用，故作春秋，垂空文以斷禮義，當一王之法。今夫子上遇明天子，下得守職，萬事既具，咸各序其宜，夫子所論，欲以何明？」太史公曰：「唯唯，否否，不然。余聞之先人曰：『虙戲至純厚，作易八卦。堯舜之盛，尚書載之，禮樂作焉。湯武之隆，詩人歌之。春秋采善貶惡，推三代之德，襃周室，非獨刺譏而已也。』漢興已來，至明天子，獲符瑞，封禪，改正朔，易服色，受命於穆清，澤流罔極，海外殊俗重譯款塞，請來獻見者，不可勝道。臣下百官力誦聖德，猶不能宣盡其意。且士賢能矣，而不用，有國者恥也；主上明聖，德不布聞，有司之過也。且余掌其官，廢明聖盛德不載，滅功臣賢大夫之業不述，墮先人所言，罪莫大焉。余所謂述故事，整齊其世傳，非所謂作也，而君比之春秋，謬矣。」

<a id="p96"></a>**〔96〕**　<sub>中華本頁 2733a</sub>　且人不能蚤自財繩墨之外，已稍陵夷至於鞭箠之間，乃欲引節，斯不亦遠乎！古人所

<a id="p97"></a>**〔97〕**　<sub>中華本頁 2733a</sub>　以重施刑於大夫者，殆為此也。夫人情莫不貪生惡死，念親戚，顧妻子，至激於義

<a id="p98"></a>**〔98〕**　<sub>中華本頁 2733a</sub>　理者不然，乃有不得已也。今僕不幸，蚤失二親，無兄弟之親，獨身孤立，少卿視僕

<a id="p99"></a>**〔99〕**　<sub>中華本頁 2733a</sub>　於妻子何如哉？且勇者不必死節，怯夫慕義，何處不勉焉！僕雖怯耎欲苟活，

<a id="p100"></a>**〔100〕**　<sub>中華本頁 2733a</sub>　亦頗識去就之分矣，何至自湛溺累紲之辱哉！且夫臧獲婢妾猶能引決，況若僕

<a id="p101"></a>**〔101〕**　<sub>中華本頁 2733a</sub>　之不得已乎！所以隱忍苟活，函糞土之中而不辭者，恨私心有所不盡，鄙沒世而文采

<a id="p102"></a>**〔102〕**　<sub>中華本頁 2733a</sub>　不表於後也。

<a id="p103"></a>**〔103〕**　<sub>中華本頁 2733a</sub>　戹而作春秋；屈原放逐，乃賦離騷；左丘失明，厥有國語；孫子髕脚，兵法修列；

<a id="p104"></a>**〔104〕**　<sub>中華本頁 2733a</sub>　不韋遷蜀，世傳呂覽；韓非囚秦，說難、孤憤。詩三百篇，大氐賢聖發憤之所為

<a id="p105"></a>**〔105〕**　<sub>中華本頁 2733a</sub>　作也。此人皆意有所鬱結，不得通其道，故述往事，思來者。及如左丘明無目，

<a id="p106"></a>**〔106〕**　<sub>中華本頁 2733a</sub>　孫子斷足，終不可用，退論書策以舒其憤，思垂空文以自見。僕竊不遜，近自託於

<a id="p107"></a>**〔107〕**　<sub>中華本頁 2733a</sub>　無能之辭，網羅天下放失舊聞，考之行事，稽其成敗興壞之理，凡百三十篇，亦欲

<a id="p108"></a>**〔108〕**　<sub>中華本頁 2733a</sub>　以究天人之際，通古今之變，成一家之言。草創未就，適會此禍，惜其不成，是以就極

<a id="p109"></a>**〔109〕**　<sub>中華本頁 2733a</sub>　刑而無慍色。僕誠已著此書，藏之名山，傳之其人通邑大都，則僕償前辱之責，雖

<a id="p110"></a>**〔110〕**　<sub>中華本頁 2733a</sub>　萬被戮，豈有悔哉！然此可為智者道，難為俗人言也。

<a id="p111"></a>**〔111〕**　<sub>中華本頁 2736a</sub>　面目復上父母之丘墓乎？雖累百世，垢彌甚耳！是以腸一日而九回，居則忽忽若有所

<a id="p112"></a>**〔112〕**　<sub>中華本頁 2736a</sub>　亡，出則不知所如往。每念斯恥，汗未嘗不發背霑衣也。身直為閨閤之臣，寧得自

<a id="p113"></a>**〔113〕**　<sub>中華本頁 2736a</sub>　引深臧於巖穴邪！故且從俗浮湛，與時俯仰，以通其狂惑。今少卿乃教以推賢進

<a id="p114"></a>**〔114〕**　<sub>中華本頁 2736a</sub>　士，無乃與僕之私指謬乎。今雖欲自彫瑑，曼辭以自解，無益，於俗不信，祗

<a id="p115"></a>**〔115〕**　<sub>中華本頁 2736a</sub>　取辱耳。要之死日，然後是非乃定。書不能盡意，故略陳固陋。

<a id="p116"></a>**〔116〕**　<sub>中華本頁 2736a</sub>　遷既死後，其書稍出。宣帝時，遷外孫平通侯楊惲祖述其書，遂宣布焉。至王莽時，求封遷後，為史通子。

<a id="p117"></a>**〔117〕**　<sub>中華本頁 2736a</sub>　贊曰：自古書契之作而有史官，其載籍博矣。至孔氏之，上（(繼)）【斷】唐堯，下訖秦繆。唐虞以前雖有遺文，其語不經，故言黃帝、顓頊之事未可明也。及孔子因魯史記而作春秋，而左丘明論輯其本事以為之傳，又異同為國語。又有世本，錄黃帝以來至春秋時帝王公侯卿大夫祖世所出。春秋之後，七國並爭，秦兼諸侯，有戰國策。漢興伐秦定天下，有楚漢春秋。故司馬遷據左氏、國語，采世本、戰國策，述楚漢春秋，接其後事，訖于（(大)）【天】漢。其言秦漢，詳矣。至於采經摭傳，分散數家之事，甚多疏略，或有抵梧。亦其涉獵者廣博，貫穿經傳，馳騁古今，上下數千載間，斯以勤矣。又其是非頗繆於聖人，論大道則先黃老而後六經，序遊俠則退處士而進姦雄，述貨殖則崇勢利而羞賤貧，此其所蔽也。然自劉向、揚雄博極羣書，皆稱遷有良史之材，服其善序事理，辨而不華，質而不俚，其文直，其事核，不虛美，不隱惡，故謂之實錄。烏呼！以遷之博物洽聞，而不能以知自全，既陷極刑，幽而發憤，書亦信矣。迹其所以自傷悼，小雅巷伯之倫。夫唯大雅「既明且哲，能保其身」，難矣哉！
