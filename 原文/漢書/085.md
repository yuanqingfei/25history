# 漢書·卷85　谷永杜鄴傳第五十五

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 3443a</sub>　谷永杜鄴傳第五十五

<a id="p2"></a>**〔2〕**　<sub>中華本頁 3443a</sub>　谷永字子雲，長安人也。父吉，為衞司馬，使送郅支單于侍子，為郅支所殺，語在陳湯傳。永少為長安小史，後博學經書。建昭中，御史大夫繁延壽聞其有茂材，除補屬，舉為太常丞，數上疏言得失。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 3443a</sub>　建始三年冬，日食地震同日俱發，詔舉方正直言極諫之士，太常陽城侯劉慶忌舉永待詔公車。對曰：陛下秉至聖之純德，懼天地之戒異，飭身修政，納問公卿，又下明詔，帥舉直

<a id="p4"></a>**〔4〕**　<sub>中華本頁 3443a</sub>　言，燕見紬繹，以求咎愆，使臣等得造明朝，承聖問。臣材朽學淺，不通政事。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 3443a</sub>　竊聞明王即位，正五事，建大中，以承天心，則庶徵序於下，日月理於上；如人

<a id="p6"></a>**〔6〕**　<sub>中華本頁 3444a</sub>　君淫溺後宮，般樂游田，五事失於躬，大中之道不立，則咎徵降而六極至。凡災

<a id="p7"></a>**〔7〕**　<sub>中華本頁 3444a</sub>　異之發，各象過失，以類告人。乃十二月朔戊申，日食婺女之分，地震蕭牆之內，二

<a id="p8"></a>**〔8〕**　<sub>中華本頁 3444a</sub>　者同日俱發，以丁寧陛下，厥咎不遠，宜厚求諸身。意豈陛下志在閨門，未卹政

<a id="p9"></a>**〔9〕**　<sub>中華本頁 3444a</sub>　事，不慎舉錯，婁失中與？內寵大盛，女不遵道，嫉妒專上，妨繼嗣與？古之王

<a id="p10"></a>**〔10〕**　<sub>中華本頁 3444a</sub>　者廢五事之中，失夫婦之紀，妻妾得意，謁行於內，勢行於外，至覆傾國家，或亂陰

<a id="p11"></a>**〔11〕**　<sub>中華本頁 3444a</sub>　陽。昔襃姒用國，宗周以喪；閻妻驕扇，日以不臧。此其效也。經曰：「皇極，

<a id="p12"></a>**〔12〕**　<sub>中華本頁 3444a</sub>　皇建其有極。」傳曰：「皇之不極，是謂不建，時則有日月亂行。」

<a id="p13"></a>**〔13〕**　<sub>中華本頁 3444a</sub>　誠留意於正身，勉強於力行，損燕私之閒以勞天下，放去淫溺之樂，罷歸倡優之

<a id="p14"></a>**〔14〕**　<sub>中華本頁 3444a</sub>　{GJ-F9DE}，絕卻不享之義，慎節游田之虞，起居有常，循禮而動，躬親政事，致行無倦，

<a id="p15"></a>**〔15〕**　<sub>中華本頁 3444a</sub>　安服若性。經曰：「繼自今嗣王，其毋淫于酒，毋逸于游田，惟正之共。」未有身治

<a id="p16"></a>**〔16〕**　<sub>中華本頁 3444a</sub>　正而臣下邪者也。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 3444a</sub>　莊忍絕丹姬，以成伯功；幽王惑於襃姒，周德降亡；魯桓脅於齊女，社稷以傾。

<a id="p18"></a>**〔18〕**　<sub>中華本頁 3444a</sub>　誠修後宮之政，明尊卑之序，貴者不得嫉妬專寵，以絕驕嫚之端，抑襃、閻之亂，賤者咸

<a id="p19"></a>**〔19〕**　<sub>中華本頁 3444a</sub>　得秩進，各得厥職，以廣繼嗣之統，息白華之怨，後宮親屬，饒之以財，勿與政

<a id="p20"></a>**〔20〕**　<sub>中華本頁 3444a</sub>　事，以遠皇父之類，損妻黨之權，未有閨門治而天下亂者也。

<a id="p21"></a>**〔21〕**　<sub>中華本頁 3444a</sub>　事。誠敕正左右齊栗之臣，戴金貂之飾執常伯之職者皆使學先王之道，知君

<a id="p22"></a>**〔22〕**　<sub>中華本頁 3444a</sub>　臣之義，濟濟謹孚，無敖戲驕恣之過，則左右肅艾，羣僚仰法，化流四方。經曰：

<a id="p23"></a>**〔23〕**　<sub>中華本頁 3444a</sub>　「亦惟先正克左右。」未有左右正而百官枉者也。

<a id="p24"></a>**〔24〕**　<sub>中華本頁 3444a</sub>　材選士，必試於職，明度量以程能，考功實以定德，無用比周之虛譽，毋聽潤之譖

<a id="p25"></a>**〔25〕**　<sub>中華本頁 3444a</sub>　愬，則抱功修職之吏無蔽傷之憂，比周邪偽之徒不得即工，小人日銷，俊艾日

<a id="p26"></a>**〔26〕**　<sub>中華本頁 3444a</sub>　隆。經曰：「三載考績，三考黜陟幽明。」又曰：「九德咸事，俊艾在官。」未有功

<a id="p27"></a>**〔27〕**　<sub>中華本頁 3444a</sub>　賞得於前衆賢布於官而不治者也。

<a id="p28"></a>**〔28〕**　<sub>中華本頁 3444a</sub>　無怨於下也。秦居平土，一夫大呼而海內崩析者，刑罰深酷，吏行殘賊也。夫違天

<a id="p29"></a>**〔29〕**　<sub>中華本頁 3444a</sub>　害德，為上取怨於下，莫甚乎殘賊之吏。誠放退殘賊酷暴之吏【錮】廢勿用，益選溫

<a id="p30"></a>**〔30〕**　<sub>中華本頁 3444a</sub>　良上德之士以親萬姓，平刑釋寃以理民命，務省繇役，毋奪民時，薄收賦稅，毋

<a id="p31"></a>**〔31〕**　<sub>中華本頁 3444a</sub>　殫民財，使天下黎元咸安家樂業，不苦踰時之役，不患苛暴之政，不疾酷烈之

<a id="p32"></a>**〔32〕**　<sub>中華本頁 3444a</sub>　吏，雖有唐堯之大災，民無離上之心。經曰：「懷保小人，惠于[⿰魚眾]寡。」未有德

<a id="p33"></a>**〔33〕**　<sub>中華本頁 3444a</sub>　厚吏良而民畔者也。

<a id="p34"></a>**〔34〕**　<sub>中華本頁 3444a</sub>　然簡易，則咎罰不除。經曰：「饗用五福，畏用六極。」傳曰：「六沴作見，若不共御，

<a id="p35"></a>**〔35〕**　<sub>中華本頁 3444a</sub>　六罰既侵，六極其下。」今三年之間，災異鋒起，小大畢具，所行不享上帝，上帝

<a id="p36"></a>**〔36〕**　<sub>中華本頁 3444a</sub>　不豫，炳然甚著。不求之身，無所改正，疏舉廣謀，又不用其言，是循不享之迹，

<a id="p37"></a>**〔37〕**　<sub>中華本頁 3444a</sub>　無謝過之實也，天責愈深。此五者，王事之綱紀，南面之急務，唯陛下留神。

<a id="p38"></a>**〔38〕**　<sub>中華本頁 3444a</sub>　其夏，皆令諸方正對策，語在杜欽傳。永對畢，因曰：「臣前幸得條對災異之效，禍亂所極，言關於聖聰。書陳於前，陛下委棄不納，而更使方正對策，背可懼之大異，問不急之常論，廢承天之至言，角無用之虛文，欲末殺災異，滿讕誣天，是故皇天勃然發怒，甲己之間暴風三溱，拔樹折木，此天至明不可欺之效也。」上特復問永，永對曰：「日食地震，皇后貴妾專寵所致。」語在五行志。

<a id="p39"></a>**〔39〕**　<sub>中華本頁 3451a</sub>　是時，上初即位，謙讓委政元舅大將軍王鳳，議者多歸咎焉。永知鳳方見柄用，陰欲自託，乃復曰：

<a id="p40"></a>**〔40〕**　<sub>中華本頁 3451a</sub>　然，靡有兵革之警。諸侯大者乃食數縣，漢吏制其權柄，不得有為，亡吳、楚、燕、梁

<a id="p41"></a>**〔41〕**　<sub>中華本頁 3451a</sub>　之勢。百官盤互，親疏相錯，骨肉大臣有申伯之忠，洞洞屬屬，小心畏忌，無

<a id="p42"></a>**〔42〕**　<sub>中華本頁 3451a</sub>　重合、安陽、博陸之亂。三者無毛髮之辜，不可歸咎諸舅。此欲以政事過差丞相父

<a id="p43"></a>**〔43〕**　<sub>中華本頁 3451a</sub>　子、中尚書宦官，檻塞大異，皆瞽說欺天者也。竊恐陛下舍昭昭之白過，忽天地之明

<a id="p44"></a>**〔44〕**　<sub>中華本頁 3451a</sub>　戒，聽晻昧之瞽說，歸咎乎無辜，倚異乎政事，重失天心，不可之大者也。

<a id="p45"></a>**〔45〕**　<sub>中華本頁 3451a</sub>　濁四塞，覆冒京師，申以大水，著以震蝕。各有占應，相為表𩹉，百官庶事無所歸倚，

<a id="p46"></a>**〔46〕**　<sub>中華本頁 3451a</sub>　陛下獨不怪與？白氣起東方，賤人將興之表也；黃濁冒京師，王道微絕之應也。夫

<a id="p47"></a>**〔47〕**　<sub>中華本頁 3451a</sub>　賤人當起而京師道微，二者已醜。陛下誠深察愚臣之言，致懼天地之異，長思宗廟

<a id="p48"></a>**〔48〕**　<sub>中華本頁 3451a</sub>　之計，改往反過，抗湛溺之意，解偏駮之愛，奮乾剛之威，平天覆之施，使列妾得人

<a id="p49"></a>**〔49〕**　<sub>中華本頁 3451a</sub>　人更進，猶尚未足也，急復益納宜子婦人，毋擇好醜，毋避嘗字，毋論年齒。推

<a id="p50"></a>**〔50〕**　<sub>中華本頁 3453a</sub>　法言之，陛下得繼嗣於微賤之間，乃反為福。得繼嗣而已，母非有賤也。後宮女史

<a id="p51"></a>**〔51〕**　<sub>中華本頁 3453a</sub>　使令有直意者，廣求於微賤之間，以遇天所開右，慰釋皇太后之憂慍，解謝

<a id="p52"></a>**〔52〕**　<sub>中華本頁 3453a</sub>　上帝之譴怒，則繼嗣蕃滋，災異訖息。陛下則不深察愚臣之言，忽於天地之戒，咎根

<a id="p53"></a>**〔53〕**　<sub>中華本頁 3453a</sub>　不除，水雨之災，山石之異，將發不久；發則災異已極，天變成形，臣雖欲捐身關策，不

<a id="p54"></a>**〔54〕**　<sub>中華本頁 3453a</sub>　及事已。

<a id="p55"></a>**〔55〕**　<sub>中華本頁 3453a</sub>　不免於湯鑊之誅。此天保右漢家，使臣敢直言也。三上封事，然後得召；待詔一旬，

<a id="p56"></a>**〔56〕**　<sub>中華本頁 3453a</sub>　然後得見。夫由疏賤納至忠，甚苦；由至尊聞天意，甚難。語不可露，願具書所言，

<a id="p57"></a>**〔57〕**　<sub>中華本頁 3453a</sub>　因侍中奏陛下，以示腹心大臣。腹心大臣以為非天意，臣當伏妄言之誅；即以為誠

<a id="p58"></a>**〔58〕**　<sub>中華本頁 3453a</sub>　天意也，奈何忘國家大本，背天意而從欲！唯陛下省察熟念，厚為宗廟計。

<a id="p59"></a>**〔59〕**　<sub>中華本頁 3453a</sub>　時對者數十人，永與杜欽為上第焉。上皆以其書示後宮。後上嘗賜許皇后書，采永言以責之，語在外戚傳。

<a id="p60"></a>**〔60〕**　<sub>中華本頁 3453a</sub>　永既陰為大將軍鳳說矣，能實最高，由是擢為光祿大夫。永奏書謝鳳曰：「永斗筲之材，質薄學朽，無一日之雅，左右之介，將軍說其狂言，擢之皂衣之吏，廁之爭臣之末，不聽浸潤之譖，不食膚受之愬，雖齊桓晉文用士篤密，察父悊兄覆育子弟，誠無以加！昔豫子吞炭壞形以奉見異，齊客隕首公門以報恩施，知氏、孟嘗猶有死士，何況將軍之門！」鳳遂厚之。

<a id="p61"></a>**〔61〕**　<sub>中華本頁 3455a</sub>　數年，出為安定太守。時上諸舅皆修經書，任政事。平阿侯譚年次當繼大將軍鳳輔政，尤與永善。陽朔中，鳳薨。鳳病困，薦從弟御史大夫音以自代。上從之，以音為大司馬車騎將軍，領尚書事，而平阿侯譚位特進，領城門兵。永聞之，與譚書曰：「君侯躬周召之德，執管晏之操，敬賢下士，樂善不倦，宜在上將久矣，以大將軍在，故抑鬱於家，不得舒憤。今大將軍不幸蚤薨，絫親疏，序材能，宜在君侯。拜吏之日，京師士大夫悵然失望。此皆永等愚劣，不能襃揚萬（(一)）【分】。屬聞以特進領城門兵，是則車騎將軍秉政雍容于內，而至戚賢舅執管籥於外也。愚竊不為君侯喜。宜深辭職，自陳淺薄不足以固城門之守，收太伯之讓，保謙謙之路，闔門高枕，為知者首。願君侯與博覽者參之，小子為君侯安此。」譚得其書大感，遂辭讓不受領城門職。由是譚、音相與不平。

<a id="p62"></a>**〔62〕**　<sub>中華本頁 3456a</sub>　永遠為郡吏，恐為音所危，病滿三月免。音奏請永補營軍司馬，永數謝罪自陳，得轉為長史。

<a id="p63"></a>**〔63〕**　<sub>中華本頁 3456a</sub>　音用從舅越親輔政，威權損於鳳時。永復說音曰：「將軍履上將之位，食膏腴之都，任周召之職，擁天下之樞，可謂富貴之極，人臣無二，天下之責四面至矣，將何以居之？宜夙夜孳孳，執伊尹之彊德，以守職匡上，誅惡不避親愛，舉善不避仇讎，以章至公，立信四方。篤行三者，乃可以長堪重任，久享盛寵。太白出西方六十日，法當參天，今已過期，尚在桑榆之間，質弱而行遲，形小而光微。熒惑角怒明大，逆行守尾。其逆，常也；守尾，變也。意豈將軍忘湛漸之義，委曲從順，所執不彊，不廣用士，尚有好惡之忌，蕩蕩之德未純，方與將相大臣乖離之萌也？何故始襲司馬之號，俄而金火並有此變？上天至明，不虛見異，唯將軍畏之慎之，深思其故，改求其路，以享天意。」音猶不平，薦永為護菀使者。

<a id="p64"></a>**〔64〕**　<sub>中華本頁 3457a</sub>　音薨，成都侯商代為大司馬衞將軍，永乃遷為涼州刺史。奏事京師訖，當之部，時有黑龍見東萊，上使尚書問永，受所欲言。永對曰：

<a id="p65"></a>**〔65〕**　<sub>中華本頁 3457a</sub>　輒上聞，則商周不易姓而迭興，三正不變改而更用。夏商之將亡也，行道之人

<a id="p66"></a>**〔66〕**　<sub>中華本頁 3457a</sub>　皆知之，晏然自以若天有日莫能危，是故惡日廣而不自知，大命傾而不寤。易

<a id="p67"></a>**〔67〕**　<sub>中華本頁 3457a</sub>　曰：「危者有其安者也，亡者保其存者也。」陛下誠垂寬明之聽，無忌諱之誅，使芻蕘

<a id="p68"></a>**〔68〕**　<sub>中華本頁 3457a</sub>　之臣得盡所聞於前，不懼於後患，直言之路開，則四方衆賢不遠千里，輻湊陳忠，羣臣

<a id="p69"></a>**〔69〕**　<sub>中華本頁 3457a</sub>　之上願，社稷之長福也。

<a id="p70"></a>**〔70〕**　<sub>中華本頁 3457a</sub>　應。未知同姓有見本朝無繼嗣之慶，多危殆之隙，欲因擾亂舉兵而起者邪？將動心冀

<a id="p71"></a>**〔71〕**　<sub>中華本頁 3457a</sub>　為後者，殘賊不仁，若廣陵、昌邑之類？臣愚不能處也。元年九月黑龍見，其晦，日

<a id="p72"></a>**〔72〕**　<sub>中華本頁 3457a</sub>　有食之。今年二月己未夜星隕，乙酉，日有食之。六月之間，大異四發，二而同月，三

<a id="p156"></a>**〔156〕**　<sub>中華本頁 3473a</sub>　永所居任職，為北地太守歲餘，衞將軍商薨，曲陽侯根為票騎將軍，薦永，徵入為大司農。歲餘，永病，三月，有司奏請免。故事，公卿病，輒賜告，至永獨即時免。數月，卒於家。本名並，以尉氏樊並反，更名永云。

<a id="p158"></a>**〔158〕**　<sub>中華本頁 3473a</sub>　與車騎將軍王音善。平阿侯譚不受城門職，後薨，上閔悔之，乃復令譚弟成都侯商位特進，領城門兵，得舉吏如將軍府。鄴見音前與平阿有隙，即說音曰：「鄴聞人情，恩深者其養謹，愛至者其求詳。夫戚而不見殊，孰能無怨？此棠棣、角弓之詩所為作也。昔秦伯有千乘之國，而不能容其母弟，春秋亦書而譏焉。周召則不然，忠以相輔，義以相匡，同己之親，等己之尊，不以聖德獨兼國寵，又不為長專受榮任，分職於陝，並為弼疑。故內無感恨之隙，外無侵侮之羞，俱享天祐，兩荷高名者，蓋以此也。竊見成都侯以特進領城門兵，復有詔得舉吏如五府，此明詔所欲寵也。將軍宜承順聖意，加異往時，每事凡議，必與及之，指為誠發，出於將軍，則孰敢不說諭？昔文侯寤大鴈之獻而父子益親，陳平共壹飯之而將相加驩，所接雖在楹階俎豆之間，其於為國折衝厭難，豈不遠哉！竊慕倉唐、陸子之義，所白ミ內，唯深察焉。」音甚嘉其言，由是與成都侯商親密，二人皆重鄴。後以病去郎。商為大司馬衞將軍，除鄴主簿，以為腹心，舉侍御史。哀帝即位，遷為涼州刺史。鄴居職寬舒，少威嚴，數年以病免。

<a id="p159"></a>**〔159〕**　<sub>中華本頁 3474a</sub>　是時，帝祖母定陶傅太后稱皇太太后，帝母丁姬稱帝太后，而皇后即傅太后從弟子也。傅氏侯者三人，丁氏侯者二人。又封傅太后同母弟子鄭業為陽信侯。傅太后尤與政專權。元壽元年正月朔，上以皇后父孔鄉侯傅晏為大司馬衞將軍，而帝舅陽安侯丁明為大司馬票騎將軍。臨拜，日食，詔舉方正直言。扶陽侯韋育舉鄴方正，鄴對曰：

<a id="p160"></a>**〔160〕**　<sub>中華本頁 3474a</sub>　者之危，敢不極陳！臣聞陽尊陰卑，卑者隨尊，尊者兼卑，天之道也。是以男雖賤，各為

<a id="p161"></a>**〔161〕**　<sub>中華本頁 3474a</sub>　其家陽；女雖貴，猶為其國陰。故禮明三從之義，雖有文母之德，必繫於子。春

<a id="p162"></a>**〔162〕**　<sub>中華本頁 3474a</sub>　秋不書紀侯之母，陰義殺也。昔鄭伯隨姜氏之欲，終有叔段篡國之禍；周襄王內迫

<a id="p163"></a>**〔163〕**　<sub>中華本頁 3474a</sub>　惠后之難，而遭居鄭之危。漢興，呂太后權私親屬，又以外孫為孝惠后，是時繼嗣不

<a id="p164"></a>**〔164〕**　<sub>中華本頁 3476a</sub>　明，凡事多晻，晝昏冬雷之變，不可勝載。竊見陛下行不偏之政，每事約儉，非禮不

<a id="p165"></a>**〔165〕**　<sub>中華本頁 3476a</sub>　動，誠欲正身與天下更始也。然嘉瑞未應，而日食地震，民訛言行籌，傳相驚恐。案春秋

<a id="p166"></a>**〔166〕**　<sub>中華本頁 3476a</sub>　災異，以指象為言語，故在於得一類而達之也。日食，明陽為陰所臨，坤卦乘離，明

<a id="p167"></a>**〔167〕**　<sub>中華本頁 3476a</sub>　夷之象也。坤以法地，為土為母，以安靜為德。震，不陰之效也。占象甚明，臣敢

<a id="p168"></a>**〔168〕**　<sub>中華本頁 3476a</sub>　不直言其事！

<a id="p169"></a>**〔169〕**　<sub>中華本頁 3476a</sub>　非理者，故無可間也。前大司馬新都侯莽退伏弟家，以詔策決，復遣就國。高昌侯

<a id="p170"></a>**〔170〕**　<sub>中華本頁 3476a</sub>　宏去蕃自絕，猶受封土。制書侍中駙馬都尉遷不忠巧佞，免歸故郡，間未旬月，

<a id="p171"></a>**〔171〕**　<sub>中華本頁 3476a</sub>　則有詔還，大臣奏正其罰，卒不得遣，而反兼官奉使，顯寵過故。及陽信侯業，皆緣私

<a id="p172"></a>**〔172〕**　<sub>中華本頁 3476a</sub>　君國，非功義所止。諸外家昆弟無賢不肖，並侍帷幄，布在列位，或典兵衞，或將

<a id="p173"></a>**〔173〕**　<sub>中華本頁 3476a</sub>　軍屯，寵意并於一家，積貴之勢，世所希見所希聞也。至乃并置大司馬將軍之官。皇

<a id="p174"></a>**〔174〕**　<sub>中華本頁 3476a</sub>　甫雖盛，三桓雖隆，魯為作三軍，無以甚此。當拜之日，晻然日食。不在前後，臨事

<a id="p175"></a>**〔175〕**　<sub>中華本頁 3476a</sub>　而發者，明陛下謙遜無專，承指非一，所言輒聽，所欲輒隨，有罪惡者不坐辜罰，無

<a id="p176"></a>**〔176〕**　<sub>中華本頁 3476a</sub>　功能者畢受官爵，流漸積猥，正尤在是，欲令昭昭以覺聖朝。昔詩人所刺，春秋所

<a id="p177"></a>**〔177〕**　<sub>中華本頁 3476a</sub>　譏，指象如此，殆不在它。由後視前，忿邑非之，逮身所行，不自鏡見，則以為可，

<a id="p178"></a>**〔178〕**　<sub>中華本頁 3476a</sub>　計之過者。疏賤獨偏見，疑內亦有此類。天變不空，保右世主如此之至，奈何不

<a id="p179"></a>**〔179〕**　<sub>中華本頁 3476a</sub>　應！

<a id="p180"></a>**〔180〕**　<sub>中華本頁 3476a</sub>　初，事稽諸古，以厭下心，則黎庶羣生無不說喜，上帝百神收還威怒，禎祥福

<a id="p181"></a>**〔181〕**　<sub>中華本頁 3476a</sub>　祿何嫌不報！

<a id="p182"></a>**〔182〕**　<sub>中華本頁 3476a</sub>　鄴未拜，病卒。鄴言民訛言行籌，及谷永言王者買私田，彗星隕石牡飛之占，語在五行志。

<a id="p183"></a>**〔183〕**　<sub>中華本頁 3476a</sub>　初，鄴從張吉學，吉子竦又幼孤，從鄴學問，亦著於世，尤長小學。鄴子林，清靜好古，亦有雅材，建武中歷位列卿，至大司空。其正文字過於鄴、竦，故世言小學者由杜公。

<a id="p184"></a>**〔184〕**　<sub>中華本頁 3476a</sub>　贊曰：孝成之世，委政外家，諸舅持權，重於丁、傅在孝哀時。故杜鄴敢譏丁、傅，而欽、永不敢言王氏，其勢然也。及欽欲挹損鳳權，而鄴附會音、商。永陳三七之戒，斯為忠焉，至其引申伯以阿鳳，隙平阿於車騎，指金火以求合，可謂諒不足而談有餘者。孔子稱「友多聞」，三人近之矣。
