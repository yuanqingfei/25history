# 汉书·卷7　昭帝纪第七

<a id="p1"></a>**〔1〕**　<sub>中华本页 0217a</sub>　昭帝纪第七

<a id="p2"></a>**〔2〕**　<sub>中华本页 0217a</sub>　孝昭皇帝，武帝少子也。母曰赵{GJ-FB87}伃，本以有奇异得幸，及生帝，亦奇异。语在外戚传。武帝末，戾太子败，燕王旦、广陵王胥行骄嫚，后元二年二月上疾病，遂立昭帝为太子，年八岁。以侍中奉车都尉霍光为大司马大将军，受遗诏辅少主。明日，武帝崩。戊辰，太子即皇帝位，谒高庙。帝姊鄂邑公主益汤沐邑，为长公主，共养省中。大将军光秉政，领尚书事，车骑将军金日䃅、左将军上官桀副焉。

<a id="p3"></a>**〔3〕**　<sub>中华本页 0217a</sub>　夏六月，赦天下。

<a id="p4"></a>**〔4〕**　<sub>中华本页 0217a</sub>　秋七月，有星孛于东方。

<a id="p5"></a>**〔5〕**　<sub>中华本页 0217a</sub>　济北王宽有罪，自杀。

<a id="p6"></a>**〔6〕**　<sub>中华本页 0217a</sub>　赐长公主及宗室昆弟各有差。追尊赵{GJ-FB87}伃为皇太后，起云陵。

<a id="p7"></a>**〔7〕**　<sub>中华本页 0217a</sub>　冬，匈奴入朔方，杀略吏民。发军屯西河，左将军桀行北边。

<a id="p8"></a>**〔8〕**　<sub>中华本页 0217a</sub>　始元元年春二月，黄鹄下建章宫太液池中。公卿上寿。赐诸侯王、列侯、宗室金钱各有差。

<a id="p9"></a>**〔9〕**　<sub>中华本页 0217a</sub>　己亥，上耕于钩盾弄田。

<a id="p10"></a>**〔10〕**　<sub>中华本页 0217a</sub>　益封燕王、广陵王及鄂邑长公主各万三千户。

<a id="p11"></a>**〔11〕**　<sub>中华本页 0217a</sub>　夏，为太后起园庙云陵。

<a id="p12"></a>**〔12〕**　<sub>中华本页 0217a</sub>　益州廉头、姑缯、牂柯谈指、同并二十四邑皆反。遣水衡都尉吕破胡募吏民及发犍为、蜀郡犇命击益州，大破之。

<a id="p13"></a>**〔13〕**　<sub>中华本页 0217a</sub>　有司请河内属冀州，河东属并州。

<a id="p14"></a>**〔14〕**　<sub>中华本页 0217a</sub>　秋七月，赦天下，赐民百户牛酒。大雨，渭桥绝。

<a id="p15"></a>**〔15〕**　<sub>中华本页 0217a</sub>　八月，齐孝王孙刘泽谋反，欲杀青州刺史隽不疑，发觉，皆伏诛。迁不疑为京兆尹，赐钱百万。

<a id="p16"></a>**〔16〕**　<sub>中华本页 0220a</sub>　九月丙子，车骑将军日䃅薨。

<a id="p17"></a>**〔17〕**　<sub>中华本页 0220a</sub>　闰月，遣故廷尉王平等五人持节行郡国，举贤良，问民所疾苦、冤、失职者。

<a id="p18"></a>**〔18〕**　<sub>中华本页 0220a</sub>　冬，无冰。

<a id="p19"></a>**〔19〕**　<sub>中华本页 0220a</sub>　二年春正月，大将军光、左将军桀皆以前捕斩反虏重合侯马通功封，光为博陆侯，桀为安阳侯。

<a id="p20"></a>**〔20〕**　<sub>中华本页 0220a</sub>　以宗室毋在位者，举茂才刘辟彊、刘长乐皆为光禄大夫，辟彊守长乐衞尉。

<a id="p21"></a>**〔21〕**　<sub>中华本页 0220a</sub>　三月，遣使者振贷贫民毋种、食者。秋八月，诏曰：“往年灾害多，今年蚕麦伤，所振贷种、食勿收责，毋令民出今年田租。”

<a id="p22"></a>**〔22〕**　<sub>中华本页 0220a</sub>　冬，发习战射士诣朔方，调故吏将屯田张掖郡。

<a id="p23"></a>**〔23〕**　<sub>中华本页 0220a</sub>　三年春二月，有星孛于西北。

<a id="p24"></a>**〔24〕**　<sub>中华本页 0220a</sub>　秋，募民徙云陵，赐钱田宅。

<a id="p25"></a>**〔25〕**　<sub>中华本页 0220a</sub>　冬十月，凤皇集东海，遣使者祠其处。

<a id="p26"></a>**〔26〕**　<sub>中华本页 0220a</sub>　十一月壬辰朔，日有蚀之。

<a id="p27"></a>**〔27〕**　<sub>中华本页 0220a</sub>　四年春三月甲寅，立皇后上官氏。赦天下。辞讼在后二年前，皆勿听治。夏六月，皇后见高庙。赐长公主、丞相、将军、列侯、中二千石以下及郎吏宗室钱帛各有差。

<a id="p28"></a>**〔28〕**　<sub>中华本页 0220a</sub>　徙三辅富人云陵，赐钱，户十万。

<a id="p29"></a>**〔29〕**　<sub>中华本页 0220a</sub>　秋七月，诏曰：“比岁不登，民匮于食，流庸未尽还，往时令民共出马，其止勿出。诸给中都官者，且减之。”

<a id="p30"></a>**〔30〕**　<sub>中华本页 0222a</sub>　冬，遣大鸿胪田广明击益州。

<a id="p31"></a>**〔31〕**　<sub>中华本页 0222a</sub>　廷尉李种坐故纵死罪弃市。

<a id="p32"></a>**〔32〕**　<sub>中华本页 0222a</sub>　五年春正月，追尊皇太后父为顺成侯。

<a id="p33"></a>**〔33〕**　<sub>中华本页 0222a</sub>　夏阳男子张延年诣北阙，自称衞太子，诬罔，要斩。

<a id="p34"></a>**〔34〕**　<sub>中华本页 0222a</sub>　夏，罢天下亭母马及马弩关。

<a id="p35"></a>**〔35〕**　<sub>中华本页 0222a</sub>　六月，封皇后父骠骑将军上官安为桑乐侯。

<a id="p36"></a>**〔36〕**　<sub>中华本页 0222a</sub>　诏曰：“朕以眇身获保宗庙，战战栗栗，夙兴夜寐，修古帝王之事，通保傅，传孝经、论语、尚书，未云有明。其令三辅、太常举贤良各二人，郡国文学高第各一人。赐中二千石以下至吏民爵各有差。”

<a id="p37"></a>**〔37〕**　<sub>中华本页 0222a</sub>　罢儋耳、真番郡。

<a id="p38"></a>**〔38〕**　<sub>中华本页 0222a</sub>　秋，大鸿胪广明、军正王平击益州，斩首捕虏三万余人，获畜产五万余头。

<a id="p39"></a>**〔39〕**　<sub>中华本页 0222a</sub>　六月春正月，上耕于上林。

<a id="p40"></a>**〔40〕**　<sub>中华本页 0222a</sub>　二月，诏有司问郡国所举贤良文学民所疾苦。议罢盐铁榷酤。

<a id="p41"></a>**〔41〕**　<sub>中华本页 0222a</sub>　栘中监苏武前使匈奴，留单于庭十九岁乃还，奉使全节，以武为典属国，赐钱百万。

<a id="p42"></a>**〔42〕**　<sub>中华本页 0224a</sub>　夏，旱，大雩，大得举火。

<a id="p43"></a>**〔43〕**　<sub>中华本页 0224a</sub>　秋七月，罢榷酤官，令民得以律占租，卖酒升四钱。以边塞阔远，取天水、陇西、张掖郡各二县置金城郡。

<a id="p44"></a>**〔44〕**　<sub>中华本页 0224a</sub>　诏曰：“钩町侯毋波率其君长人民击反者，斩首捕虏有功。其立毋波为钩町王。大鸿胪广明将率有功，赐爵关内侯，食邑。”

<a id="p45"></a>**〔45〕**　<sub>中华本页 0224a</sub>　元凤元年春，长公主共养劳苦，复以蓝田益长公主汤沐邑。

<a id="p46"></a>**〔46〕**　<sub>中华本页 0224a</sub>　泗水戴王前薨，以毋嗣，国除。后宫有遗腹子煖，相、内史不奏言，上闻而怜之，立煖为泗水王。相、内史皆下狱。

<a id="p47"></a>**〔47〕**　<sub>中华本页 0224a</sub>　三月，赐郡国所选有行义者涿郡韩福等五人帛，人五十匹，遣归。诏曰：“朕闵劳以官职之事，其务修孝弟以教乡里。令郡县常以正月赐羊酒。有不幸者赐衣被一袭，祠以中牢。”

<a id="p48"></a>**〔48〕**　<sub>中华本页 0224a</sub>　武都氐人反，遣执金吾马适建、龙侯韩增、大鸿胪广明将三辅、太常徒，皆免刑击之。

<a id="p49"></a>**〔49〕**　<sub>中华本页 0224a</sub>　夏六月，赦天下。

<a id="p50"></a>**〔50〕**　<sub>中华本页 0224a</sub>　秋七月乙亥晦，日有蚀之，既。

<a id="p51"></a>**〔51〕**　<sub>中华本页 0224a</sub>　八月，改始元为元凤。

<a id="p52"></a>**〔52〕**　<sub>中华本页 0224a</sub>　九月，鄂邑长公主、燕王旦与左将军上官桀、桀子票骑将军安、御史大夫桑弘羊皆谋反，伏诛。初，桀、安父子与大将军光争权，欲害之，诈使人为燕王旦上书言光罪。时上年十四，觉其诈。后有谮光者，上辄怒曰：“大将军国家忠臣，先帝所属，敢有谮毁者，坐之。”光由是得尽忠。语在燕王、霍光传。

<a id="p53"></a>**〔53〕**　<sub>中华本页 0224a</sub>　冬十月，诏曰：“左将军安阳侯桀、票骑将军桑乐侯安、御史大夫弘羊皆数以邪枉干辅政，大将军不听，而怀怨望，与燕王通谋，置驿往来相约结。燕王遣寿西长、孙纵之等赂遗长公主、丁外人、谒者杜延年、大将军长史公孙遗等，交通私书，共谋令长公主置酒，伏兵杀大将军光，征立燕王为天子，大逆毋道。故稻田使者燕仓先发觉，以告大司农敞，敞告谏大夫延年，延年以闻。丞相征事任宫手捕斩桀，丞相少史王寿诱将安入府门，皆已伏诛，吏民得以安。封延年、仓、宫、寿皆为列侯。”又曰：“燕王迷惑失道，前与齐王子刘泽等为逆，抑而不扬，望王反道自新，今乃与长公主及左将军桀等谋危宗庙。王及公主皆自伏辜。其赦王太子建、公主子文信及宗室子与燕王、上官桀等谋反父母同产当坐者，皆免为庶人。其吏为桀等所诖误，未发觉在吏者，除其罪。”

<a id="p54"></a>**〔54〕**　<sub>中华本页 0227a</sub>　二年夏四月，上自建章宫徙未央宫，大置酒。赐郎从官帛，及宗室子钱，人二十万。吏民献牛酒者赐帛，人一匹。

<a id="p55"></a>**〔55〕**　<sub>中华本页 0227a</sub>　六月，赦天下。诏曰：“朕闵百姓未赡，前年减漕三百万石。颇省乘舆马及（(菀)）【苑】马，以补边郡三辅传马。其令郡国毋敛今年马口钱，三辅、太常郡得以叔粟当赋。”

<a id="p56"></a>**〔56〕**　<sub>中华本页 0227a</sub>　三年春正月，泰山有大石自起立，上林有柳树枯僵自起生。

<a id="p57"></a>**〔57〕**　<sub>中华本页 0229a</sub>　罢中牟苑赋贫民。诏曰：“乃者民被水灾，颇匮于食，朕虚仓廪，使使者振困乏。其止四年毋漕。三年以前所振贷，非丞相御史所请，边郡受牛者勿收责。”

<a id="p58"></a>**〔58〕**　<sub>中华本页 0229a</sub>　夏四月，少府徐仁、廷尉王平、左冯翊贾胜胡皆坐纵反者，仁自杀，平、胜胡皆要斩。

<a id="p59"></a>**〔59〕**　<sub>中华本页 0229a</sub>　冬，辽东乌桓反，以中郎将范明友为度辽将军，将北边七郡郡二千骑击之。

<a id="p60"></a>**〔60〕**　<sub>中华本页 0229a</sub>　四年春正月丁亥，帝加元服，见于高庙。赐诸侯王、丞相、大将军、列侯、宗室下至吏民金帛牛酒各有差。赐中二千石以下及天下民爵。毋收四年、五年口赋。三年以前逋更赋未入者，皆勿收。令天下酺五日。

<a id="p61"></a>**〔61〕**　<sub>中华本页 0229a</sub>　甲戌，丞相千秋薨。

<a id="p62"></a>**〔62〕**　<sub>中华本页 0229a</sub>　夏四月，诏曰：“度辽将军明友前以羌骑校尉将羌王侯君长以下击益州反虏，后复率击武都反氐，今破乌桓，斩虏获生，有功。其封明友为平陵侯。平乐监傅介子持节使，诛斩楼兰王安，归首县北阙，封义阳侯。”

<a id="p63"></a>**〔63〕**　<sub>中华本页 0229a</sub>　五月丁丑，孝文庙正殿火，上及群臣皆素服。发中二千石将五校作治，六日成。太常及庙令丞郎吏皆劾大不敬，会赦，太常轑阳侯德免为庶人。

<a id="p64"></a>**〔64〕**　<sub>中华本页 0231a</sub>　六月，赦天下。

<a id="p65"></a>**〔65〕**　<sub>中华本页 0231a</sub>　五年春正月，广陵王来朝，益国万一千户，赐钱二千万，黄金二百斤，剑二，安车一，乘马二驷。

<a id="p66"></a>**〔66〕**　<sub>中华本页 0231a</sub>　夏，大旱。

<a id="p67"></a>**〔67〕**　<sub>中华本页 0231a</sub>　六月，发三辅及郡国恶少年吏有告劾亡者，屯辽东。

<a id="p68"></a>**〔68〕**　<sub>中华本页 0231a</sub>　秋，罢象郡，分属郁林、牂柯。

<a id="p69"></a>**〔69〕**　<sub>中华本页 0231a</sub>　冬十一月，大雷。

<a id="p70"></a>**〔70〕**　<sub>中华本页 0231a</sub>　十二月庚戌，丞相䜣薨。

<a id="p71"></a>**〔71〕**　<sub>中华本页 0231a</sub>　六年春正月，募郡国徒筑辽东玄菟城。夏，赦天下。诏曰：“夫谷贱伤农，今三辅、太常谷减贱，其令以叔粟当今年赋。”

<a id="p72"></a>**〔72〕**　<sub>中华本页 0231a</sub>　右将军张安世宿衞忠谨，封富平侯。

<a id="p73"></a>**〔73〕**　<sub>中华本页 0231a</sub>　乌桓复犯塞，遣度辽将军范明友击之。

<a id="p74"></a>**〔74〕**　<sub>中华本页 0231a</sub>　元平元年春二月，诏曰：“天下以农桑为本。日者省用，罢不急官，减外繇，耕桑者益众，而百姓未能家给，朕甚愍焉。其减口赋钱。”有司奏请减什三，上许之。

<a id="p75"></a>**〔75〕**　<sub>中华本页 0231a</sub>　甲申，晨有流星，大如月，众星皆随西行。

<a id="p76"></a>**〔76〕**　<sub>中华本页 0231a</sub>　夏四月癸未，帝崩于未央宫。六月壬申，葬平陵。

<a id="p77"></a>**〔77〕**　<sub>中华本页 0233a</sub>　赞曰：昔周成以孺子继统，而有管、蔡四国流言之变。孝昭幼年即位，亦有燕、盍、上官逆乱之谋。成王不疑周公，孝昭委任霍光，各因其时以成名，大矣哉！承孝武奢侈余敝师旅之后，海内虚耗，户口减半，光知时务之要，轻繇薄赋，与民休息。至始元、元凤之间，匈奴和亲，百姓充实。举贤良文学，问民所疾苦，议盐铁而罢榷酤，尊号曰“昭”，不亦宜乎！
