<a id="p1"></a>**〔1〕**　<sub>中华本页 2327a</sub>　贾邹枚路传第二十一

<a id="p2"></a>**〔2〕**　<sub>中华本页 2327a</sub>　贾山，颍川人也。祖父（(祛)）【袪】，故魏王时博士弟子也。山受学（(祛)）【袪】，所言涉猎书记，不能为醇儒。尝给事颍阴侯为骑。

<a id="p3"></a>**〔3〕**　<sub>中华本页 2327a</sub>　孝文时，言治乱之道，借秦为谕，名曰至言。其辞曰：臣闻为人臣者，尽忠竭愚，以直谏主，不避死亡之诛者，臣山是也。臣不敢以久远

<a id="p4"></a>**〔4〕**　<sub>中华本页 2327a</sub>　谕，愿借秦以为谕，唯陛下少加意焉。夫布衣韦带之士，修身于内，成名于外，而使后世不绝息。至秦则不然。贵

<a id="p5"></a>**〔5〕**　<sub>中华本页 2327a</sub>　为天子，富有天下，赋敛重数，百姓任罢，赭衣半道，群盗满山，使天下之人戴目

<a id="p6"></a>**〔6〕**　<sub>中华本页 2328a</sub>　而视，倾耳而听。一夫大謼，天下向应者，陈胜是也。秦非徒如此也，起咸阳而

<a id="p7"></a>**〔7〕**　<sub>中华本页 2328a</sub>　西至雍，离宫三百，钟鼓帷帐，不移而具。又为阿房之殿，殿高数十仞，东西五

<a id="p8"></a>**〔8〕**　<sub>中华本页 2328a</sub>　里，南北千步，从车罗骑，四马骛驰，旌旗不桡。为宫室之丽至于此，使其后世曾不

<a id="p9"></a>**〔9〕**　<sub>中华本页 2328a</sub>　得聚庐而托处焉。为驰道于天下，东穷燕齐，南极吴楚，江湖之上，濒海之观毕至。

<a id="p10"></a>**〔10〕**　<sub>中华本页 2328a</sub>　道广五十步，三丈而树，厚筑其外，隐以金椎，树以青松。为驰道之丽至于此，使

<a id="p11"></a>**〔11〕**　<sub>中华本页 2328a</sub>　其后世曾不得邪径而托足焉。死葬乎骊山，吏徒数十万人，旷日十年。下彻三

<a id="p12"></a>**〔12〕**　<sub>中华本页 2328a</sub>　泉合采金石，冶铜锢其内，桼涂其外，被以珠玉，饰以翡翠，中成观游，上成

<a id="p13"></a>**〔13〕**　<sub>中华本页 2328a</sub>　山林。为葬薶之侈至于此，使其后世曾不得蓬颗蔽冢而托葬焉。秦以熊罴之力，虎

<a id="p14"></a>**〔14〕**　<sub>中华本页 2328a</sub>　狼之心，蚕食诸侯，并吞海内，而不笃礼义，故天殃已加矣。臣昧死以闻，愿陛下少

<a id="p15"></a>**〔15〕**　<sub>中华本页 2328a</sub>　留意而详择其中。

<a id="p16"></a>**〔16〕**　<sub>中华本页 2328a</sub>　主所欲急闻，忠臣之所以蒙死而竭知也。地之硗者，虽有善种，不能生焉；江皋

<a id="p17"></a>**〔17〕**　<sub>中华本页 2330a</sub>　河濒，虽有恶种，无不猥大。昔者夏商之季世，虽关龙逢、箕子、比干之贤，身死

<a id="p18"></a>**〔18〕**　<sub>中华本页 2330a</sub>　亡而道不用。文王之时，豪俊之士皆得竭其智，刍荛采薪之人皆得尽其力，此

<a id="p19"></a>**〔19〕**　<sub>中华本页 2330a</sub>　周之所以兴也。故地之美者善养禾，君之仁者善养士。雷霆之所击，无不摧折者；

<a id="p20"></a>**〔20〕**　<sub>中华本页 2330a</sub>　万钧之所压，无不糜灭者。今人主之威，非特雷霆也；势重，非特万钧也。开道而

<a id="p21"></a>**〔21〕**　<sub>中华本页 2330a</sub>　求谏，和颜色而受之，用其言而显其身，士犹恐惧而不敢自尽，又乃况于纵欲恣行暴

<a id="p23"></a>**〔23〕**　<sub>中华本页 2330a</sub>　哉？如此，则人主不得闻其过失矣；弗闻，则社稷危矣。古者圣王之制，史在前书

<a id="p24"></a>**〔24〕**　<sub>中华本页 2330a</sub>　过失，工诵箴谏，瞽诵诗谏，公卿比谏，士传言谏（(过)），庶人谤于道，商旅议于

<a id="p25"></a>**〔25〕**　<sub>中华本页 2330a</sub>　市，然后君得闻其过失也。闻其过失而改之，见义而从之，所以永有天下也。天子

<a id="p26"></a>**〔26〕**　<sub>中华本页 2330a</sub>　之尊，四海之内，其义莫不为臣。然而养三老于大学，亲执酱而餽，执爵而酳，祝{GJ-C879}

<a id="p27"></a>**〔27〕**　<sub>中华本页 2330a</sub>　在前，祝鲠在后，公卿奉杖，大夫进履，举贤以自辅弼，求修正之士使直谏。故

<a id="p28"></a>**〔28〕**　<sub>中华本页 2330a</sub>　以天子之尊，尊养三老，视孝也；立辅弼之臣者，恐骄也；置直谏之士者，恐不得

<a id="p29"></a>**〔29〕**　<sub>中华本页 2330a</sub>　闻其过也；学问至于刍荛者，求善无餍也；商人庶人诽谤己而改之，从善无不听也。

<a id="p30"></a>**〔30〕**　<sub>中华本页 2330a</sub>　小之势，轻重之权，其与一家之富，一夫之彊，胡可胜计也！然而兵破于陈涉，地夺

<a id="p31"></a>**〔31〕**　<sub>中华本页 2332a</sub>　于刘氏者，何也？秦王贪狼暴虐，残贼天下，穷困万民，以适其欲也。昔者，周盖千

<a id="p32"></a>**〔32〕**　<sub>中华本页 2332a</sub>　八百国，以九州之民养千八百国之君，用民之力不过岁三日，什一而籍，君有余财，

<a id="p34"></a>**〔34〕**　<sub>中华本页 2332a</sub>　其求。一君之身耳，所以自养者驰骋弋猎之娱，天下弗能供也。劳罢者不得休

<a id="p35"></a>**〔35〕**　<sub>中华本页 2332a</sub>　息，饥寒者不得衣食，亡罪而死刑者无所告诉，人与之为怨，家与之为雠，故天下坏

<a id="p36"></a>**〔36〕**　<sub>中华本页 2332a</sub>　也。秦皇帝身在之时，天下已坏矣，而弗自知也。秦皇帝东巡狩，至会稽、琅邪，刻石著

<a id="p37"></a>**〔37〕**　<sub>中华本页 2332a</sub>　其功，自以为过尧舜统；县石铸钟虡，筛土筑阿房之宫，自以为万世有天下

<a id="p38"></a>**〔38〕**　<sub>中华本页 2332a</sub>　也。古者圣王作谥，三四十世耳，虽尧舜禹汤文武絫{GJ-A530}广德以为子孙基业，无过二

<a id="p39"></a>**〔39〕**　<sub>中华本页 2332a</sub>　三十世者也。秦皇帝曰死而以谥法，是父子名号有时相袭也，以一至万，则世世不

<a id="p41"></a>**〔41〕**　<sub>中华本页 2332a</sub>　度其后嗣，世世无穷，然身死才数月耳，天下四面而攻之，宗庙灭绝矣。

<a id="p42"></a>**〔42〕**　<sub>中华本页 2332a</sub>　养老之义，亡辅弼之臣，亡进谏之士，纵恣行诛，退诽谤之人，杀直谏之士，是以道

<a id="p43"></a>**〔43〕**　<sub>中华本页 2332a</sub>　谀媮合苟容，比其德则贤于尧舜，课其功则贤于汤武，天下已溃而莫之告也。

<a id="p44"></a>**〔44〕**　<sub>中华本页 2334a</sub>　诗曰：“匪言不能，胡此畏忌，听言则对，谮言则退。”此之谓也。又曰：“济济多士，

<a id="p45"></a>**〔45〕**　<sub>中华本页 2334a</sub>　文王以宁。”天下未尝亡士也，然而文王独言以宁者何也？文王好仁则仁兴，得士

<a id="p46"></a>**〔46〕**　<sub>中华本页 2334a</sub>　而敬之则士用，用之有礼义。

<a id="p47"></a>**〔47〕**　<sub>中华本页 2334a</sub>　能成其功。故古之贤君于其臣也，尊其爵禄而亲之；疾则临视之亡数，死则往吊

<a id="p48"></a>**〔48〕**　<sub>中华本页 2334a</sub>　哭之，临其小敛大敛，已棺涂而后为之服锡衰麻绖，而三临其丧；未敛不饮酒食

<a id="p49"></a>**〔49〕**　<sub>中华本页 2334a</sub>　肉，未葬不举乐，当宗庙之祭而死，为之废乐。故古之君人者于其臣也，可谓尽礼矣；

<a id="p50"></a>**〔50〕**　<sub>中华本页 2334a</sub>　服法服，端容貌，正颜色，然后见之。故臣下莫敢不竭力尽死以报其上，功德立于后

<a id="p51"></a>**〔51〕**　<sub>中华本页 2334a</sub>　世，而令闻不忘也。

<a id="p52"></a>**〔52〕**　<sub>中华本页 2334a</sub>　之士，天下皆䜣䜣焉，曰将兴尧舜之道，三王之功矣。天下之士莫不精白以承休
