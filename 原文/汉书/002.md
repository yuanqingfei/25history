# 汉书·卷2　惠帝纪第二

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中华本页 0085a</sub>　惠帝纪第二

<a id="p2"></a>**〔2〕**　<sub>中华本页 0085a</sub>　孝惠皇帝，高祖太子也，母曰吕皇后。帝年五岁，高祖初为汉王。二年，立为太子。十二年四月，高祖崩。五月丙寅，太子即皇帝位，尊皇后曰皇太后。赐民爵一级。中郎、郎中满六岁爵三级，四岁二级。外郎满六岁二级。中郎不满一岁一级。外郎不满二岁赐钱万。宦官尚食比郎中。谒者、执楯、执戟、武士、驺比外郎。太子御骖乘赐爵五大夫，舍人满五岁二级。赐给丧事者，二千石钱二万，六百石以上万，五百石、二百石以下至佐史五千。视作斥上者，将军四十金，二千石二十金，六百石以上六金，五百石以下至佐史二金。减田租，复十五税一。爵五大夫、吏六百石以上及宦皇帝而知名者有罪当盗械者，皆颂系。上造以上及内外公孙耳孙有罪当刑及当为城旦舂者，皆耐为鬼薪白粲。民年七十以上若不满十岁有罪当刑者，皆完之。又曰：“吏所以治民也，能尽其治则民赖之，故重其禄，所以为民也。今吏六百石以上父母妻子与同居，及故吏尝佩将军都尉印将兵及佩二千石官印者，家唯给军赋，他无有所与。

<a id="p3"></a>**〔3〕**　<sub>中华本页 0086a</sub>　令郡诸侯王立高庙。

<a id="p4"></a>**〔4〕**　<sub>中华本页 0086a</sub>　元年冬十二月，赵隐王如意薨。民有罪，得买爵三十级以免死罪。赐民爵，户一级。

<a id="p5"></a>**〔5〕**　<sub>中华本页 0086a</sub>　春正月，城长安。

<a id="p6"></a>**〔6〕**　<sub>中华本页 0086a</sub>　二年冬十月，齐悼恵王来朝，献城阳郡以益鲁元公主邑，尊公主为太后。

<a id="p7"></a>**〔7〕**　<sub>中华本页 0086a</sub>　春正月癸酉，有两龙见兰陵家人井中，乙亥夕而不见。陇西地震。

<a id="p8"></a>**〔8〕**　<sub>中华本页 0086a</sub>　夏旱。郃阳侯仲薨。秋七月辛未，相国何薨。

<a id="p9"></a>**〔9〕**　<sub>中华本页 0086a</sub>　三年春，发长安六百里内男女十四万六千人城长安，三十日罢。

<a id="p10"></a>**〔10〕**　<sub>中华本页 0086a</sub>　以宗室女为公主，嫁匈奴单于。

<a id="p11"></a>**〔11〕**　<sub>中华本页 0086a</sub>　夏五月，立闽越君摇为东海王。

<a id="p12"></a>**〔12〕**　<sub>中华本页 0086a</sub>　六月，发诸侯王、列侯徒隶二万人城长安。

<a id="p13"></a>**〔13〕**　<sub>中华本页 0086a</sub>　秋七月，都灾。南越王赵佗称臣奉贡。

<a id="p14"></a>**〔14〕**　<sub>中华本页 0086a</sub>　四年冬十月壬寅，立皇后张氏。

<a id="p15"></a>**〔15〕**　<sub>中华本页 0086a</sub>　春正月，举民孝弟力田者复其身。

<a id="p16"></a>**〔16〕**　<sub>中华本页 0086a</sub>　三月甲子，皇帝冠，赦天下。省法令妨吏民者；除挟书律。长乐宫鸿台灾。宜阳雨血。

<a id="p17"></a>**〔17〕**　<sub>中华本页 0086a</sub>　秋七月乙亥，未央宫凌室灾；丙子，织室灾。

<a id="p18"></a>**〔18〕**　<sub>中华本页 0086a</sub>　五年冬十月，靁；桃李华，枣实。

<a id="p19"></a>**〔19〕**　<sub>中华本页 0086a</sub>　春正月，复发长安六百里内男女十四万五千人城长安，三十日罢。

<a id="p20"></a>**〔20〕**　<sub>中华本页 0086a</sub>　夏，大旱。

<a id="p21"></a>**〔21〕**　<sub>中华本页 0091a</sub>　秋八月己丑，相国参薨。

<a id="p22"></a>**〔22〕**　<sub>中华本页 0091a</sub>　九月，长安城成。赐民爵，户一级。

<a id="p23"></a>**〔23〕**　<sub>中华本页 0091a</sub>　六年冬十月辛丑，齐王肥薨。

<a id="p24"></a>**〔24〕**　<sub>中华本页 0091a</sub>　令民得卖爵。女子年十五以上至三十不嫁，五算。

<a id="p25"></a>**〔25〕**　<sub>中华本页 0091a</sub>　夏六月，舞阳侯哙薨。

<a id="p26"></a>**〔26〕**　<sub>中华本页 0091a</sub>　起长安西巿，修敖仓。

<a id="p27"></a>**〔27〕**　<sub>中华本页 0091a</sub>　七年冬十月，发车骑、材官诣荥阳，太尉灌婴将。

<a id="p28"></a>**〔28〕**　<sub>中华本页 0091a</sub>　春正月辛丑朔，日有蚀之。夏五月丁卯，日有蚀之，既。

<a id="p29"></a>**〔29〕**　<sub>中华本页 0091a</sub>　秋八月戊寅，帝崩于未央宫。九月辛丑，葬安陵。

<a id="p30"></a>**〔30〕**　<sub>中华本页 0091a</sub>　赞曰：孝惠内修亲亲，外礼宰相，优宠齐悼、赵隐，恩敬笃矣。闻叔孙通之谏则惧然，纳曹相国之对而心说，可谓宽仁之主。遭吕太后亏损至德，悲夫！
