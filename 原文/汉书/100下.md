# 汉书·卷100下　传第七十下

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中华本页 4235a</sub>　传第七十下

<a id="p2"></a>**〔2〕**　<sub>中华本页 4235a</sub>　固以为唐虞三代，诗书所及，世有典籍，故虽尧舜之盛，必有典谟之篇，然后扬名于后世，冠德于百王，故曰“巍巍乎其有成功，焕乎其有文章也！”汉绍尧运，以建帝业，至于六世，史臣乃追述功德，私作本纪，编于百王之末，厕于秦、项之列。太初以后，阙而不录，故探篹前记，缀辑所闻，以述汉书，起元高祖，终于孝平王莽之诛，十有二世，二百三十年，综其行事，旁贯五经，上下洽通，为春秋考纪、表、志、传，凡百篇。其曰：

<a id="p3"></a>**〔3〕**　<sub>中华本页 4235a</sub>　皇矣汉祖，纂尧之绪，实天生德，聪明神武。秦人不纲，罔漏于楚，爰兹发迹，断蛇奋旅。神母告符，朱旗乃举，粤蹈秦郊，婴来稽首。革命创制，三章是纪，应天顺民，五星同晷。项氏畔换，黜我巴、汉，西土宅心，战士愤怨。乘衅而运，席卷三秦，割据河山，保此怀民。股肱萧、曹，社稷是经，爪牙信、布，腹心良、平，龚行天罚，赫赫明明。述高纪第一。

<a id="p4"></a>**〔4〕**　<sub>中华本页 4235a</sub>　孝惠短世，高后称制，罔顾天显，吕宗以败。述惠纪第二，高后纪第三。

<a id="p5"></a>**〔5〕**　<sub>中华本页 4235a</sub>　太宗穆穆，允恭玄默，化民以躬，帅下以德。农不供贡，辠不收孥，宫不新馆，陵不崇墓。我德如风，民应如屮，国富刑清，登我汉道。述文纪第四。

<a id="p6"></a>**〔6〕**　<sub>中华本页 4235a</sub>　孝景莅政，诸侯方命，克伐七国，王室以定。匪怠匪荒，务在农桑，著于甲令，民用宁康。述景纪第五。

<a id="p7"></a>**〔7〕**　<sub>中华本页 4235a</sub>　世宗晔晔，思弘祖业，畴咨熙载，髦俊并作。厥作伊何？百蛮是攘，恢我疆宇，外博四荒。武功既抗，亦迪斯文，宪章六学，统壹圣真。封禅郊祀，登秩百神；协律改正，飨兹永年。述武纪第六。

<a id="p8"></a>**〔8〕**　<sub>中华本页 4238a</sub>　孝昭幼冲，冢宰惟忠。燕、盖诪张，实叡实聪，辠人斯得，邦家和同。述昭纪第七。

<a id="p9"></a>**〔9〕**　<sub>中华本页 4238a</sub>　中宗明明，夤用刑名，时举傅纳，听断惟精。柔远能迩，𬊤燿威灵，龙荒幕朔，莫不来庭。丕显祖烈，尚于有成。述宣纪第八。

<a id="p10"></a>**〔10〕**　<sub>中华本页 4238a</sub>　孝元翼翼，高明柔克，宾礼故老，优繇亮直。外割禁囿，内损御服，离宫不衞，山陵不邑。阉尹之{GJ-C893}，秽我明德。述元纪第九。

<a id="p11"></a>**〔11〕**　<sub>中华本页 4238a</sub>　孝成煌煌，临朝有光，威仪之盛，如圭如璋。壸闱恣赵，朝政在王，炎炎燎火，亦允不阳。述成纪第十。

<a id="p12"></a>**〔12〕**　<sub>中华本页 4238a</sub>　孝哀彬彬，克㖿威神，雕落洪支，底剭鼎臣。婉娈董公，惟亮天功，大过之困，实桡实凶。述哀纪第十一。

<a id="p13"></a>**〔13〕**　<sub>中华本页 4238a</sub>　孝平不造，新都作宰，不周不伊，丧我四海。述平纪第十二。

<a id="p14"></a>**〔14〕**　<sub>中华本页 4238a</sub>　汉初受命，诸侯并政，制自项氏，十有八姓。述异姓诸侯王表第一。

<a id="p15"></a>**〔15〕**　<sub>中华本页 4238a</sub>　太祖元勋，启立辅臣，支庶藩屏，侯王并尊。述诸侯王表第二。

<a id="p16"></a>**〔16〕**　<sub>中华本页 4238a</sub>　侯王之祉，祚及宗子，公族蕃滋，支叶硕茂。述王子侯表第三。

<a id="p17"></a>**〔17〕**　<sub>中华本页 4238a</sub>　受命之初，赞功剖符，奕世弘业，爵土乃昭。述高惠高后孝文功臣侯表第四。

<a id="p18"></a>**〔18〕**　<sub>中华本页 4238a</sub>　景征吴楚，武兴师旅，后昆承平，亦有绍土。述景武昭宣元成哀功臣侯表第五。

<a id="p19"></a>**〔19〕**　<sub>中华本页 4238a</sub>　亡德不报，爰存二代，宰相外戚，昭韪见戒。述外戚恩泽侯表第六。

<a id="p20"></a>**〔20〕**　<sub>中华本页 4238a</sub>　汉迪于秦，有革有因，觕举僚职，并列其人。述百官公卿表第七。

<a id="p21"></a>**〔21〕**　<sub>中华本页 4238a</sub>　篇章博举，通于上下，略差名号，九品之。述古今人表第八。

<a id="p22"></a>**〔22〕**　<sub>中华本页 4238a</sub>　元元本本，数始于一，产气黄钟，造计秒忽。八音七始，五声六律，度量权衡，历算逌出。官失学微，六家分乖，壹彼壹此，庶研其几。述律历志第一。

<a id="p23"></a>**〔23〕**　<sub>中华本页 4238a</sub>　上天下泽，春靁奋作，先王观象，爰制礼乐。厥后崩坏，郑衞荒淫，风流民化，湎湎纷纷。略存大纲，以统旧文。述礼乐志第二。

<a id="p24"></a>**〔24〕**　<sub>中华本页 4242a</sub>　靁电皆至，天威震耀，五刑之作，是则是效，威实辅德，刑亦助教。季世不详，背本争末，吴、孙狙诈，申、商酷烈。汉章九法，太宗改作，轻重之差，世有定籍。述刑法志第三。

<a id="p25"></a>**〔25〕**　<sub>中华本页 4242a</sub>　厥初生民，食货惟先。割制庐井，定尔土田，什一供贡，下富上尊。商以足用，茂迁有无，货自龟贝，至此五铢。扬搉古今，监世盈虚。述食货志第四。

<a id="p26"></a>**〔26〕**　<sub>中华本页 4242a</sub>　昔在上圣，昭事百神，类帝禋宗，望秩山川，明德惟馨，永世丰年。季末淫祀，营信巫史，大夫胪岱，侯伯僭畤，放诞之徒，缘间而起。瞻前顾后，正其终始。述郊祀志第五。

<a id="p27"></a>**〔27〕**　<sub>中华本页 4243a</sub>　炫炫上天，县象著明，日月周辉，星辰垂精。百官立法，宫室混成，降应王政，景以烛形。三季之后，厥事放纷，举其占应，览故考新。述天文志第六。

<a id="p28"></a>**〔28〕**　<sub>中华本页 4243a</sub>　河图命庖，洛书赐禹，八卦成列，九畴逌。世代寔宝，光演文武，春秋之占，咎征是举。告往知来，王事之表。述五行志第七。

<a id="p29"></a>**〔29〕**　<sub>中华本页 4243a</sub>　坤作墬势，高下九则，自昔黄、唐，经略万国，（(变)）【爕】定东西，疆理南北。三代损益，降及秦、汉，革刬五等，制立郡县。略表山川，彰其剖判。述地理志第八。

<a id="p30"></a>**〔30〕**　<sub>中华本页 4244a</sub>　夏乘四载，百川是导。唯河为{GJ-FC9C}，灾及后代。商竭周移，秦决南涯，自兹{GJ-C8E0}汉，北亡八支。文𦝪枣野，武作瓠歌，成有平年，后遂滂沱。爰及沟渠，利我国家。述沟洫志第九。

<a id="p31"></a>**〔31〕**　<sub>中华本页 4244a</sub>　虙羲画卦，书契后作，虞夏商周，孔纂其业，篹书删诗，缀礼正乐，彖系大易，因史立法。六学既登，遭世罔弘，群言纷乱，诸子相腾。秦人是灭，汉修其缺，刘向司籍，九流以别。爰著目录，略序洪烈。述艺文志第十。

<a id="p32"></a>**〔32〕**　<sub>中华本页 4245a</sub>　上嫚下暴，惟盗是伐，胜、广熛起，梁、籍扇烈。赫赫炎炎，遂焚咸阳，宰割诸夏，命立侯王，诛婴放怀，诈虐以亡。述陈胜项籍传第一。

<a id="p33"></a>**〔33〕**　<sub>中华本页 4245a</sub>　张、陈之交，斿如父子，携手{GJ-C8DF}秦，拊翼俱起。据国争权，还为豺虎，耳谋甘公，作汉藩辅。述张耳陈余传第二。

<a id="p34"></a>**〔34〕**　<sub>中华本页 4245a</sub>　三枿之起，本根既朽，枯杨生华，曷惟其旧！横虽雄材，伏于海{GJ-C886}，沐浴尸乡，北面奉首，旅人慕殉，义过黄鸟。述魏豹田儋韩信传第三。

<a id="p35"></a>**〔35〕**　<sub>中华本页 4245a</sub>　信惟饿隶，布实黥徒，越亦狗盗，芮尹江湖。云起龙襄，化为侯王，割有齐、楚，跨制淮、梁。绾自同闬，镇我北疆，德薄位尊，非胙惟殃。吴克忠信，胤嗣乃长。述韩彭英卢吴传第四。

<a id="p36"></a>**〔36〕**　<sub>中华本页 4245a</sub>　贾廑从旅，为镇淮、楚。泽王琅邪，权激诸吕。濞之受吴，疆土逾矩，虽戒东南，终用齐斧。述荆燕吴传第五。

<a id="p37"></a>**〔37〕**　<sub>中华本页 4247a</sub>　太上四子：伯兮早夭，仲氏王代，斿宅于楚。戊实淫{GJ-C8DE}，平陆乃绍。其在于京，奕世宗正，劬劳王室，用侯阳成。子政博学，三世成名，述楚元王传第六。

<a id="p38"></a>**〔38〕**　<sub>中华本页 4247a</sub>　季氏之诎，辱身毁节，信于上将，议臣震栗。栾公哭梁，田叔殉赵，见危授命，谊动明主。布历燕、齐，叔亦相鲁，民思其政，或金或社。述季布栾布田叔传第七。

<a id="p39"></a>**〔39〕**　<sub>中华本页 4247a</sub>　高祖八子，二帝六王。三赵不辜，淮厉自亡，燕灵绝嗣，齐悼特昌。掩有东土，自岱徂海，支庶分王，前后九子。六国诛毙，适齐亡祀。城阳、济北，后承我国。赳赳景王，匡汉社稷。述高五王传第八。

<a id="p40"></a>**〔40〕**　<sub>中华本页 4247a</sub>　猗与元勋，包汉举信，镇守关中，足食成军，营都立宫，定制修文。平阳玄默，继而弗革，民用作歌，化我淳德。汉之宗臣，是谓相国。述萧何曹参传第九。

<a id="p41"></a>**〔41〕**　<sub>中华本页 4247a</sub>　留侯袭秦，作汉腹心，图折武关，解鸿门。推齐销印，敺致越、信；招宾四老，惟宁嗣君。陈公扰攘，归汉乃安，毙范亡项，走狄擒韩，六奇既设，我罔艰难。安国廷争，致仕杜门。绛侯矫矫，诛吕尊文。亚夫守节，吴楚有勋。述张陈王周传第十。

<a id="p42"></a>**〔42〕**　<sub>中华本页 4247a</sub>　舞阳鼓刀，滕公驺，颍阴商贩，曲周庸夫，攀龙附凤，并乘天衢。述樊郦滕灌傅靳周传第十一。

<a id="p43"></a>**〔43〕**　<sub>中华本页 4247a</sub>　北平志古，司秦柱下，定汉章程，律度之绪。建平质直，犯上干色；广阿之廑，食厥旧德。故安执节，责通请错，蹇蹇帝臣，匪躬之故。述张周赵任申屠传第十二。

<a id="p44"></a>**〔44〕**　<sub>中华本页 4247a</sub>　食其监门，长揖汉王，画袭陈留，进收敖仓，塞隘杜津，王基以张。贾作行人，百越来宾，从容风议，博我以文。敬繇役夫，迁京定都，内强关中，外和匈奴。叔孙奉常，与时抑扬，税介免胄，礼义是创。或悊或谋，观国之光。述郦陆朱娄叔孙传第十三。

<a id="p45"></a>**〔45〕**　<sub>中华本页 4250a</sub>　淮南僭狂，二子受殃。安辩而邪，赐顽以荒，敢行称乱，窘世荐亡。述淮南衡山济北传第十四。

<a id="p46"></a>**〔46〕**　<sub>中华本页 4250a</sub>　蒯通壹说，三雄是败，覆郦骄韩，田横颠沛。被之拘系，乃成患害。充、躬罔极，交乱弘大。述蒯伍江息夫传第十五。

<a id="p47"></a>**〔47〕**　<sub>中华本页 4250a</sub>　万石温温，幼寤圣君，宜尔子孙，夭夭伸伸，庆社于齐，不言动民。衞、直、周、张，淑慎其身。述万石衞直周张传第十六。

<a id="p48"></a>**〔48〕**　<sub>中华本页 4250a</sub>　孝文三王，代孝二梁，怀折亡嗣，孝乃尊光。内为母弟，外扞吴楚，怙宠矜功，僭欲失所，思心既霿，牛告妖。帝庸亲亲，厥国五分，德不堪宠，四支不传。述文三王传第十七。

<a id="p49"></a>**〔49〕**　<sub>中华本页 4250a</sub>　贾生矫矫，弱冠登朝。遭文叡圣，屡抗其疏，暴秦之戒，三代是据。建设藩屏，以强守圉，吴楚合从，赖谊之虑。述贾谊传第十八。

<a id="p50"></a>**〔50〕**　<sub>中华本页 4250a</sub>　子丝慷慨，激辞纳说，㖿辔正席，显陈成败。错之琐材，智小谋大，如发机，先寇受害。述爰盎朝错传第十九。

<a id="p51"></a>**〔51〕**　<sub>中华本页 4250a</sub>　释之典刑，国宪以平。冯公矫魏，增主之明。长孺刚直，义形于色，下折淮南，上正元服。庄之推贤，于兹为德。述张冯汲郑传第二十。

<a id="p52"></a>**〔52〕**　<sub>中华本页 4253a</sub>　荣如辱如，有机有枢，自下摩上，惟德之隅。赖依忠正，君子采诸。述贾邹枚路传第二十一。

<a id="p53"></a>**〔53〕**　<sub>中华本页 4253a</sub>　魏其翩翩，好节慕声，灌夫矜勇，武安骄盈，凶德相挻，败用成。安国壮趾，王恢兵首，彼若天命，此近人咎。述窦田灌韩传第二十二。

<a id="p54"></a>**〔54〕**　<sub>中华本页 4253a</sub>　景十三王，承文之庆。鲁恭馆室，江都訬轻；赵敬险诐，中山淫蒏；长沙寂漠，广川亡声；胶东不亮，常山骄盈。四国绝祀，河间贤明，礼乐是修，为汉宗英。述景十三王传第二十三。

<a id="p55"></a>**〔55〕**　<sub>中华本页 4254a</sub>　李广恂恂，实获士心，控弦贯石，威动北邻，躬战七十，遂死于军。敢怨衞青，见讨去病。陵不引决，忝世灭姓。苏武信节，不诎王命。述李广苏建传第二十四。

<a id="p56"></a>**〔56〕**　<sub>中华本页 4254a</sub>　长平桓桓，上将之元，薄伐猃允，恢我朔边，戎车七征，冲輣闲闲，合围单于，北登阗颜。票骑冠军，猋勇纷纭，长驱六举，电击雷震，饮马翰海，封狼居山，西规大河，列郡祈连。述衞青霍去病传第二十五。

<a id="p57"></a>**〔57〕**　<sub>中华本页 4254a</sub>　抑抑仲舒，再相诸侯，身修国治，致仕县车，下帷覃思，论道属书，谠言访对，为世纯儒。述董仲舒传第二十六。

<a id="p58"></a>**〔58〕**　<sub>中华本页 4254a</sub>　文艳用寡，子虚乌有，寓言淫丽，托风终始，多识博物，有可观采，蔚为辞宗，赋颂之首。述司马相如传第二十七。

<a id="p59"></a>**〔59〕**　<sub>中华本页 4254a</sub>　平津斤斤，晚跻金门，既登爵位，禄赐颐贤，布衾疎食，用俭饬身。卜式耕牧，以求其志，忠寤明君，乃爵乃试。儿生亹亹，束发修学，偕列名臣，从政辅治。述公孙弘卜式儿宽传第二十八。

<a id="p60"></a>**〔60〕**　<sub>中华本页 4256a</sub>　张汤遂达，用事任职，媚兹一人，日旰忘食，既成宠禄，亦罗咎慝。安世温良，塞渊其德，子孙遵业，全祚保国。述张汤传第二十九。

<a id="p61"></a>**〔61〕**　<sub>中华本页 4256a</sub>　杜周治文，唯上浅深，用取世资，幸而免身。延年宽和，列于名臣。钦用材谋，有异厥伦。述杜周传第三十。

<a id="p62"></a>**〔62〕**　<sub>中华本页 4256a</sub>　博望杖节，收功大夏；贰师秉钺，身衅胡社。致死为福，每生作。述张骞李广利传第三十一。

<a id="p63"></a>**〔63〕**　<sub>中华本页 4257a</sub>　乌呼史迁，薰胥以刑！幽而发愤，乃思乃精，错综群言，古今是经，勒成一家，大略孔明。述司马迁传第三十二。

<a id="p64"></a>**〔64〕**　<sub>中华本页 4257a</sub>　孝武六子，昭、齐亡嗣。燕剌谋逆，广陵祝诅。昌邑短命，昬贺失据。戾园不幸，宣承天序。述武五子传第三十三。

<a id="p65"></a>**〔65〕**　<sub>中华本页 4257a</sub>　六世耽耽，其欲浟浟，文武方作，是庸四克。助、偃、淮南，数子之德，不忠其身，善谋于国。述严朱吾丘主父徐严终王贾传第三十四。

<a id="p66"></a>**〔66〕**　<sub>中华本页 4257a</sub>　东方赡辞，诙谐倡优，讥苑扞偃，正谏举邮，怀肉污殿，弛张沈浮。述东方朔传第三十五。

<a id="p67"></a>**〔67〕**　<sub>中华本页 4257a</sub>　葛绎内宠，屈牦王子。千秋时发，宜春旧仕。敞、义依霍，庶几云已。弘惟政事，万年容己。咸睡厥诲，孰为不子？述公孙刘田杨王蔡陈郑传第三十六。

<a id="p68"></a>**〔68〕**　<sub>中华本页 4257a</sub>　王孙臝葬，建乃斩将。云廷讦禹，福逾刺凤，是谓狂狷，敞近其衷。述杨胡朱梅云传第三十七。

<a id="p69"></a>**〔69〕**　<sub>中华本页 4257a</sub>　博陆堂堂，受遗武皇，拥毓孝昭，末命导扬。遭家不造，立帝废王，权定社禝，配忠阿衡。怀禄耽宠，渐化不详，阴妻之逆，至子而亡。秺侯狄孥，虔恭忠信，奕世载德，貤于子孙。述霍光金日䃅传第三十八。

<a id="p70"></a>**〔70〕**　<sub>中华本页 4257a</sub>　兵家之策，惟在不战。营平皤皤，立功立论，以不济可，上谕其信。武贤父子，虎臣之俊。述赵充国辛庆忌传第三十九。

<a id="p71"></a>**〔71〕**　<sub>中华本页 4257a</sub>　义阳楼兰，长罗昆弥，安远日逐，义成郅支。陈汤诞节，救在三悊；会宗勤事，疆外之桀。述傅常郑甘陈段传第四十。

<a id="p72"></a>**〔72〕**　<sub>中华本页 4257a</sub>　不疑肤敏，应变当理，辞霍不婚，逡遁致仕。疏克有终，散金娱老。定国之祚，于其仁考。广德、当、宣，近于知耻。述隽疏于薛平彭传第四十一。

<a id="p73"></a>**〔73〕**　<sub>中华本页 4257a</sub>　四皓遯秦，古之逸民，不营不拔，严平、郑真。吉困于贺，涅而不缁；禹既黄发，以德来仕。舍惟正身，胜死善道；郭钦、蒋诩，近遯之好。述王贡两龚鲍传第四十二。

<a id="p74"></a>**〔74〕**　<sub>中华本页 4257a</sub>　扶阳济济，闻诗闻礼。玄成退让，仍世作相。汉之宗庙，叔孙是谟，革自孝元，诸儒变度。国之诞章，博载其路。述韦贤传第四十三。

<a id="p75"></a>**〔75〕**　<sub>中华本页 4261a</sub>　高平师师，惟辟作威，图黜凶害，天子是毗。博阳不伐，含弘光大，天诱其衷，庆流苗裔。述魏相丙吉传第四十四。

<a id="p76"></a>**〔76〕**　<sub>中华本页 4261a</sub>　占往知来，幽赞神明，苟非其人，道不虚行。学微术昧，或见仿佛，疑殆匪阙，违众迕世，浅为尤悔，深作敦害。述眭两夏侯京翼李传第四十五。

<a id="p77"></a>**〔77〕**　<sub>中华本页 4261a</sub>　广汉尹京，克聪克明；延寿作翊，既和且平。矜能讦上，俱陷极刑。翁归承风，帝扬厥声。敞；亦平平，文雅自赞；尊实赳赳，邦家之彦；章死非辠，士民所叹。述赵尹韩张两王传第四十六。

<a id="p78"></a>**〔78〕**　<sub>中华本页 4261a</sub>　宽饶正色，国之司直。丰繄好刚，辅亦慕直。皆陷狂狷，不典不式。崇执言责，隆持官守。宝曲定陵，并有立志。述盖诸葛刘郑毋将孙何传第四十七。

<a id="p79"></a>**〔79〕**　<sub>中华本页 4261a</sub>　长倩{GJ-C8DB}{GJ-C8DB}，觌霍不举，遇宣乃拔，傅元作辅，不图不虑，见踬石、许。述萧望之传第四十八。

<a id="p80"></a>**〔80〕**　<sub>中华本页 4263a</sub>　子明光光，发迹西疆，列于御侮，厥子亦良。述冯奉世传第四十九。

<a id="p81"></a>**〔81〕**　<sub>中华本页 4263a</sub>　宣之四子，淮阳聪敏，舅氏蘧蒢，几陷大理。楚孝恶疾，东平失轨，中山凶短，母归戎里。元之二王，孙后大宗，昭而不穆，大命更登。述宣元六王传第五十。

<a id="p82"></a>**〔82〕**　<sub>中华本页 4263a</sub>　乐安，古之文学，民具尔瞻，困于二司。安昌货殖，朱云作娸。博山惇慎，受莽之疚。述匡张孔马传第五十一。

<a id="p83"></a>**〔83〕**　<sub>中华本页 4263a</sub>　乐昌笃实，不桡不诎，遘闵既多，是用废黜。武阳殷勤，辅导副君，既忠且谋，飨兹旧勋。高武守正，因用济身。述王商、史丹、傅喜传第五十二。

<a id="p84"></a>**〔84〕**　<sub>中华本页 4263a</sub>　高阳文法，扬乡武略，政事之材，道德惟薄，位过厥任，鲜终其禄。博之翰音，鼓妖先作。述薛宣朱博传第五十三。

<a id="p85"></a>**〔85〕**　<sub>中华本页 4263a</sub>　高陵修儒，任刑养威，用合时宜，器周世资。义得其勇，如虎如貔，进不跬步，宗为鲸鲵。述翟方进传第五十四。

<a id="p86"></a>**〔86〕**　<sub>中华本页 4265a</sub>　统微政缺，灾眚屡发。永陈厥咎，戒在三七。邺指丁、傅，略窥占术。述谷永杜邺传第五十五。

<a id="p87"></a>**〔87〕**　<sub>中华本页 4265a</sub>　哀、平之恤，丁、傅、莽、贤。武、嘉戚之，乃丧厥身。高乐废黜，咸列贞臣。述何武王嘉师丹传第五十六。

<a id="p88"></a>**〔88〕**　<sub>中华本页 4265a</sub>　渊哉若人！实好斯文。初拟相如，献赋黄门，辍而覃思，草法篹玄，斟酌六经，放易象论，潜于篇籍，以章厥身。述扬雄传第五十七。

<a id="p89"></a>**〔89〕**　<sub>中华本页 4265a</sub>　犷犷亡秦，灭我圣文，汉存其业，六学析分。是综是理，是纲是纪，师徒弥散，著其终始。述儒林传第五十八。

<a id="p90"></a>**〔90〕**　<sub>中华本页 4265a</sub>　谁毁谁誉，誉其有试。泯泯群黎，化成良吏。淑人君子，时同功异。没世遗爱，民有余思。述循吏传第五十九。

<a id="p91"></a>**〔91〕**　<sub>中华本页 4265a</sub>　上替下陵，奸轨不胜，猛政横作，刑罚用兴。曾是强圉，掊克为雄，报虐以威，殃亦凶终。述酷吏传第六十。

<a id="p92"></a>**〔92〕**　<sub>中华本页 4265a</sub>　四民食力，罔有兼业，大不淫侈，细不匮乏，盖均无贫，遵王之法。靡法靡度，民肆其诈，偪上并下，荒殖其货。侯服玉食，败俗伤化。述货殖传第六十一。

<a id="p93"></a>**〔93〕**　<sub>中华本页 4265a</sub>　开国承家，有法有制，家不臧甲，国不专杀。矧乃齐民，作威作惠，如台不匡，礼法是谓！述游侠传第六十二。

<a id="p94"></a>**〔94〕**　<sub>中华本页 4265a</sub>　彼何人斯，窃此富贵！营损高明，作戒后世。述佞幸传第六十三。

<a id="p95"></a>**〔95〕**　<sub>中华本页 4265a</sub>　于惟帝典，戎夷猾夏；周宣攘之，亦列风雅。宗幽既昬，淫于襃女，戎败我骊，遂亡酆鄗。大汉初定，匈奴强盛，围我平城，寇侵边境。至于孝武，爰赫斯怒，王师雷起，霆击朔野。宣承其末，乃施洪德，震我威灵，五世来服。王莽窃命，是倾是覆，备其变理，为世典式。述匈奴传第六十四。

<a id="p96"></a>**〔96〕**　<sub>中华本页 4265a</sub>　西南外夷，种别域殊。南越尉佗，自王番禺，攸攸外寓，闽越、东瓯。爰洎朝鲜，燕之外区。汉兴柔远，与尔剖符。皆恃其岨，乍臣乍骄，孝武行师，诛灭海隅。述西南夷两越朝鲜传第六十五。

<a id="p97"></a>**〔97〕**　<sub>中华本页 4265a</sub>　西戎即序，夏后是表。周穆观兵，荒服不旅。汉武劳神，图远甚勤。王师驒驒，致诛大宛。姼姼公主，乃女乌孙，使命乃通，条支之濒。昭、宣承业，都护是立，总督城郭，三十有六，修奉朝贡，各以其职。述西城传第六十六。

<a id="p98"></a>**〔98〕**　<sub>中华本页 4265a</sub>　诡矣祸福，刑于外戚。高后首命，吕宗颠覆。薄姬{GJ-F9E9}魏，宗文产德。窦后违意，考盘于代。王氏仄微，世武作嗣。子夫既兴，扇而不终。钩弋忧伤，孝昭以登。上官幼尊，类祃厥宗。史娣、王悼，身遇不祥，及宣飨国，二族后光。恭哀产元，夭而不遂。邛成乘序，履尊三世。飞燕之妖，祸成厥妹。丁、傅僭恣，自求凶害。中山无辜，乃丧冯、衞。惠张、景薄，武陈、宣霍，成许、哀傅，平王之作，事虽歆羡，非天所度。怨咎若兹，如何不恪！述外戚传第六十七。

<a id="p99"></a>**〔99〕**　<sub>中华本页 4265a</sub>　元后娠母，月精见表。遭成之逸，政自诸舅。阳平作威，诛加卿宰。成都煌煌，假我明光。曲阳（({GJ-C849}{GJ-C849})）【歊歊】，亦朱其堂。新都亢极，作乱以亡。述元后传第六十八。

<a id="p100"></a>**〔100〕**　<sub>中华本页 4265a</sub>　咨尔贼臣，篡汉滔天，行骄夏癸，虐烈商辛。伪稽黄、虞，缪称典文，众怨神怒，恶复诛臻。百王之极，究其奸昏。述王莽传第六十九。

<a id="p101"></a>**〔101〕**　<sub>中华本页 4265a</sub>　凡汉书，帝皇，列官司，建侯王。准天地，统阴阳，阐元极，步三光。分州域，物土疆，穷人理，该万方。纬六经，缀道纲，总百氏，赞篇章。函雅故，通古今，正文字，惟学林。述传第七十。
