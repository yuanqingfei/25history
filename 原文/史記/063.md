# 史記·卷63　老子韓非列傳第三

底本：TLS 中华书局点校本。段号即定位符中的“段”。授权与改动说明见 [原文/README.md](../README.md)。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 2139a</sub>　老子韓非列傳第三

<a id="p2"></a>**〔2〕**　<sub>中華本頁 2139a</sub>　老子者，楚苦縣厲鄉曲仁里人也，姓李氏，名耳，字，周守藏室之史也。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 2139a</sub>　孔子適周，將問禮於老子。老子曰：「子所言者，其人與骨皆已朽矣，獨其言在耳。且君子得其時則駕，不得其時則蓬累而行。吾聞之，良賈深藏若虛，君子盛德容貌若愚。去子之驕氣與多欲，態色與淫志，是皆無益於子之身。吾所以告子，若是而已。」孔子去，謂弟子曰：「鳥，吾知其能飛；魚，吾知其能游；獸，吾知其能走。走者可以為罔，游者可以為綸，飛者可以為矰。至於龍，吾不能知其乘風雲而上天。吾今日見老子，其猶龍邪！」

<a id="p4"></a>**〔4〕**　<sub>中華本頁 2139a</sub>　老子脩道德，其學以自隱無名為務。居周久之，見周之衰，迺遂去。至關，關令尹喜曰：「子將隱矣，彊為我著書。」於是老子迺著書上下篇，言道德之意五千餘言而去，莫知其所終。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 2139a</sub>　或曰：老萊子亦楚人也，著書十五篇，言道家之用，與孔子同時云。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 2142a</sub>　蓋老子百有六十餘歲，或言二百餘歲，以其脩道而養壽也。

<a id="p7"></a>**〔7〕**　<sub>中華本頁 2142a</sub>　自孔子死之後百二十九年，而史記周太史儋見秦獻公曰：「始秦與周合，合五百歲而離，離七十歲而霸王者出焉。」或曰儋即老子，或曰非也，世莫知其然否。老子，隱君子也。

<a id="p8"></a>**〔8〕**　<sub>中華本頁 2142a</sub>　老子之子名宗，宗為魏將，封於段干。宗子注，注子宮，宮玄孫假，假仕於漢孝文帝。而假之子解為膠西王卬太傅，因家于齊焉。

<a id="p9"></a>**〔9〕**　<sub>中華本頁 2143a</sub>　世之學老子者則絀儒學，儒學亦絀老子。「道不同不相為謀」，豈謂是邪？李耳無為自化，清靜自正。

<a id="p10"></a>**〔10〕**　<sub>中華本頁 2143a</sub>　莊子者，蒙人也，名周。周嘗為蒙漆園吏，與梁惠王、齊宣王同時。其學無所不闚，然其要本歸於老子之言。故其著書十餘萬言，大抵率寓言也。作漁父、盜跖、胠篋，以詆訿孔子之徒，以明老子之術。畏累虛、亢桑子之屬，皆空語無事實。然善屬書離辭，指事類情，用剽剝儒、墨，雖當世宿學不能自解免也。其言洸洋自恣以適己，故自王公大人不能器之。

<a id="p11"></a>**〔11〕**　<sub>中華本頁 2144a</sub>　楚威王聞莊周賢，使使厚幣迎之，許以為相。莊周笑謂楚使者曰：「千金，重利；卿相，尊位也。子獨不見郊祭之犧牛乎？養食之數歲，衣以文繡，以入大廟。當是之時，雖欲為孤豚，豈可得乎？子亟去，無污我。我寧游戲污瀆之中自快，無為有國者所羈，終身不仕，以快吾志焉。」

<a id="p12"></a>**〔12〕**　<sub>中華本頁 2144a</sub>　申不害者，京人也，故鄭之賤臣。學術以干韓昭侯，昭侯用為相。內脩政教，外應諸侯，十五年。終申子之身，國治兵彊，無侵韓者。

<a id="p13"></a>**〔13〕**　<sub>中華本頁 2144a</sub>　申子之學本於黃老而主刑名。著書二篇，號曰申子。

<a id="p14"></a>**〔14〕**　<sub>中華本頁 2144a</sub>　韓非者，韓之諸公子也。喜刑名法術之學，而其歸本於黃老。非為人口吃，不能道說，而善著書。與李斯俱事荀卿，斯自以為不如非。

<a id="p15"></a>**〔15〕**　<sub>中華本頁 2144a</sub>　非見韓之削弱，數以書諫韓王，韓王不能用。於是韓非疾治國不務脩明其法制，執勢以御其臣下，富國彊兵而以求人任賢，反舉浮淫之蠹而加之於功實之上。以為儒者用文亂法，而俠者以武犯禁。寬則寵名譽之人，急則用介冑之士。今者所養非所用，所用非所養。悲廉直不容於邪枉之臣，觀往者得失之變，故作孤憤、五蠹、內外儲、說林、說難十餘萬言。

<a id="p16"></a>**〔16〕**　<sub>中華本頁 2144a</sub>　然韓非知說之難，為說難書甚具，終死於秦，不能自脫。

<a id="p17"></a>**〔17〕**　<sub>中華本頁 2144a</sub>　說難曰：

<a id="p18"></a>**〔18〕**　<sub>中華本頁 2144a</sub>　非吾敢橫失能盡之難也。凡說之難，在知所說之心，可以吾說當之。

<a id="p19"></a>**〔19〕**　<sub>中華本頁 2144a</sub>　說出於厚利者也。而說之以名高，則見無心而遠事情，必不收矣。所說實為厚利而

<a id="p20"></a>**〔20〕**　<sub>中華本頁 2144a</sub>　顯為名高者也，而說之以名高，則陽收其身而實疏之；若說之以厚利，則陰用其言

<a id="p21"></a>**〔21〕**　<sub>中華本頁 2144a</sub>　而顯[⿱𠫓廾]其身。此之不可不知也。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 2144a</sub>　夫事以密成，語以泄敗。未必其身泄之也，而語及其所匿之事，如是者身危。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 2150a</sub>　貴人有過端，而說者明言善議以推其惡者，則身危。周澤未渥也而語極知，說行而

<a id="p24"></a>**〔24〕**　<sub>中華本頁 2150a</sub>　有功則德亡，說不行而有敗則見疑，如是者身危。夫貴人得計而欲自以為功，

<a id="p25"></a>**〔25〕**　<sub>中華本頁 2150a</sub>　說者與知焉，則身危。彼顯有所出事，迺自以為也故，說者與知焉，則身危。彊

<a id="p26"></a>**〔26〕**　<sub>中華本頁 2150a</sub>　之以其所必不為，止之以其所不能已者，身危。故曰：與之論大人，則以為閒

<a id="p27"></a>**〔27〕**　<sub>中華本頁 2150a</sub>　己；與之論細人，則以為粥權。論其所愛，則以為借資；論其所憎，則以為

<a id="p28"></a>**〔28〕**　<sub>中華本頁 2150a</sub>　嘗己。徑省其辭，則不知而屈之；汎濫博文，則多而久之。順事陳意，則曰怯

<a id="p29"></a>**〔29〕**　<sub>中華本頁 2150a</sub>　懦而不盡；慮事廣肆，則曰草野而倨侮。此說之難，不可不知也。

<a id="p30"></a>**〔30〕**　<sub>中華本頁 2150a</sub>　之；自勇其斷，則毋以其敵怒之；自多其力，則毋以其難概之。規異事與同

<a id="p31"></a>**〔31〕**　<sub>中華本頁 2150a</sub>　計，譽異人與同行者，則以飾之無傷也。有與同失者，則明飾其無失也。大忠

<a id="p32"></a>**〔32〕**　<sub>中華本頁 2150a</sub>　無所拂悟，辭言無所擊排，迺後申其辯知焉。此所以親近不疑，知盡之難

<a id="p33"></a>**〔33〕**　<sub>中華本頁 2150a</sub>　也。得曠日彌久，而周澤既渥，深計而不疑，交爭而不罪，迺明計利害以致其

<a id="p34"></a>**〔34〕**　<sub>中華本頁 2150a</sub>　功，直指是非以飾其身，以此相持，此說之成也。

<a id="p35"></a>**〔35〕**　<sub>中華本頁 2150a</sub>　能無役身而涉世如此其汙也，則非能仕之所設也。

<a id="p36"></a>**〔36〕**　<sub>中華本頁 2150a</sub>　其家甚知其子而疑鄰人之父。昔者鄭武公欲伐胡，迺以其子妻之。因問羣臣

<a id="p37"></a>**〔37〕**　<sub>中華本頁 2150a</sub>　曰：「吾欲用兵，誰可伐者？」關其思曰：「胡可伐。」迺戮關其思，曰：「胡，兄弟之國也，

<a id="p38"></a>**〔38〕**　<sub>中華本頁 2150a</sub>　子言伐之，何也？」胡君聞之，以鄭為親己而不備鄭。鄭人襲胡，取之。此二說者，其

<a id="p39"></a>**〔39〕**　<sub>中華本頁 2150a</sub>　知皆當矣，然而甚者為戮，薄者見疑。非知之難也，處知則難矣。

<a id="p40"></a>**〔40〕**　<sub>中華本頁 2150a</sub>　聞，往夜告之，彌子矯駕君車而出。君聞之而賢之曰：「孝哉，為母之故而犯刖罪！」

<a id="p41"></a>**〔41〕**　<sub>中華本頁 2150a</sub>　與君游果園，彌子食桃而甘，不盡而奉君。君曰：「愛我哉，忘其口而念我！」及彌子

<a id="p42"></a>**〔42〕**　<sub>中華本頁 2150a</sub>　色衰而愛弛，得罪於君。君曰：「是嘗矯駕吾車，又嘗食我以其餘桃。」故彌子之行未

<a id="p43"></a>**〔43〕**　<sub>中華本頁 2150a</sub>　變於初也，前見賢而後獲罪者，愛憎之至變也。故有愛於主，則知當而加親；見憎於

<a id="p44"></a>**〔44〕**　<sub>中華本頁 2150a</sub>　主，則罪當而加疏。故諫說之士不可不察愛憎之主而後說之矣。夫龍之為蟲也，可擾狎而騎也。然其喉下有逆鱗徑尺，人有嬰之，則必殺人。

<a id="p45"></a>**〔45〕**　<sub>中華本頁 2155a</sub>　人主亦有逆鱗，說之者能無嬰人主之逆鱗，則幾矣。

<a id="p46"></a>**〔46〕**　<sub>中華本頁 2155a</sub>　人或傳其書至秦。秦王見孤憤、五蠹之書，曰：「嗟乎，寡人得見此人與之游，死不恨矣！」李斯曰：「此韓非之所著書也。」秦因急攻韓。韓王始不用非，及急，迺遣非使秦。秦王悅之，未信用。李斯、姚賈害之，毀之曰：「韓非，韓之諸公子也。今王欲并諸侯，非終為韓不為秦，此人之情也。今王不用，久留而歸之，此自遺患也，不如以過法誅之。」秦王以為然，下吏治非。李斯使人遺非藥，使自殺。韓非欲自陳，不得見。秦王後悔之，使人赦之，非已死矣。

<a id="p47"></a>**〔47〕**　<sub>中華本頁 2155a</sub>　申子、韓子皆著書，傳於後世，學者多有。余獨悲韓子為說難而不能自脫耳。

<a id="p48"></a>**〔48〕**　<sub>中華本頁 2156a</sub>　太史公曰：老子所貴道，虛無，因應變化於無為，故著書辭稱微妙難識。莊子散道德，放論，要亦歸之自然。申子卑卑，施之於名實。韓子引繩墨，切事情，明是非，其極慘礉少恩。皆原於道德之意，而老子深遠矣。
