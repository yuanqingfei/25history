# 史記·卷19　惠景閒侯者年表第七

底本：见 [原文/README.md](../README.md)。段号即定位符中的“段”。

<a id="p1"></a>**〔1〕**　<sub>中華本頁 0977a</sub>　惠景閒侯者年表第七

<a id="p2"></a>**〔2〕**　<sub>中華本頁 0977a</sub>　太史公讀列封至便侯，曰：有以也夫！長沙王者，著令甲，稱其忠焉。昔高祖定天下，功臣非同姓疆土而王者八國。至孝惠時，唯獨長江全，禪五世，禪五世，以無嗣絕，意無過，為藩守職，信矣。故其澤流枝庶，毋功而侯者數人。及孝惠訖孝景閒五十載，追修高祖時遣功臣，及從代來，吳楚之勞，諸侯子弟若肺腑，外國歸義，封者九十有餘。咸表始終，當世仁義成功之著者也。
