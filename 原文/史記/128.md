# 史記·卷128　史記卷一百二十八

<a id="p1"></a>**〔1〕**　<sub>中華本頁 3223a</sub>　龜策列傳第六十八索隱龜策傳有錄無書，褚先生所補。其事煩蕪陋略，無可取。正義史記至元成閒十篇有錄無書，而褚少孫補景、武紀，將相年表，禮書、樂書、律書，三王世家，蒯成侯、日者、龜策列傳。日者、龜策言辭最鄙陋，非太史公之本意也。

<a id="p2"></a>**〔2〕**　<sub>中華本頁 3223a</sub>　太史公曰：自古聖王將建國受命，興動事業，何嘗不寶卜筮以助善！唐虞以上，不可記已。自三代之興，各據禎祥。塗山之兆從而夏啟世，飛燕之卜順故殷興，百穀之筮吉故周王。王者決定諸疑，參以卜筮，斷以蓍龜，不易之道也。

<a id="p3"></a>**〔3〕**　<sub>中華本頁 3223a</sub>　蠻夷氐羌雖無君臣之序，亦有決疑之卜。或以金石，或以草木，國不同俗。然皆可以戰伐攻擊，推兵求勝，各信其神，以知來事。

<a id="p4"></a>**〔4〕**　<sub>中華本頁 3223a</sub>　略聞夏殷欲卜者，乃取蓍龜，已則[⿱𠫓廾]去之，以為龜藏則不靈，蓍久則不神。至周室之卜官，常寶藏蓍龜；又其大小先後，各有所尚，要其歸等耳。或以為聖王遭事無不定，決疑無不見，其設稽神求問之道者，以為後世衰微，愚不師智，人各自安，化分為百室，道散而無垠，故推歸之至微，要絜於精神也。或以為昆蟲之所長，聖人不能與爭。其處吉凶，別然否，多中於人。至高祖時，因秦太卜官。天下始定，兵革未息。及孝惠享國日少，呂后女主，孝文、孝景因襲掌故，未遑講試，雖父子疇官，世世相傳，其精微深妙，多所遺失。至今上即位，博開藝能之路，悉延百端之學，通一伎之士咸得自效，絕倫超奇者為右，無所阿私，數年之閒，太卜大集。會上欲擊匈奴，西攘大宛，南收百越，卜筮至預見表象，先圖其利。及猛將推鋒執節，獲勝於彼，而蓍龜時日亦有力於此。上尤加意，賞賜至或數千萬。如丘子明之屬，富溢貴寵，傾於朝廷。至以卜筮射蠱道，巫蠱時或頗中。素有眦睚不快，因公行誅，恣意所傷，以破族滅門者，不可勝數。百僚蕩恐，皆曰龜策能言。後事覺姦窮，亦誅三族。

<a id="p5"></a>**〔5〕**　<sub>中華本頁 3224a</sub>　夫摓策定數，灼龜觀兆，變化無窮，是以擇賢而用占焉，可謂聖人重事者乎！周公卜三龜，而武王有瘳。紂為暴虐，而元龜不占。晉文將定襄王之位，卜得黃帝之兆，卒受彤弓之命。獻公貪驪姬之色，卜而兆有口象，其禍竟流五世。楚靈將背周室，卜而龜逆，終被乾谿之敗。兆應信誠於內，而時人明察見之於外，可不謂兩合者哉！君子謂夫輕卜筮，無神明者，悖；背人道，信禎祥者，鬼神不得其正。故書建稽疑，五謀而卜筮居其二，五占從其多，明有而不專之道也。

<a id="p6"></a>**〔6〕**　<sub>中華本頁 3225a</sub>　余至江南，觀其行事，問其長老，云龜千歲乃遊蓮葉之上，蓍百莖共一根。又其所生，獸無虎狼，草無毒螫。江傍家人常畜龜飲食之，以為能導引致氣，有益於助衰養老，豈不信哉！

<a id="p7"></a>**〔7〕**　<sub>中華本頁 3225a</sub>　略闚其要，故作龜策列傳。」臣往來長安中，求龜策列傳不能得，故之大卜官，問掌故

<a id="p8"></a>**〔8〕**　<sub>中華本頁 3225a</sub>　文學長老習事者，寫取龜策卜事，編于下方。聞古五帝、三王發動舉事，必先決蓍龜。傳曰：「下有伏靈，上有兔絲；上有擣

<a id="p9"></a>**〔9〕**　<sub>中華本頁 3225a</sub>　蓍，下有神龜。」所謂伏靈者，在兔絲之下，狀似飛鳥之形。新雨已，天清靜無風，

<a id="p10"></a>**〔10〕**　<sub>中華本頁 3225a</sub>　以夜捎兔絲去之，既以燭此地燭之，火滅，即記其處，以新布四丈環置之，明即掘

<a id="p11"></a>**〔11〕**　<sub>中華本頁 3225a</sub>　取之，入四尺至七尺，得矣，過七尺不可得。伏靈者，千歲松根也，食之不死。聞蓍生

<a id="p12"></a>**〔12〕**　<sub>中華本頁 3225a</sub>　滿百莖者，其下必有神龜守之，其上常有青雲覆之。傳曰：「天下和平，王道得，而蓍莖

<a id="p13"></a>**〔13〕**　<sub>中華本頁 3225a</sub>　長丈，其叢生滿百莖。」方今世取蓍者，不能中古法度，不能得滿百莖長丈者，取八十

<a id="p14"></a>**〔14〕**　<sub>中華本頁 3225a</sub>　莖已上，蓍長八尺，即難得也。人民好用卦者，取滿六十莖已上，長滿六尺者，既可用

<a id="p15"></a>**〔15〕**　<sub>中華本頁 3225a</sub>　矣。記曰：「能得名龜者，財物歸之，家必大富至千萬。」一曰「北斗龜」，二曰「南辰龜」，

<a id="p16"></a>**〔16〕**　<sub>中華本頁 3225a</sub>　三曰「五星龜」，四曰「八風龜」，五曰「二十八宿龜」，六曰「日月龜」，七曰「九州龜」，八

<a id="p17"></a>**〔17〕**　<sub>中華本頁 3225a</sub>　曰「玉龜」：凡八名龜。龜圖各有文在腹下，文云云者，此某之龜也。略記其大指，不

<a id="p18"></a>**〔18〕**　<sub>中華本頁 3225a</sub>　寫其圖。取此龜不必滿尺二寸，民人得長七八寸，可寶矣。今夫珠玉寶器，雖有所深

<a id="p19"></a>**〔19〕**　<sub>中華本頁 3225a</sub>　藏，必見其光，必出其神明，其此之謂乎！故玉處於山而木潤，淵生珠而岸不枯者，

<a id="p20"></a>**〔20〕**　<sub>中華本頁 3227a</sub>　潤澤之所加也。明月之珠出於江海，藏於蚌中，蚗龍伏之。王者得之，長有天下，四

<a id="p21"></a>**〔21〕**　<sub>中華本頁 3227a</sub>　夷賓服。能得百莖蓍，并得其下龜以卜者，百言百當，足以決吉凶。

<a id="p22"></a>**〔22〕**　<sub>中華本頁 3227a</sub>　日剔取其腹下甲。龜千歲乃滿尺二寸。王者發軍行將，必鑽龜廟堂之上，以決吉凶。

<a id="p23"></a>**〔23〕**　<sub>中華本頁 3227a</sub>　今高廟中有龜室，藏內以為神寶。傳曰：「取前足臑骨穿佩之，取龜置室西北隅懸之，以入深山大林中，不惑。」臣

<a id="p24"></a>**〔24〕**　<sub>中華本頁 3227a</sub>　為郎時，見萬畢石朱方，傳曰：「有神龜在江南嘉林中。嘉林者，獸無虎狼，鳥無鴟

<a id="p25"></a>**〔25〕**　<sub>中華本頁 3227a</sub>　梟，草無毒螫，野火不及，斧斤不至，是為嘉林。龜在其中，常巢於芳蓮之上。左脅書文

<a id="p26"></a>**〔26〕**　<sub>中華本頁 3227a</sub>　曰：『甲子重光，得我者匹夫為人君，有土正，諸侯得我為帝王。』求之於白蛇蟠

<a id="p27"></a>**〔27〕**　<sub>中華本頁 3228a</sub>　杅林中者，齋戒以待，譺然，狀如有人來告之，因以醮酒佗髮，求之三宿

<a id="p28"></a>**〔28〕**　<sub>中華本頁 3228a</sub>　而得。」由是觀之，豈不偉哉！故龜可不敬與？

<a id="p29"></a>**〔29〕**　<sub>中華本頁 3228a</sub>　問者曰：「龜至神若此，然太卜官得生龜，何為輒殺取其甲乎？」近世江上人有得名

<a id="p30"></a>**〔30〕**　<sub>中華本頁 3228a</sub>　龜，畜置之，家因大富。與人議，欲遣去。人教殺之勿遣，遣之破人家。龜見夢曰：「送我

<a id="p31"></a>**〔31〕**　<sub>中華本頁 3228a</sub>　水中，無殺吾也。」其家終殺之。殺之後，身死，家不利。人民與君王者異道。人民得

<a id="p32"></a>**〔32〕**　<sub>中華本頁 3228a</sub>　名龜，其狀類不宜殺也。以往古故事言之，古明王聖主皆殺而用之。宋元王時得龜，亦殺而用之。謹連其事於左方，令好事者觀擇其中焉。宋元王二年，江使神龜使於河，至於泉陽，漁者豫且舉網得而囚之。置之籠中。

<a id="p33"></a>**〔33〕**　<sub>中華本頁 3229a</sub>　夜半，龜來見夢於宋元王曰：「我為江使於河，而幕網當吾路。泉陽豫且得我，我不能

<a id="p34"></a>**〔34〕**　<sub>中華本頁 3229a</sub>　去。身在患中，莫可告語。王有德義，故來告訴。」元王惕然而悟。乃召博士衞平

<a id="p35"></a>**〔35〕**　<sub>中華本頁 3229a</sub>　而問之曰：「今寡人夢見一丈夫，延頸而長頭，衣玄繡之衣而乘輜車，來見夢於寡人

<a id="p36"></a>**〔36〕**　<sub>中華本頁 3229a</sub>　曰：『我為江使於河，而幕網當吾路。泉陽豫且得我，我不能去。身在患中，莫可告語。

<a id="p37"></a>**〔37〕**　<sub>中華本頁 3229a</sub>　王有德義，故來告訴。』是何物也？」衞平乃援式而起，仰天而視月之光，觀斗所

<a id="p38"></a>**〔38〕**　<sub>中華本頁 3229a</sub>　指，定日處鄉。規矩為輔，副以權衡。四維已定，八卦相望。視其吉凶，介蟲先見。乃

<a id="p39"></a>**〔39〕**　<sub>中華本頁 3229a</sub>　對元王曰：「今昔壬子，宿在牽牛。河水大會，鬼神相謀。漢正南北，江河固期，

<a id="p40"></a>**〔40〕**　<sub>中華本頁 3229a</sub>　南風新至，江使先來。白雲壅漢，萬物盡留。斗柄指日，使者當囚。玄服而乘輜車，

<a id="p41"></a>**〔41〕**　<sub>中華本頁 3229a</sub>　其名為龜。王急使人問而求之。」王曰：「善。」

<a id="p42"></a>**〔42〕**　<sub>中華本頁 3229a</sub>　於王，王故使我求之。」泉陽令乃使吏案籍視圖，水上漁者五十五家，上流之廬，名為

<a id="p43"></a>**〔43〕**　<sub>中華本頁 3229a</sub>　豫且。泉陽令曰：「諾。」乃與使者馳而問豫且曰：「今昔汝漁何得？」豫且曰：「夜半

<a id="p44"></a>**〔44〕**　<sub>中華本頁 3229a</sub>　時舉網得龜。」使者曰：「今龜安在？」曰：「在籠中。」使者曰：「王知子得龜，故使我

<a id="p45"></a>**〔45〕**　<sub>中華本頁 3229a</sub>　求之。」豫且曰：「諾。」即系龜而出之籠中，獻使者。

<a id="p46"></a>**〔46〕**　<sub>中華本頁 3229a</sub>　風將而行。入於端門，見於東箱。身如流水，潤澤有光。望見元王，延頸而前，三步而

<a id="p47"></a>**〔47〕**　<sub>中華本頁 3229a</sub>　止，縮頸而卻，復其故處。元王見而怪之，問衞平曰：「龜見寡人，延頸而前，以何望

<a id="p48"></a>**〔48〕**　<sub>中華本頁 3229a</sub>　也？縮頸而復，是何當也？」衞平對曰：「龜在患中，而終昔囚，王有德義，使人活之。

<a id="p49"></a>**〔49〕**　<sub>中華本頁 3229a</sub>　今延頸而前，以當謝也，縮頸而卻，欲亟去也。」元王曰：「善哉！神至如此乎，不可久

<a id="p50"></a>**〔50〕**　<sub>中華本頁 3229a</sub>　留；趣駕送龜，勿令失期。」衞平對曰：「龜者是天下之寶也，先得此龜者為天子，且十言十當，十戰十勝。生

<a id="p51"></a>**〔51〕**　<sub>中華本頁 3231a</sub>　於深淵，長於黃土。知天之道，明於上古。游三千歲，不出其域。安平靜正，動不用力。

<a id="p52"></a>**〔52〕**　<sub>中華本頁 3231a</sub>　壽蔽天地，莫知其極。與物變化，四時變色。居而自匿，伏而不食。春倉夏黃，秋白冬

<a id="p53"></a>**〔53〕**　<sub>中華本頁 3231a</sub>　黑。明於陰陽，審於刑德。先知利害，察於禍福，以言而當，以戰而勝，王能寶之，諸

<a id="p54"></a>**〔54〕**　<sub>中華本頁 3231a</sub>　侯盡服。王勿遣也，以安社稷。」元王曰：「龜甚神靈，降于上天，陷於深淵。在患難中。以我為賢。德厚而忠信，故來

<a id="p55"></a>**〔55〕**　<sub>中華本頁 3231a</sub>　告寡人。寡人若不遣也，是漁者也。漁者利其肉，寡人貪其力，下為不仁，上為無德。

<a id="p56"></a>**〔56〕**　<sub>中華本頁 3231a</sub>　君臣無禮，何從有福？寡人不忍，柰何勿遣！」衞平對曰：「不然。臣聞盛德不報，重寄不歸；天與不受，天奪之寶。今龜周流天

<a id="p57"></a>**〔57〕**　<sub>中華本頁 3231a</sub>　下，還復其所，上至蒼天，下薄泥塗。還徧九州，未嘗愧辱，無所稽留。今至泉陽，漁者

<a id="p58"></a>**〔58〕**　<sub>中華本頁 3231a</sub>　辱而囚之。王雖遣之，江河必怒，務求報仇。自以為侵，因神與謀。淫雨不霽，水不可

<a id="p59"></a>**〔59〕**　<sub>中華本頁 3231a</sub>　治。若為枯旱，風而揚埃，蝗蟲暴生，百姓失時。王行仁義，其罰必來。此無佗故，其祟

<a id="p60"></a>**〔60〕**　<sub>中華本頁 3231a</sub>　在龜。後雖悔之，豈有及哉！王勿遣也。」元王慨然而歎曰：「夫逆人之使，絕人之謀，是不暴乎？取人之有，以自為寶，是不

<a id="p61"></a>**〔61〕**　<sub>中華本頁 3231a</sub>　彊乎？寡人聞之，暴得者必暴亡，彊取者必後無功。桀紂暴彊，身死國亡。今我聽子，

<a id="p62"></a>**〔62〕**　<sub>中華本頁 3231a</sub>　是無仁義之名而有暴彊之道。江河為湯武，我為桀紂。未見其利，恐離其咎。寡人狐

<a id="p63"></a>**〔63〕**　<sub>中華本頁 3232a</sub>　疑，安事此寶，趣駕送龜，勿令久留。」衞平對曰：「不然，王其無患。天地之閒，累石為山。高而不壞，地得為安。故云物

<a id="p64"></a>**〔64〕**　<sub>中華本頁 3232a</sub>　或危而顧安，或輕而不可遷；人或忠信而不如誕謾，或醜惡而宜大官，或美好佳麗

<a id="p65"></a>**〔65〕**　<sub>中華本頁 3232a</sub>　而為衆人患。非神聖人，莫能盡言。春秋冬夏，或暑或寒。寒暑不和，賊氣相奸。同歲異

<a id="p66"></a>**〔66〕**　<sub>中華本頁 3232a</sub>　節，其時使然。故令春生夏長，秋收冬藏。或為仁義，或為暴彊。暴彊有鄉，仁義有時。

<a id="p67"></a>**〔67〕**　<sub>中華本頁 3232a</sub>　萬物盡然，不可勝治。大王聽臣，臣請悉言之。天出五色，以辨白黑。地生五穀，以知

<a id="p68"></a>**〔68〕**　<sub>中華本頁 3232a</sub>　善惡。人民莫知辨也，與禽獸相若。谷居而穴處，不知田作。天下禍亂，陰陽相錯。悤

<a id="p69"></a>**〔69〕**　<sub>中華本頁 3232a</sub>　悤疾疾，通而不相擇。妖數見，傳為單薄。聖人別其生，使無相獲。禽獸有牝
