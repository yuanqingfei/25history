# 编写规范

## 1. 一个人一个文件

`人物/<首见书>/<姓名>.md`。同名者在文件名后加括号区别，例如 `召平（廣陵）.md`。
没有名字的人，用书中的称呼作为姓名（如“陳嬰母”“烏江亭長”），并标 `无名: true`。必要时可以加地名区别（如“陰陵田父”），并在备注中说明这个称呼不是原文人名。

编号 `id` 格式为 `书代号 + 首见卷三位 + "-" + 卷内出场序号`，例如 `SJ007-022`（范增）。书代号见 `scripts/books.tsv`。编号一经分配就不再改动；以后与 CBDB 对齐时，另加 `cbdb_id` 字段。

## 2. 文件格式

```markdown
---
id: SJ007-022
姓名: 范增
别称: [亞父, 歷陽侯, 范曾]
籍贯: 居鄛
时代: 秦末楚漢之際
身份: 臣属
品评: 君子
品评依据类型: 书中人物评语
品评依据:
  - 原文〔史記·卷56·陳丞相世家〕
出现卷: [7, 8, 56]
互见: ["卷8¶45 勸項羽擊沛公"]
异文: "..."
消歧: "..."
备注: "..."
待补: "..."
校对状态: "..."
---

# 范增傳

> 原文〔史記·卷7·項羽本紀〕

> 原文〔史記·卷56·陳丞相世家〕
```

正文规则（由 `verify.py` 强制检查）：

- 正文只能有标题行、空行和引文行，**不允许任何非原文的文字**。
- 每个引文行是底本某一卷中的**一段连续原文**，只忽略空白；标点、字形必须完全一致。不能用省略号拼接：要跳过中间的内容，就拆成两行。
- 引文按事件先后排列。
- 同一件事在多处都有记载时，正文取记载最详细的一处，其余位置列入 `互见`（格式为 `卷N¶段落号 摘要`）。如果另一处补充了关键信息（例如曹无伤“欲以求封”），就改取那一处入正文。
- 评论别人的话（如高祖评范增），以及史臣论赞中涉及此人的句子，也可以作为引文收入正文。

## 3. 两个维度：身份 × 品评

**身份**（只看地位，不看好坏）：帝王、国王、后妃、宗室、臣属、将领、士民、妇女、四夷、方外、其他。

**品评**（按修史者的价值观，不按今人的价值观）：

| 品评 | 含义 |
|---|---|
| 君子 | 包括英雄、忠臣、义士、贤者，男女都算 |
| 普通 | 书中无褒贬，或褒贬并存、无法判断 |
| 小人 | 叛徒、告密、谄佞、负义等小恶 |
| 恶贼 | 故意杀人作恶、大奸大逆 |

**品评依据类型**按可信程度从高到低排列：

1. `史臣论赞`：“太史公曰”“史臣曰”“赞曰”中的评价
2. `类传归属`：被列入忠义、孝友、循吏、酷吏、佞幸、奸臣、叛臣、逆臣等类传
3. `史家叙评`：叙事中作者直接下的评语（如“素信謹，稱為長者”）
4. `书中人物评语`：书中其他人物对此人的评价
5. `行事推断`：书中无明文，按当时的伦理（忠、孝、节、义）由行事推断
6. `无`：无可依据，品评必须为“普通”

规则：

- 除依据类型为“无”的以外，品评都要在 `品评依据` 里列出原文，同样逐字校验。
- 书中无明文褒贬、行事也谈不上善恶的人，一律列为“普通”。
- 依据类型为“行事推断”，或者褒贬互相冲突时，必须在 `备注` 中写明理由，并标“存争议”。
- 帝王同样有品评，例如可以是“帝王 × 恶贼”。

## 4. 消歧

- 同名不同人：每个人分别立文件，并在 `消歧` 字段中列出其他同名者所在的卷。
- 一人多名：所有称呼都列入 `别称`，包括字、号、爵号、谥号、官称和异文。
- 检索的误中（如“召平陽君”实为“召/平陽君”）要记录在 `消歧` 中，方便以后复核。
- 不能确定是否同一人的，在人物表中标“待考”，暂不合并。

## 5. 工作流程

1. 逐卷整理人物表（`_<篇名>人物表.tsv`）。
2. 对每个人用 `find.py` 检索全书的所有称呼，逐条判断是否指这个人。
3. 按本规范编排传记。
4. 运行 `verify.py`，必须 0 错误才能提交。
5. 跨书合并：处理后面的史书（如《汉书》）时，已有传的人物直接在原文件里追加引文。
