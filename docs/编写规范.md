# 编写规范

## 1. 一个人一个文件

`人物/<首见书>/<姓名>.md`。同名者在文件名后加括号区别，例如 `召平（廣陵）.md`。
没有名字的人，用书中的称呼作为姓名（如“陳嬰母”“烏江亭長”），并标 `无名: true`。必要时可以加地名区别（如“陰陵田父”），并在备注中说明这个称呼不是原文人名。

编号 `id` 格式为 `书代号 + 首见卷三位 + "-" + 卷内出场序号`，例如 `SJ007-022`（范增）。书代号见 `scripts/books.tsv`。编号一经分配就不再改动；以后与 CBDB 对齐时，另加 `cbdb_id` 字段。

## 2. 共享段落：传记里只存定位符

原文只存一份，就是底本（`sources/`）。传记里不抄原文，只写**定位符**，由 `scripts/render.py` 展开成可读的全文传记（输出到 `build/`）。同一段原文被几个人引用时，几篇传记指向同一个定位符，不产生重复文本；`scripts/index.py` 生成 `索引/段落人物.tsv`，可以查到每一段涉及哪些人。

定位符格式：

```
書名·卷·段｜起…止
書名·卷·段｜全文
```

- **卷**：卷标记，例如 `7`、`1上`、`27中之下`。
- **段**：该卷的第几段（非空行，从 1 起）。用 `find.py` 检索时，结果直接给出这三项。
- **起…止**：所引原文的开头几个字和结尾几个字，中间用一个“…”连接，展开为两者之间（含两端）的全部原文。开头字串在该段中必须唯一。
- 原文不超过 40 字时，直接写全文，不用省略。
- 锚点不用手工挑：先写全文，再运行 `scripts/reanchor.py <文件>`，自动缩成最短的唯一锚点（每端至少 8 字）。

```markdown
---
id: SJ007-012
姓名: 陳嬰
别称: [堂邑侯]
时代: 秦末楚漢之際
身份: 臣属
类传:                 # 有类传时填写，见第 3 节
品评: 君子
品评依据类型: 史家叙评
品评依据:
- 史記·7·4｜陳嬰者，故東陽令史，居縣中，素信謹，稱為長者。
推断理由:             # 品评依据类型为“行事推断”时必填
出现卷:
  史記: ['7', '91']
  漢書: ['31', '97上', '100上']
已查: [史記, 漢書]     # 已经检索过的书
互见:                 # 同一事件的其他记载，也是定位符，不展开
- 史記·91·2｜陳嬰以項氏世為楚將
异文: ...
消歧: ...
待补: ...
校对状态: ...
---

# 陳嬰傳

> 史記·7·4｜聞陳嬰已下東陽，…，異軍蒼頭特起。
```

正文规则（由 `verify.py` 强制检查）：

- 正文只能有标题行、空行和 `> 定位符` 行，不允许任何非原文的文字。YAML 里的定位符（品评依据、互见等）同样必须能展开。
- 引文按事件先后排列。一个定位符不能跨段：要跨段就拆成两行。
- 同一件事有多处记载时，正文取记载最详细的一处，其余列入 `互见`。如果另一处补充了关键信息（例如曹无伤“欲以求封”、陈婴后封堂邑侯），就把那一处也收入正文。
- 底本修订后，运行 `verify.py` 就能找出失效的定位符。

## 3. 检索范围：本书 + 相邻史书

每个人至少要查完**首见书和 `scripts/neighbors.tsv` 列出的全部相邻史书**（`find.py 史记+ 人名` 一次查完），查过的书记入 `已查`。南北史与八书、新旧两唐书、新旧两五代史属于同时代重修，一律视为相邻。

跨越很多代的家族，在 `家族/` 下另立家族文件（见第 6 节）。

## 4. 两个维度：身份 × 品评

**身份**（只看地位，不看好坏）：帝王、国王、后妃、宗室、臣属、将领、士民、妇女、四夷、方外、其他。

**品评**（按修史者的价值观，不按今人的价值观）：

| 品评 | 含义 |
|---|---|
| 君子 | 包括英雄、忠臣、义士、贤者，男女都算 |
| 普通 | 书中无褒贬，或褒贬并存、无法判断 |
| 小人 | 叛徒、告密、谄佞、负义等小恶 |
| 恶贼 | 故意杀人作恶、大奸大逆 |

**品评的判定顺序**：

1. **类传归属**优先：被列入忠义、孝友、循吏、酷吏、佞幸、奸臣、叛臣、逆臣、列女、儒林、隐逸等类传的，填 `类传` 字段，品评取 `scripts/leizhuan.tsv` 中的默认值。确实需要改判时（例如《史记·酷吏列传》中以廉著称的人），在备注中写“改判”并说明理由。
2. 没有类传时，依次看：`史臣论赞`（太史公曰、史臣曰、赞曰）→ `史家叙评`（叙事中作者的直接评语，如“素信謹，稱為長者”）→ `书中人物评语`。
3. 以上都没有时，由我们根据此人的言行，按当时的伦理（忠、孝、节、义）推断：`行事推断`，并且必须填写 `推断理由`。项目组也是裁判之一。
4. 实在无可依据的：`无`，品评只能是“普通”。

其他规则：

- 除“无”以外，品评都要在 `品评依据` 中列出定位符。
- 帝王同样要品评，例如可以是“帝王 × 恶贼”。

## 5. 消歧

- 同名不同人：每个人分别立文件，并在 `消歧` 字段中列出其他同名者所在的卷。
- 一人多名：所有称呼都列入 `别称`，包括字、号、爵号、谥号、官称和异文。
- 检索的误中（如“召平陽君”实为“召/平陽君”）要记录在 `消歧` 中，方便以后复核。
- 不能确定是否同一人的，在人物表中标“待考”，暂不合并。

## 6. 家族

`家族/<姓氏>（<郡望>）.md`。YAML 中的 `成员` 逐个列出：人物编号、姓名、世代（以始见者为第 1 代）、关系，以及关系的原文依据（定位符）。`verify.py` 会检查成员编号是否存在于人物表中，且姓名一致。正文和人物传一样，只能放定位符，收录关于整个家族的记载。史书没有记载的关系写“未載”，不推测。

## 7. 工作流程

1. 逐卷整理人物表（`_<篇名>人物表.tsv`）。
2. 对每个人用 `find.py <首见书>+ <全部称呼>` 检索本书和相邻史书，逐条判断是否指这个人（注意异文，如“曹毋傷”）。
3. 按本规范编排传记，运行 `reanchor.py` 缩短锚点。
4. 运行 `verify.py`，必须 0 错误才能提交；再运行 `index.py` 更新反向索引。
5. 以后处理到别的史书时，已有传的人物直接在原文件里追加定位符，并更新 `已查`。
