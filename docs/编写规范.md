# 编写规范

## 0. 一律用简体

传记、家族、人物表、原文、文件名、定位符一律用简体中文。底本选用质量最好的繁体本（TLS 中华书局点校本、维基文库），导入后由 `scripts/jianti.py` 用 OpenCC 转成简体工作文本（引号改为“”‘’）。转换逐段保持字数不变，繁简字位一一对应，所以引文可以随时回查繁体原本（`sources/_繁/`）。只有在找不到繁体底本、只能用简体本时，才直接使用该简体本。

## 1. 一个人一个文件

`人物/<首见书>/<姓名>.md`。同名者在文件名后加括号区别，例如 `召平（广陵）.md`。
没有名字的人，用书中的称呼作为姓名（如“陈婴母”“乌江亭长”），并标 `无名: true`。必要时可以加地名区别（如“阴陵田父”），并在备注中说明这个称呼不是原文人名。

编号 `id` 格式为 `书代号 + 首见卷三位 + "-" + 卷内出场序号`，例如 `SJ007-022`（范增）。书代号见 `scripts/books.tsv`。编号一经分配就不再改动；以后与 CBDB 对齐时，另加 `cbdb_id` 字段。

## 2. 引文的两种写法：独用写原文，共享写定位符

原文只在底本（`sources/`，可浏览版在 `原文/`）中保存一份。传记正文的引文行有两种写法，由 `scripts/reanchor.py` 统计全部传记后**自动决定**，不用手工维护：

- **独用引文**（没有别的传记或家族文件引用到这些文字）：直接写原文全文，后面附出处链接，读者不必跳转：

  ```
  > 曾祖父陈婴与项羽俱起，后归汉，为堂邑侯。〔[汉书·97上·29](../../原文/汉书/097上.md#p29)〕
  ```

- **共享引文**（与其他文件的引文在文字上有重叠）：只写定位符，点击跳到 `原文/` 中的段落：

  ```
  > [史记·7·5｜陈婴母谓婴曰：“…言，以兵属项梁。](../../原文/史记/007.md#p5)
  ```

以后有新的传记引用了同一段文字，原来直接写原文的那一条会在下次运行 `reanchor.py` 时自动改成定位符。两种写法都能还原成同一个定位符，校验、展开（`render.py`）、迁移都按定位符处理。`scripts/index.py` 生成的 `索引/段落人物.tsv` 可以查每一段涉及哪些人；`原文/` 中每段后面也列出“引用此段”的人物。

定位符格式：

```
书名·卷·段｜起…止
书名·卷·段｜全文
```

- **卷**：卷标记，例如 `7`、`1上`、`27中之下`。
- **段**：该卷的第几段（非空行，从 1 起）。用 `find.py` 检索时，结果直接给出这三项。
- **起…止**：所引原文的开头几个字和结尾几个字，中间用一个“…”连接，展开为两者之间（含两端）的全部原文。开头字串在该段中必须唯一。
- 原文不超过 40 字时，直接写全文，不用省略。
- 锚点不用手工挑：先写全文，再运行 `scripts/reanchor.py <文件>`，自动缩成最短的唯一锚点（每端至少 8 字）。
- 底本分段有误、一句话被断在两段时，段号可写成 `31-32`（最多跨 3 段）。
- 正文中的引文（无论哪种写法）都链接到 `原文/<书>/<卷>.md#p<段>`。链接由 `reanchor.py` 自动生成，`verify.py` 检查写法和链接是否规范。YAML 中的定位符（品评依据、互见等）保持纯文本。
- 底本更换后，用 `scripts/migrate.py` 把定位符迁移到新底本（去标点、繁简归一后匹配，异文处模糊匹配），再运行 `build_yuanwen.py` 和 `verify.py`。

```markdown
---
id: SJ007-012
姓名: 陈婴
别称: [堂邑侯]
时代: 秦末楚汉之际
身份: 臣属
类传:                 # 有类传时填写，见第 3 节
品评: 君子
品评依据类型: 史家叙评
品评依据:
- 史记·7·4｜陈婴者，故东阳令史，居县中，素信谨，称为长者。
推断理由:             # 品评依据类型为“行事推断”时必填
出现卷:
  史记: ['7', '91']
  汉书: ['31', '97上', '100上']
已查: [史记, 汉书]     # 已经检索过的书
互见:                 # 同一事件的其他记载，也是定位符，不展开
- 史记·91·2｜陈婴以项氏世为楚将
异文: ...
消歧: ...
待补: ...
校对状态: ...
---

# 陈婴传

> [史记·7·5｜闻陈婴已下东阳，…，异军苍头特起。](../../原文/史记/007.md#p5)
```

正文规则（由 `verify.py` 强制检查）：

- 正文只能有标题行、空行和引文行（上述两种写法之一），不允许任何非原文的文字。YAML 里的定位符（品评依据、互见等）同样必须能展开。
- 引文按事件先后排列。一个定位符不能跨段：要跨段就拆成两行。
- 同一件事有多处记载时，正文取记载最详细的一处，其余列入 `互见`。如果另一处补充了关键信息（例如曹无伤“欲以求封”、陈婴后封堂邑侯），就把那一处也收入正文。
- 底本修订后，运行 `verify.py` 就能找出失效的定位符。

## 3. 检索范围：两层

**必查层**：首见书和 `scripts/neighbors.tsv` 列出的全部相邻史书（`find.py 史记+ 人名`）逐条判断，构成传记**主体**。

**全史扫描层**：`scripts/scan.py <人物文件>` 自动检索首见书**之后**的全部史书（一个人只会被身后的史书提到；必查层已查过的书不再重复），按句列出命中。逐条判断：

- **本人**：后世的追赠、祭祀、评论、典故、遗迹（墓冢、地名）、传说等，收入传记末尾的 `## 后世` 一节；同一内容在几部书重复出现（如南史抄宋书、北史抄北齐书），只收一处，其余列入 `互见`。后世史书对此人的评价，可同时列入 `品评依据`。
- **同名异人**、**字面误中**（如“召平章政事”“宋义阳王”）：不收。把能稳定识别的误中写进 `检索排除`（正则，匹配命中处前后各 6 字），别称会带来大量误中的，用 `检索词` 指定实际检索的词（如“虞”只检索“虞姬”“虞兮”“美人名虞”）。
- 扫描结果记入 YAML：

```yaml
已查: [史记, 汉书, 全史]
检索词: [范增, 亚父]          # 可选，默认为姓名＋别称
检索排除: [陈匡范增]          # 可选
全史扫描:
  范围: 后汉书—清史稿（23部）
  命中: 29
  收入后世: 12
  列入互见: 14
  排除: “历阳侯”另有其人……
```

底本误断段、句子被截在段末时，`scan.py` 会自动接上下一段，给出 `31-32` 形式的定位符。

跨越很多代的家族，在 `家族/` 下另立家族文件（见第 6 节）。

## 4. 两个维度：身份 × 品评

**身份**（只看地位，不看好坏）：帝王、国王、后妃、宗室、臣属、将领、士民、妇女、四夷、方外、其他。

**品评**（按修史者的价值观，不按今人的价值观）：

| 品评 | 含义 |
|---|---|
| 君子 | 包括英雄、忠臣、义士、贤者，男女都算 |
| 普通 | 书中无褒贬，或褒贬并存、无法判断 |
| 小人 | 叛徒、告密、谄佞、负义等小恶 |
| 恶贼 | 故意杀人作恶、大奸大逆 |

**品评的判定顺序**：

1. **类传归属**优先：被列入忠义、孝友、循吏、酷吏、佞幸、奸臣、叛臣、逆臣、列女、儒林、隐逸等类传的，填 `类传` 字段，品评取 `scripts/leizhuan.tsv` 中的默认值。确实需要改判时（例如《史记·酷吏列传》中以廉著称的人），在备注中写“改判”并说明理由。
2. 没有类传时，依次看：`史臣论赞`（太史公曰、史臣曰、赞曰）→ `史家叙评`（叙事中作者的直接评语，如“素信谨，称为长者”）→ `书中人物评语`。
3. 以上都没有时，由我们根据此人的言行，按当时的伦理（忠、孝、节、义）推断：`行事推断`，并且必须填写 `推断理由`。项目组也是裁判之一。
4. 实在无可依据的：`无`，品评只能是“普通”。

其他规则：

- 除“无”以外，品评都要在 `品评依据` 中列出定位符。
- 帝王同样要品评，例如可以是“帝王 × 恶贼”。

## 5. 消歧

- 同名不同人：每个人分别立文件，并在 `消歧` 字段中列出其他同名者所在的卷。
- 一人多名：所有称呼都列入 `别称`，包括字、号、爵号、谥号、官称和异文。
- 检索的误中（如“召平阳君”实为“召/平阳君”）要记录在 `消歧` 中，方便以后复核。
- 不能确定是否同一人的，在人物表中标“待考”，暂不合并。

## 6. 家族

`家族/<姓氏>（<郡望>）.md`。YAML 中的 `成员` 逐个列出：人物编号、姓名、世代（以始见者为第 1 代）、关系，以及关系的原文依据（定位符）。`verify.py` 会检查成员编号是否存在于人物表中，且姓名一致。正文和人物传一样，只能放定位符，收录关于整个家族的记载。史书没有记载的关系写“未载”，不推测。

## 7. 工作流程

1. 逐卷整理人物表（`_<篇名>人物表.tsv`）。
2. 对每个人用 `find.py <首见书>+ <全部称呼>` 检索本书和相邻史书，逐条判断是否指这个人（注意异文，如“曹毋伤”）。
3. 按本规范编排传记（引文行可以先写成 `> 定位符` 或 `> 书·卷·段｜原文全文`），运行 `reanchor.py`，自动决定写法、生成链接。
4. 运行 `build_yuanwen.py` 更新 原文/ 的反向链接，运行 `index.py` 更新索引，最后运行 `verify.py`，必须 0 错误才能提交。
5. 以后处理到别的史书时，已有传的人物直接在原文件里追加定位符，并更新 `已查`。
