# 底本说明

## 选择原则

1. **主底本**首选中华书局点校本系统：繁体、有标点、分段，学界通行，便于他人核对。
2. **备选底本**选不同来源（最好是不同版本系统）的完整文本，用于**对校**：找出主底本的漏字、错字、标记错误。
3. 授权必须允许公开再发布，因为 `原文/` 要放进本仓库供定位符跳转。
4. 一部书只用一个主底本，不在书内混用版本；主底本缺卷时，宁可整部换用另一来源，或者明确标出补自何本。

## 简体工作文本

主底本都是繁体，导入后统一转为简体（`scripts/jianti.py`，OpenCC t2s 按词转换，引号「」『』改为“”‘’）。全书所有段落转换前后字数完全相同，繁简逐字对应；繁体原本保留在 `sources/_繁/`。繁简转换偶有一对多的问题（如“餘/余”“乾/干”），遇到人名、地名转换不当时，记入 `scripts/jiaokan.tsv` 修正。

## 已知问题与待办

- **对校**：写 `scripts/duijiao.py`，把主底本与备选底本逐卷对齐（去标点、去注、繁简归一），列出一方有、一方无的文字段。TLS 的“正文误入注文”类错误要靠这一步系统找出，修补记入 `scripts/jiaokan.tsv`。
- **表格（优先）**：TLS《史记》十表、《汉书》八表都只有序言、没有表格内容。表中有大量封侯、任免、卒年记载（如陈婴、项伯、吕马童的卒年都在功臣侯者年表），直接影响人物覆盖与生卒。需从备选底本导入表格。表格类卷次的引用规则另行制定，表格文字拟取自备选本。
- **注文**：颜师古注、裴松之注、三家注目前一律去掉。裴注里有大量人物材料，以后可考虑作为“注文层”单独收录。
- **校勘符号**：点校本的删字（圆括号）、补字（方括号）照原样保留。

## 校勘记

对主底本的每一处修补都记在 `scripts/jiaokan.tsv`，导入时自动应用，并写明依据。
